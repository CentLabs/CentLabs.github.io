### 英语一 / 英语二差异说明

**来源｜AI归来·大作文（2.1 考试大纲、2.2 大作文）原文**

```
该部分由A、B 两节组成，考查考生的书面表达能力。共2 小题，共30 分。
A 节（1 小题）：要求考生根据规定情景写一篇约100 词（标点符号不计算在内）的应用文，
类型包括书信、通知、告示、纪要等。共10 分。
B 节（1 小题）：要求考生根据提示信息写一篇160~200 词（标点符号不计算在内）的短文。
提示信息的形式为文字、图画、图表等。共20 分。
（英语二）共2 小题，共25 分；B 节约150 词，共15 分。
可见，除了分数和字数不同，英一英二大纲写作部分完全相同，大作文均有可能考到图画、
图表和文字作文，小作文均有可能考到书信、通知、告示、纪要。
```

| 项目 | 英语一 | 英语二 | 说明 |
|---|---|---|---|
| 小作文 A 节 | 约 100 词 / 10 分 | 约 100 词 / 10 分 | 完全相同，无区分 |
| 大作文 B 节 | 160~200 词 / 20 分 | 约 150 词 / 15 分 | 仅分值、字数不同 |
| 提示形式 | 文字 / 图画 / 图表 | 文字 / 图画 / 图表 | 大纲表述完全相同 |
| 命题传统 | 长期考图画 | 长期考图表 | **已被打破** |
| 近年变化 | 24 图画+图表；25 表格；26 双图表 | 仍以图表为主 | 英一重点已调整至图表（尤其双图表） |

**来源｜AI归来·大作文（前言）原文**

```
即便25 考研英一大作文突然考图表（表格）26 考研英一大作文突然考双图表，
```

## 第1章 大作文总论（评分标准、字数、三段式结构、审题立意）

### 1.1 得分点与"评分标准"的素材依据

各份模板讲义均**未逐条抄录官方评分量表**，而是以"高分准则 + 阅卷得分点"的形式给出可操作标准。整理如下（前五条为原文照录）：

**来源｜AI归来·大作文（2.4 高分准则）原文**

```
1.卷面整洁。建议买一本字帖，每天练习10 分钟。
2.结构清晰。看见题目就应迅速构思文章结构，本模板已帮你做到。
3.语言丰富。看见题目就应迅速确定写作句型，本模板已帮你做到。
4.拼写正确。除了掌握本模板中的单词，还要积累"主题词"。
5.契合主题。审题其实很容易，历年真题均可一眼看出文章主题，文章内容只要
和主题相关、不牵强即可。
```

**来源｜AI归来·大作文（前言）关于分数目标原文**

```
帮助同学们在考场上用40 分钟时间获得80%以上的分数，即英一24 分+，英二20 分+。
```

| 得分维度 | 对应讲义要求 | 扣分风险 |
|---|---|---|
| 卷面 | 每天练字帖 10 分钟 | 涂改、字迹潦草 |
| 结构 | 见题即构思三段 | 段落缺失、无分段 |
| 语言 | 见题即确定句型 | 通篇简单句、句式重复 |
| 拼写 | 模板词 + 主题词双积累 | 主题词拼错（英二尤其致命） |
| 契合主题 | 内容相关、不牵强 | 主题词只翻译五个字、跑题 |

**来源｜108黄金句式（开篇说明）原文**

```
英语作文不同于中文，中文作文给学生留有比较大的发挥空间，而英语作文只要文章流畅，
没有语法错误，主题明确就比较容易拿到高分，也就是说，比起语文作文，英语作文更容易被"套路"。
```

### 1.2 字数与行数、时间分配

```
字数在200 左右，占用18~20 行。在这25 分钟的时间里，5 分钟用于审题和构建
写作框架（在脑海中或写在题目旁），剩下的时间用于默写作文。
```

|---|---|---|
| 目标字数 | 英一 160~200 词；英二约 150 词 | 约 100 词 |
| 建议句数 | 三段约 10 句 | 三段约 8 句 |
| 默写用时 | 25 分钟（含 5 分钟审题） | 15 分钟内 |
| 答题卡 | 18~20 行 | — |

**来源｜补充卡片（知识点73，回填 AI归来·大作文）三段式与字数原文**

```
大作文：第一段（引入/描述+主题）→ 第二段（原因分析，英一3点/英二2~3点）→ 第三段（总结+措施+展望）
小作文：第一段（称呼+意图）→ 第二段（具体内容/原因）→ 第三段（情感+期待回信）+ 落款
```

### 1.3 三段式结构与"最大公约数"

**来源｜AI归来·大作文（2.2）原文**

```
图画作文是透过图画看寓意、图表作文是透过图表看现象、文字作文是阅读文字提主题，
这三种题型本质都是议论文，主题阐述句都可以总结为某某事很重要。
注意，图画、图表、文字作文的第一段完全不同！同时学习，内容过多难以掌握。
图画、图表、文字作文的第二、三段几乎相同，合并学习，省时省力。
因此先掌握一个类型的作文，随后加以补充，学习路径如下：
图表作文第一段 ➡ 通用的第二段 ➡ 通用的第三段 ➡ 图画作文第一段 ➡ 文字作文第一段
```

| 段落 | 图画作文 | 图表作文 | 文字作文 | 是否通用 |
|---|---|---|---|---|
| 第一段 | 图画描述 + 主题阐述 | 总体描述 + 细节描述 + 社会现象 | 改写现象 + 改写观点 + 表明态度 | **完全不同** |
| 第二段 | 过渡句 + 原因 123 | 过渡句 + 原因 123 | 过渡句 + 原因 123 | **几乎相同** |
| 第三段 | 总结 + 措施 + 展望 | 总结 + 措施 + 趋势预测 | 总结 + 措施 + 展望 | **几乎相同** |

**来源｜补充卡片（知识点75，回填 AI归来·大作文）学习路径原文**

```
英语一学习路径：图画作文第一段 → 通用第二段 → 通用第三段 → 图表作文第一段 → 文字作文第一段
英语二学习路径：图表作文第一段 → 通用第二段 → 通用第三段 → 图画作文第一段 → 文字作文第一段
七大原因方案：至少掌握五个，方案一（举例）、三（从句+五大方面）、五（虚拟语气）必须掌握。
```

### 1.4 审题立意

**来源｜补充卡片（知识点2/7，回填 AI归来·大作文 3.4）要点原文**

```
图画作文第一段 = 图画描述 + 主题阐述，透过图画看寓意，寓意可概括为"某事很重要"。
主题词要"具体到事"（如信心匮乏、环境恶化、文化交流、广泛学习），
不能只翻译"五个字"宏观概念。
```

**来源｜见山学长·主题词原文（同义替换策略）**

```
考过"孝顺"，但大部分考生不会写"filial piety"，此时可选择简单词汇进行同义替换，
比如可写"take care of our parents"，同理，英语二真题考过国产车市场份额增加，
"国产车"不会写"domestic motor vehicle"可以用"Chinese car"来替换，对分数不会有太大影响。
```

**来源｜补充卡片（知识点75，回填 AI归来·大作文）套用思想原文**

```
只背不练无用，需反复套用真题；将偏好句型抄成自己的模板；
不要"写想写的"，要"写会写的"，把写作方向向语料库靠。
```

> 审题三步：① 判定题型（图画/图表/文字/混合）→ ② 提取**具体到事**的主题词 → ③ 定性（积极品质 / 消极现象 / 中性趋势），据此选第二段理由与第三段措施。

### 1.5 常见题型与备考优先级

**来源｜泪眼汪汪·大作文（精简版模板·使用说明）原文**

```
1. 图画类大作文：范围最广，是其他题型（如文字类、混合类）的底层基础。
2. 图表类（动态图）：侧重展示数据随时间发生的上升或下降趋势。
3. 图表类（静态图）：侧重展示某一时期的比例分布状况（如饼图）。
   严禁逐个罗列所有数据，只需挑出"占比最大"和"占比最小"的两项进行对比；
   分析原因时必须使用强对比逻辑词（如By contrast）。
4. 混合类大作文（图画+图表）：看似复杂，实则是图画与图表的简单拼接。
   第二、第三段直接无缝套用前三类作文的现成模板即可，无需另行准备。
5. 文字类大作文：本质上就是"纯文字版的图画作文"。
   第一段只需写三句话（转述引文→强调价值→亮明立场）。
```

### 2.2 开头描图句（引入过渡句）· 三套来源

**来源｜AI归来·大作文（3.4 图画描述过渡句）原文**

```
升级前：As is shown in the picture above, 图画描述.
升级后：As is symbolically depicted in the figure above, 图画描述.

What looks beyond dispute in the drawing is that 图画描述.
The cartoon provides us with a socially symbolic scene: 图画描述.
Portrayed distinctively by the cartoon above is a common scene: 图画描述.
What the drawing above mirrors is not merely a scene, but a thought-provoking social trend.
```

**替换词表｜AI归来·大作文（3.4）原文**

```
shown → illustrated / depicted / demonstrated / portrayed / reflected / described /
        outlined / illuminated / expressed / presented / indicated
（加副词 vividly / symbolically / subtly / clearly / distinctively）
picture → drawing / painting / photograph / cartoon / figure
```

> 两幅图时：`Similarly, / Likewise, / On the contrary, / Unfortunately, / Meanwhile,` 引出第二幅图；逗号或 `that` 后接完整句子。

**来源｜泪眼汪汪·大作文（图画类·第一段万能模板）原文**

```
倒装悬念句：Set before us is an intriguing illustration, wherein...
客观写实句：This compelling drawing captures a striking moment when...
让步深思句：Amusing as the caricature may seem at first glance, its underlying
message regarding (核心主题) is deeply illuminating.
直击本质句：The phenomenon mirrored in this artwork serves as a powerful
metaphor for a prevailing societal trend.
```

**来源｜Fiona·图画（一、开头段模板·开篇引言）原文**

```
备选句型1）The picture offers a vivid glimpse of... / an inspiring glimpse into…
备选句型2）The picture encapsulates… / captures a vivid view of… / vividly captures (the essence of…)
备选句型3）The picture sharpens the focus on… / The picture brings…into sharper focus.
```

**来源｜Fiona·图画（真题例句）原文**

```
The picture offers an inspiring glimpse into the choice of "quitting" versus "persevering".
The picture vividly captures the essence/warmth of family love.
The picture sharpens the focus on people's attitudes towards books.
```

### 2.3 图画描述句（分类、拆分、组合法）

**来源｜AI归来·大作文（3.4 一幅图非对话型）原文**

```
公式：环境+基本动作(do)+主体，主要动作(doing)，with 细节。
例：As is symbolically depicted in the figure above, on the playground runs a young
man, rushing to the finishing line, with a sweet smile on his face.
升级（as well as 结构修饰主体）：
...on the playground runs a young man, active as well as vigorous, rushing to the
finishing line, with a sweet smile on his face.
```

**替换词表｜AI归来·大作文（3.4）原文**

```
基本动作：stand / sit / lie / run / stay
主要动作：listen / talk / read / write / wear / stare / think
万能环境：in front of us / in the middle of the picture
正面形容词对：lovely as well as cute / amiable as well as friendly /
              confident as well as optimistic
负面形容词对：cruel as well as vicious / negative as well as passive
```

**来源｜AI归来·大作文（3.4 对话型 + 两幅图）原文**

```
对话型公式：环境+基本动作+主体，主要动作. A 说的话, 关联词+B 说的话.
例：As is symbolically depicted in the figure above, in front of us stand two girls,
talking about campus lectures. One holds that campus lectures are irrelevant to her
major. On the contrary, the other holds that attending lectures is beneficial nonetheless.

两幅图例：The cartoons provide us with a thought-provoking scene: the girl in the
left picture is fully focused on her homework, thinking that she will feel relieved
when she finishes her work. Whereas in the right picture, the boy is lying on the
sofa, telling himself that he will not start until the deadline.
```

```
hold 替换：believe / argue / contend / maintain / assert / is convinced that /
           hold the view that
```

> 人物对话/想法**强烈建议转述**（直译显得低级、不连贯）；升级可加 `who` 定语从句与 `, 基本动作(doing),`。

**来源｜AI归来·大作文（3.4 例外：there be / 描述标题）原文**

```
The cartoon provides us with a socially symbolic scene: there are many cultural
elements in the delicious and nutritious hotpot, such as Peking Opera, Kung fu,
Shakespeare and so on. Below the pot, a caption reads: "Cultural hot pot, nutritious
and delicious."

描述标题句型：
Below the drawing, there is a topic which says: 翻译.
A profound statement is placed below the picture: 翻译.
The subtitle indicates: 翻译.
```

**来源｜Fiona·图画（图画描述·主干句型 / 双图表达法）原文**

```
备选a) As shown, sb is (sitting / standing / doing sth) + 介宾短语, ving 伴随状态
        + 定/状语从句
例句：As shown, a father himself is sitting in an easy chair, watching a TV show
      while urging his son to study hard.

备选b）As we can see, there is sb ving + 介宾短语 + 定/状语从句
```

### 3.1 图表类型与静态/动态判断

**来源｜Fiona·图表（常考图表类型）原文**

```
Column chart（柱状图）：用竖柱比较数据；
Bar chart（条形图）：用横条比较数据（通常用于名称较长的项目）；
Pie chart（饼状图）：展示各部分占整体的比例；
Line graph（折线图）：反映数据随时间的变化趋势；
Table（表格）：用行列呈现具体数据
```

**来源｜AI归来·大作文（3.1）原文**

```
所有图表按类型分为表格table、柱状图bar chart、线状图line chart、饼状图pie chart，
按数据分为动态图、静态图，按个数分为单图表、双图表。
如何描述图表：分类、拆分、组合法
图表描述的思路是：总体描述+细节描述。总体描述通常改编自图表的标题，
简述数据的变化（动）或分布（静）；细节描述需要具体到数据变化或占比，
而数据变化只能是增加、减少、持平、波动，变化快慢只能是迅速或缓慢。
```

**来源｜Loru·首段讲义（第一部分 图表分类）原文**

```
① 先判断图表是否呈现时间变化
静态图主要比较各项大小与比例，例如独自锻炼、和朋友一起锻炼的人各占多少，
不涉及时间变化。
动态图主要看数量或比例随时间怎样变化，例如公园数量增加、就业比例下降。
③ 单项变化与多项变化
以每张图为单位判断：单项变化描述一个统计指标随时间的变化；多项变化描述多个
类别或指标各自的变化。
同趋势变化：多项数据都上升或都下降；不同趋势变化：有的上升、有的下降
总项与分项是整体与部分的关系。例如，全国快递总业务量是总项，其中的农村快递
业务量是分项。
④ 双图
两张图表可以组合成"静态＋静态"、"动态＋静态"、"动态＋动态"。
双图也可以是"图画＋图表"，其中的图表仍按静态图或动态图来分析。
```

> 判断顺序（照录 Loru 体系）：**是否随时间变化 → 静态/动态 → 单项/多项 → 同趋势/不同趋势 → 单图/双图 → 是否图画+图表混合**。

### 5.1 大纲界定与题型关系

**来源｜AI归来·大作文（2.1 考试大纲）／AI归来·小作文（2.1）原文**

```
A 节（1 小题）：要求考生根据规定情景写一篇约100 词（标点符号不计算在内）的应用文，
类型包括书信、通知、告示、纪要等。共10 分。
小作文是应用文，包括书信、通知、告示、纪要等。英一英二并无区分。
```

**来源｜AI归来·小作文（2.1 类型说明）原文**

```
大纲对小作文的类型做出了界定：书信、通知、告示、纪要等。其中，书信……
通知＝告示，英文都是notice，一般是公开的宣布一件事或决定，是换了格式的书信；
纪要……本质上与备忘录相同，但还没有考过。
出题角度虽然不同，但本质是同一件事：以"创新大赛"为例，题目让你邀请个人参加，
就是邀请信；题目让你邀请多人参加，就是通知告示；题目让你作为选手询问比赛安排，
就是咨询信；题目让你提出举办方案，就是建议信；题目让你总结这场比赛，就是纪要。
```

> 核心结论（AI归来体系）：**弱化题型区分，强化功能表达**。同一批功能句换格式即可用于书信 / 通知 / 纪要。

### 5.2 书信分类：被动写信 vs 主动写信

**来源｜AI归来·小作文（2.1 书信分类）原文**

```
被动写信：根据题目提供的情景或来信被动回复对方，即回复信、答复信，……
答复信无需自我介绍，因为对方知道你是谁，因此直入主题，介绍来信意图。
公务信函，对方（例如：某教授、某组织、某机构等）不知道你的身份，
因此需要简单地自我介绍，表明身份即可。有两种情况：1.题干已经给出；2.题干未给出。
出现第二种情况时，默认自己是学生。
```

| 类别 | 判定 | 第一段要求 |
|---|---|---|
| 被动写信（回复/答复信） | 对方来信、认识你 | 背景提要 + 来信意图，**不自我介绍** |
| 主动写信（公务信函） | 写给机构/陌生人 | **自我介绍（不可省略）** + 来信意图 |

### 11.3 临场时间分配

**来源｜AI归来·大作文（前言 / 2.2）原文**

```
帮助同学们在考场上用40 分钟时间获得80%以上的分数，即英一24 分+，英二20 分+。
使用该大作文模板……能够在考场上25 分钟内默写完毕，字数在200 左右，占用18~20 行。
```

|---|---|---|

| 小作文 | 约 15 分钟 | 约 8 句、约 100 词，含称呼与落款 |
| 检查 | 1~2 分钟 | 按 11.1 清单专项核查语法、拼写、题干动作词 |
| 平时训练 | 每周 1 篇 → 考前 20 天每天 1 篇 | 用真题反复套用，只做小升级 |
