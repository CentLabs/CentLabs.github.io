## 四、答题规范与常见失分点

### 4.1 综合应用题的答题规范（依据真题精解中的评分说明）

1. **算法设计题（数据结构 41/42 题）必须四段齐全**：①基本设计思想；②详细实现步骤；③C/C++/Java 代码实现（关键处注释）；④时间复杂度与空间复杂度说明。
   - 2009-42 评分说明：一遍扫描得满分 15 分；两遍或多遍扫描、递归、或使用与 k 相关的辅助数组，即使结果正确**最高只给 10 分**；「只要能写出数据结构类型定义、正确的算法思想，都会至少给一半以上分数，能用伪代码写出自然更好」。
   - 2012-42 评分说明：算法正确且时间复杂度 O(m+n) 给 12 分；**超过 O(m+n) 最高 9 分**；思想描述不清但代码能清晰体现思路，按同标准给分。
   - 2011-42：O(log₂n)/O(1) 是「尽可能高效」的判分线；2010-42：O(n)/O(1) 优于 O(n)/O(p)。
   - 2009-42、2011-42、2012-42 均明确：**使用 C++/JAVA 语言正确实现的算法同样给分**。
2. **计算题必须写出过程与理由**：2009-43「如果考生只给出正确的计算结果，未给出计算过程，每个给 2 分」；2009-46、2012-46「过程描述正确但计算结果不正确，可酌情给分」；2010-45、2010-22「要求给出计算过程」「说明理由」。结论错但过程对可拿分，只写结论反而封顶。
3. **按小问分步给分，结论与理由分开计分**：2012-45 每问「结论 1 分 + 理由 1 分」；2011-44 每问 1–2 分；2009-47 每个路由项 1 分。因此即使整题不会，也应把能确定的分项（如子网掩码、接口名）写全。2009-47 还明确：「接口」用 IP 地址表示亦给分、下一跳写「直接到达」亦给分。
4. **符号与术语允许等价写法**：2009-45「wait()、signal() 等同于 P、V」；2020-45 等 PV 题同样认可；2016-43/44 评分说明「使用 C++/JAVA 语言的答案视同 C 语言」。
5. **反证/举例题要答到点子上**：2009-41「若考生回答『能求得最短路径』，无论给出何种证明，均不给分」；「只要举出一个类似反例，或答案中体现了『局部最优不等于全局最优』的思想，均可给 6 分」。

### 4.2 常见失分点（精解中明确点名的「误区/注意」）

| 失分点 | 真题出处与精解原话 |
|---|---|
| **审题看反条件** | 2009 CO-21：「题中说明的是**缺失 50 次**，而不是命中 50 次，仔细审题是做对题的第一步」（命中率应为 95%）。 |
| **速度提升 ≠ 时间减半** | 2012 CO-12【误区】：「CPU 速度提高 50%，则 CPU 运行时间减少一半。错误！」应为 90/1.5+10=70 秒。 |
| **ASL 不成功不能按全表算** | 2010 DS-41：「这里要特别防止惯性思维。查找失败时……根据散列函数 MOD 7，初始只可能在 0～6 的位置」，ASL 不成功按散列地址数 7 平均（18/7），不是按表长 10。 |
| **GBN 与 SR 的累积确认混淆** | 2009 CN-35（GBN 累积确认，收到 3 号确认即 0～3 全收到）；2011 CN-35：「选择重传协议中的 ACK **不再具有累积确认的作用**，要特别注意其与 GBN 协议的区别」。 |
| **B 树与 B+ 树混淆** | 2009 DS-8：「注意区别 B-树和 B+树各自的特点」——叶结点间指针链接是 B+ 树特征。 |
| **最小生成树「代价唯一 ≠ 树形唯一」** | 2012 DS-8：权值相同的边可能使树形不唯一，但代价一定唯一；「所有权值最小的边一定出现在所有 MST 中」错误。 |
| **TLB / Page / Cache 的蕴含关系** | 2010 CO-17：「TLB 命中，必然 Page 也命中」；三者命中组合中「TLB 命中 + Page 未命中」不可能。 |
| **教材定义与真题口径不一致** | 2009 CO-14：「部分教材中介绍的组相联跟此处的组相联并不相同……**考生应以真题为准**」。 |
| **read 系统调用的参数** | 2012 OS-28：「read 系统调用只需要使用 open 返回的**文件描述符**，并不使用文件名作为参数」；参数应为 fd、buf、n。 |
| **结构体边界对齐** | 2012 CO-15：「本题要考虑到 C 程序中的结构体 struct 按**边界对齐**的问题」，int 须 4 的倍数、short 须 2 的倍数，故 c 不可能在 0xC00D。 |
| **单位换算与分段计时** | 2009 CN-37「注意单位的转换」；2010 CN-34 存储转发要加 2 次转发延迟（80→80.16ms）；2010 CO-22 显存带宽按「50% 刷屏」再除 0.5；2012 CO-19 突发传输要把地址周期与数据周期分开算；2010 CN-47 有效数据率只算帧数据部分 1500B，不含 18B 首部。 |
| **折半插入 vs 直接插入** | 2012 DS-11：两者总趟数、移动次数、辅助空间都相同，**只有元素之间的比较次数不同**。 |
| **Peterson/谦让类算法不会饥饿** | 2010 OS-27：turn 变量有最终值，先「谦让」者先进入临界区，**不会出现饥饿**。 |
| **回忆版答案存在分歧与存疑** | 2020 王道回忆版与正式答案表第 38 题不一致（C vs D）；2022 王道回忆版第 8 题标「【存疑】」；2020 回忆版自标「题干不完整」「回忆不全」「也有同学反馈……答案就选 D」；2025 回忆版标「直播后答案有更改」。**遇分歧以带逐题解析的正式卷答案表为准，并保留核对习惯**。 |

### 4.3 复习与作答建议（基于上述复现统计）

- 把 **Cache/TLB 地址划分、PV 伪代码、TCP 拥塞窗口 ssthresh 变化、二叉树遍历序列反推、排序分趟特征、子网划分/路由聚合** 六项做成固定解题模板：它们在 17 个年份中几乎年年出现，且题型高度稳定。
- 综合题按「小问拆答、每问写结论+理由/过程」组织，即便最后数值算错，也能依评分说明拿到过程分。
- 图形、表格缺失的题目（本文已标注）在真实考场上依赖原图，复习时应补做含图版本，避免只记住本文记录的结论。
- 回忆版年份（2021、2023、2024、2025、2026）以「考点定位」为主，不宜把回忆版的答案当作唯一标准答案。
