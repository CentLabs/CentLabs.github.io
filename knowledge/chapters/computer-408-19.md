## 第1章 绪论（数据结构基本概念、算法与复杂度分析）

### 1.1 知识体系

**1.1.1 数据的基本概念层次**

- **数据**：信息的载体，是描述客观事物属性的数、字符以及所有能输入到计算机中并被程序识别和处理的符号集合。
- **数据元素**：数据的基本单位，通常作为一个整体进行考虑和处理；一个数据元素可由若干个**数据项**组成，数据项是构成数据元素的不可分割的最小单位（例如「学生记录」是数据元素，学号、姓名、性别是数据项）。
- **数据对象**：具有相同性质的数据元素的集合，是数据的一个子集（例如整数数据对象 $N=\{0,\pm1,\pm2,\dots\}$）。
- **数据类型**：一个值的集合和定义在此集合上一组操作的总称，分三类：
  - **原子类型**：值不可再分；
  - **结构类型**：值可再分解为若干成分（分量）；
  - **抽象数据类型（ADT）**：抽象数据组织及与之相关的操作，用一个三元组 $(\text{数据对象},\ \text{数据关系},\ \text{基本操作集})$ 表示。ADT 的定义仅取决于其**逻辑特性**，与在计算机内部如何表示和实现无关。
- **数据结构**：相互之间存在一种或多种特定关系的数据元素的集合，包括三方面内容：**逻辑结构、存储结构（物理结构）、数据的运算**。

> 关键结论（王道 PPT）：「一个算法的设计取决于所选定的逻辑结构，而算法的实现依赖于所采用的存储结构」；「逻辑结构和存储结构密不可分」——存储结构应正确反映逻辑关系。

**1.1.2 逻辑结构**

逻辑结构指数据元素之间的逻辑关系，与存储无关、独立于计算机，分为两大类：

- **线性结构**：数据元素之间存在一对一关系。细分为直接存取（数组）、顺序存取（链表）、字典结构（Hash）。
- **非线性结构**：
  - **集合结构**：除「同属于一个集合」外别无其他关系（群关系）；
  - **树形结构（层次结构）**：一对多，如家族族谱、通知分发；
  - **图状/网状结构（群关系）**：多对多，如地图路线分布。

（补充笔记的等价表述：线性结构 = 直接存取-数组 / 顺序存取-链表 / 字典结构-Hash；非线性结构 = 层次结构-树 / 群关系-图与集合。）

**1.1.3 四种存储结构**

| 存储结构 | 含义 | 特点 |
|---|---|---|
| 顺序存储 | 逻辑相邻的元素物理位置也相邻 | 可随机访问 $O(1)$，插入删除需移动元素 |
| 链接存储 | 物理位置未必相邻，借助指针/引用指示相邻元素 | 不需连续空间、可动态扩充，只能顺序访问 |
| 索引存储 | 附加索引表，建立关键字 key 与地址的映射 | 类似目录，检索需先查索引表 |
| 散列存储 | 由 key 通过散列函数直接计算存储地址 | 需处理冲突 |

**1.1.4 算法及其特性**

算法是为解决某一特定任务规定的**有限指令集合**（运算序列），五大特性：

1. **有输入**、2. **有输出**、3. **确定性**（每条指令含义确定、无歧义）、4. **有穷性**（执行步骤有限、有界，与「程序可能无限循环」区分）、5. **可行性**。

算法性能标准（补充笔记）：正确性、可使用性、可读性、效率、健壮性、简单性；前期估计（分析）与后期测试（统计）相结合。

**1.1.5 复杂度与渐进分析**

- **时间复杂度** $T(n)$：算法中基本运算的频度随问题规模 $n$ 增长的数量级，写作 $T(n)=O(f(n))$；一般考察**最坏情况**。王道 PPT 定义：时间复杂度衡量「算法随问题规模增大，执行时间增长的快慢」，主要分析 $T(n)$ 的数量级。
- **空间复杂度** $S(n)=O(g(n))$：算法运行所需额外存储空间的增长率。
- 渐进分析分**最好 / 最坏 / 平均**三种情形；渐进符号：$O$ 描述**上限**，$\Omega$ 描述**下限**，$\Theta$ 表示上下限同阶。
- 常用复杂度大小关系（王道 PPT 与补充笔记一致，$\log_2 n$ 常简写 $\log n$）：

$$O(1)<O(\log_2 n)<O(n)<O(n\log_2 n)<O(n^2)<O(n^3)<O(2^n)<O(n!)<O(n^n)$$

**1.1.6 复杂度计算规则**

- 计算方法：取算法中时间增长最快的那个函数项、忽略其系数（$T=(3n+6)t \Rightarrow O(n)$，常数项直接忽略）。
- **加法规则**（多个独立循环体）：$T(n)=T_1(n)+T_2(n)=\max\big(T_1(n),\,T_2(n)\big)$。
- **乘法规则**（嵌套循环体）：$T(n)=T_1(n)\times T_2(n)$。
- 典型循环：
  - `for(i=1;i<=n;i++) x++;` → 循环体执行约 $n$ 次 → $O(n)$；
  - `for(i=1;i<=n;i=2*i)` → 满足 $2^k\le n$，执行 $\lceil\log_2 n\rceil$ 次 → $O(\log n)$；
  - 双层 $n\times n$ 嵌套 → $O(n^2)$。

### 1.2 核心考点详解

**① 逻辑结构与存储结构不可混淆。** 线性表是**逻辑结构**概念，顺序表/链表是**存储实现**，二者不在同一层次；同一逻辑结构可采用多种存储结构，同一存储结构也可承载不同逻辑结构。选择题常给出「栈是逻辑结构还是存储结构」这类陷阱——栈与队列是**受限的线性表（逻辑结构 + 运算约束）**，顺序栈/链栈才是存储实现。

**② $O(\cdot)$ 只是随 $n$ 变化的趋势，$n$ 较小时不一定符合。** 补充笔记给出经典反例：$n=3$ 时反而有 $n^3>2^n>n!$（$27>8>6$），即低阶复杂度在小规模下未必更快。这也是选择题常见干扰项。

**③ 语句频度与递推次数要分开算。** 递归算法用递推式：如 2012 真题阶乘 $T(n)=T(n-1)+1,\ T(1)=O(1)$，得 $T(n)=O(n)$，而非把每层乘法当成 $O(1)$ 就误判为 $O(\log n)$。

**④ 复杂度关注增长率而非绝对时间。** 王道 PPT 用曲线说明：随 $n$ 增大，$O(n)$、$O(n\log n)$、$O(n^2)$ 的斜率差异显著放大，因此只需比较增长最快的项。

### 1.3 典型算法/代码（复杂度分析示例）

```c
/* 例1：语句频度 3n+6，取增长最快项 -> O(n) */
int sum = 0;
for (int i = 0; i <= n; i++) sum = sum + i;      /* i=0 执行1次；i<=n 判断 n+2 次；i++ 执行 n+1 次；循环体 n+1 次 */

/* 例2：i 每轮翻倍 -> O(log n) */
for (int i = 1; i <= n; i = 2 * i)               /* 满足 2^k <= n，执行 ceil(log2 n) 次 */
    x++;

/* 例3（2011 统考真题第1题）：x=2; while(x<n/2) x=2*x; -> O(log2 n) */
x = 2;
while (x < n / 2) x = 2 * x;                     /* 2^(t+1)=n/2 -> t=log2 n - 2 */

/* 例4（2012 统考真题第1题）：递归阶乘 -> O(n) */
int fact(int n){
    if (n <= 1) return 1;                        /* 递归边界 */
    return n * fact(n - 1);                      /* 递归式，共执行 n-1 次 */
}
```

### 1.4 易错点与 408 真题考点

- **算法特征判断**：2009 起多次（含 2027 王道八套卷第 1 题）考「不属于算法主要特征的是」——把「有穷性、可行性、确定性」与「可读性/健壮性/高效性」区分，后者是性能标准而非必备特征；「有穷性」的核心是步骤数有界，不是「运行一定很快」。
- **时间复杂度计算**：2011 年第 1 题 `x=2*x` 型循环 $\Rightarrow O(\log_2 n)$；2012 年第 1 题递归阶乘 $\Rightarrow O(n)$。做题先写「执行次数 $t$ 与 $n$ 的方程」再解。
- **$O$ 的趋势性**：$n$ 很小时各复杂度排序可能反转（$n=3$ 反例），勿把渐进序当成任意 $n$ 下的绝对序。
- **空间复杂度**：递归工作栈深度计入空间复杂度（如阶乘递归 $O(n)$）；注意「原地工作 $O(1)$」与「辅助数组 $O(n)$」的区别。
- **ADT 与数据类型**：抽象数据类型的定义仅取决于逻辑特性，与实现无关，是「数学模型 + 一组操作」。

## 第2章 线性表（顺序表 / 链表 / 静态链表）

### 2.1 知识体系

**2.1.1 线性表的定义**

线性表是 $n\ (n\ge 0)$ 个**数据类型相同**的数据元素构成的有限序列。除第一个元素外每个元素有且仅有一个直接前驱，除最后一个外有且仅有一个直接后继。基本运算：初始化、求表长、按值/按序号查找、插入、删除、输出、判空、销毁。

> 易混点：线性表元素类型相同；**广义表**允许元素类型不同（可为原子或子表），是线性表的推广。线性表是逻辑结构，顺序表/链表是存储结构。

**2.1.2 顺序表（顺序存储）**

用一组**地址连续**的存储单元依次存放线性表元素，逻辑顺序与物理顺序一致。设元素占 $l$ 个存储单元、基址 $\text{LOC}(a_1)$，则第 $i$ 个元素地址：

$$\text{LOC}(a_i)=\text{LOC}(a_1)+(i-1)\times l$$

因此可**随机（直接）访问**，读/改第 $i$ 个元素 $O(1)$。

- **插入**：在第 $i$ 个位置（$1\le i\le n+1$）插入，需把第 $i$ 个及之后的元素后移，移动元素数 $n-i+1$；等概率下平均移动 $\dfrac{n}{2}$ 个，时间复杂度 $O(n)$。
- **删除**：删除第 $i$ 个元素（$1\le i\le n$），需把其后元素前移，平均移动 $\dfrac{n-1}{2}$ 个，$O(n)$。
- 分**静态分配**（定长数组 `data[MaxSize]`）与动态分配；表满插入需考虑扩容。

**2.1.3 单链表（链式存储）**

结点 = 数据域 `data` + 指针域 `next`，通过指针链接。可动态扩充、不需连续空间，但**只能顺序访问**，查找第 $i$ 个结点/按值查找均 $O(n)$；插入/删除本身只需改指针 $O(1)$，但定位到该位置仍需顺序查找 $O(n)$。

- **头指针**：指向链表的指针；**头结点**：在首元结点之前附设的结点，数据域可不存元素（或存表长）；**首元结点**：第一个存数据的结点。带头结点可统一空表与非空表、统一首元结点与其它结点的插入删除操作。
- **头插法**建表：新结点 `s->next = L->next; L->next = s;`，得到**逆序**链表；**尾插法**：维护尾指针 `r->next = s; r = s;`，得到**原序**链表。
- 插入结点（在 `p` 之后）：先 `s->next = p->next`，再 `p->next = s`（顺序不可颠倒，否则断链）。
- 删除结点：`q = p->next; p->next = q->next; free(q);`。

**2.1.4 双链表、循环链表与静态链表**

- **双链表**：结点含 `prior / data / next`，可双向遍历；插入需改 4 个指针，删除需改 2 处：`p->prior->next = p->next; p->next->prior = p->prior;`。
- **循环链表**：尾结点指针指向头结点（循环单链表判空 `L->next == L`）；循环双链表空表时头结点的 `prior` 与 `next` 都等于 `Head`。可用于约瑟夫问题。
- **静态链表**：借助数组描述链式结构，每个数组元素含 `data` 与 `link`（游标）域，`link` 存的是**下一元素在数组中的下标序号（不是物理地址）**；改变 `link` 即改变逻辑顺序，无需移动元素。性能与单链表相似。

**2.1.5 顺序表 vs 链表**

| 对比项 | 顺序表 | 链表 |
|---|---|---|
| 访问 | 随机/顺序，$O(1)$ | 仅顺序，$O(n)$ |
| 插入删除 | 移动元素 $O(n)$ | 改指针 $O(1)$（定位另计 $O(n)$） |
| 空间 | 需预分配连续空间，可能浪费/溢出 | 动态分配，指针域有额外开销 |
| 适用 | 查多改少、表长稳定 | 频繁插入删除、表长变化大 |

### 2.2 核心考点详解

**① 插入位置合法性与下标约定。** 顺序表插入合法位置 $1\le i\le n+1$（位序，从 1 起）；若数组下标从 0 起，则代码里 `L.data[i-1]=e`、循环 `for(j=L.length; j>=i; j--) L.data[j]=L.data[j-1];`。删除合法位置 $1\le i\le n$。边界（空表、表满、插在表尾/表头）是选择题与算法题的高频扣分点。

**② 头插逆序、尾插原序。** 头插每次把新结点插到头结点之后，输入序列 $a_1,a_2,\dots,a_n$ 建成的链表次序为 $a_n,\dots,a_1$（逆序），常用于链表逆转；尾插用尾指针保持原序。这一区别常用于「给出建表结果判断建表方式」的选择题。

**③ 插入/删除务必防断链。** 单链表在 `p` 后插入必须「先连新结点后继，再改 `p->next`」；删除必须先用 `q` 保存被删结点，改完 `p->next` 再 `free(q)`。双链表插入/删除要同时维护 `prior` 与 `next`。

**④ 静态链表的 `link` 是数组下标而非地址。** 这是与单链表最本质的区别，选择题常以「静态链表需要指针」设错。

**⑤ 一趟扫描类算法（408 综合题常考）。**
- **倒数第 $k$ 个结点**（2009 年第 42 题）：双指针 `p`、`q`，先让 `p` 走 $k$ 步，再让二者同步前进；当 `p` 到表尾时 `q` 正好指向倒数第 $k$ 个。仅一遍扫描，$O(n)$ 时间、$O(1)$ 空间。
- **两链表共同后缀起始点**（2012 年第 42 题）：先求两表长 $m,n$，长表指针先走 $|m-n|$ 步对齐表尾，再同步后移，首次 `p->next == q->next` 即为公共后缀起点，$O(m+n)$。
- **数组循环左移 $p$ 位**（2010 年第 42 题）：三次逆置 `Reverse(0,p-1)`、`Reverse(p,n-1)`、`Reverse(0,n-1)`，时间 $O(n)$、空间 $O(1)$（另解借助大小为 $p$ 的辅助数组，空间 $O(p)$）。
- **有序链表合并**、**逆转链表/顺序表**：见典型代码。

### 2.3 典型算法/代码

```c
/* 顺序表静态定义与插入（重要算法整理 P15） */
#define MaxSize 100
typedef int ElemType;
typedef struct { ElemType data[MaxSize]; int length; } SqList;

bool ListInsert(SqList &L, int i, ElemType e){
    if (i < 1 || i > L.length + 1) return false;   /* 位序合法性 */
    if (L.length >= MaxSize) return false;         /* 表满 */
    for (int j = L.length; j >= i; j--)
        L.data[j] = L.data[j - 1];                 /* 第 i 个及之后后移 */
    L.data[i - 1] = e;                            /* 下标从 0 起 */
    L.length++;
    return true;
}

/* 单链表结点类型、头插法建表（逆序）与尾插法建表（原序） */
typedef struct LNode { ElemType data; struct LNode *next; } LNode, *LinkList;
LinkList List_HeadInsert(LinkList &L){
    L = (LinkList)malloc(sizeof(LNode)); L->next = NULL;
    LNode *s; ElemType x; scanf("%d", &x);
    while (x != 9999){
        s = (LNode*)malloc(sizeof(LNode)); s->data = x;
        s->next = L->next; L->next = s;           /* 插到头结点之后 */
        scanf("%d", &x);
    }
    return L;
}

/* 在 p 之后插入 s；删除 p 之后结点（先保存后继，防断链） */
s->next = p->next;  p->next = s;
q = p->next;  p->next = q->next;  free(q);

/* 逆转顺序表 / 逆转单链表（数据结构算法背诵） */
void Reverse(int A[], int n){
    for (int i = 0; i < n / 2; i++){
        int t = A[i]; A[i] = A[n - i - 1]; A[n - i - 1] = t;
    }
}

/* 2009 年第 42 题：一趟扫描求链表倒数第 k 个结点 */
int Search_k(LinkList list, int k){

    int count = 0;
```

### 2.4 易错点与 408 真题考点

- **2009 年第 42 题**：带头结点单链表只给头指针，一趟扫描查找倒数第 $k$ 个结点（双指针法）；评分说明中「两遍/多遍扫描最高 10 分、一遍扫描满分 15 分、使用与 $k$ 相关的辅助数组空间复杂度过高最高 10 分」。
- **2010 年第 42 题**：数组循环左移 $p$ 位，要求时空尽量高效——三次逆置 $O(n)/O(1)$ 为最优解。
- **2011 年第 10 题**：快速排序宜采用**顺序存储**（因划分过程需前后双向交替扫描），从侧面强调「绝大多数内部排序只适用于顺序存储结构」。
- **2012 年第 42 题**：两个单词链表共享相同后缀，找共同后缀起始位置，时间 $O(m+n)$ / $O(\max(m,n))$。
- 头结点数据域不存元素；带头结点可简化空表与首元结点的操作——判断题高频。
- 链表 `pop`/删除结点若只改指针不 `free`，造成内存泄漏（见第 3 章链栈）。
- 静态链表 `link` 域是**序号不是地址**；双链表删除要改前驱 `next` 与后继 `prior` 共 2 处。
- 顺序表插入平均移动 $\frac{n}{2}$、删除平均 $\frac{n-1}{2}$；定位「第 $i$ 个位置」是 $O(1)$（顺序表）还是 $O(n)$（链表）要分清。

## 第3章 栈、队列与数组（循环队列、栈在递归/表达式求值中的应用、稀疏矩阵）

### 3.1 知识体系

**3.1.1 栈（Stack）**

栈是**只允许在一端（栈顶 top）进行插入和删除**的受限线性表，遵循**后进先出 LIFO**。基本操作：`Push`（入栈）、`Pop`（出栈）、`GetTop`（读栈顶）、`InitStack`、`StackEmpty`。

- 可用**顺序表（顺序栈）**或**链表（链栈）**实现。顺序栈两种约定：`top` 指向真实栈顶，或 `top` 指向真实栈顶的下一个位置；判空/判满条件随约定变化（如 `top==-1` 为空、`top==maxSize-1` 为满）。
- 链栈通常以链表头作为栈顶；**由单链表构成的链栈 `pop` 时必须 `free` 被删结点，否则内存泄漏**（补充笔记明确强调）。

**3.1.2 栈的应用**

1. **括号匹配**：遇左括号入栈，遇右括号弹栈并校验配对，扫描结束栈空则匹配。多种括号允许交叉时每种括号一个栈；不允许交叉只用一个栈即可。
2. **后缀表达式（逆波兰式 RPN）求值**：栈内存放操作数；顺序扫描，操作数入栈，遇双目运算符 $op$ 连续退栈两次得 $Y$、$X$（先弹出的是右操作数），计算 $X\ op\ Y$ 并把结果入栈；扫描完栈顶即结果。
3. **中缀转后缀**：栈内存放操作符，需区分**栈内优先级 ISP** 与**栈外优先级 ICP**（主要体现在左右括号的优先级变化）。扫描规则（补充笔记）：
   - 操作数直接输出；
   - 操作符 $op$：`op.ICP > top.ISP` → $op$ 入栈；`op.ICP < top.ISP` → 退栈并输出栈顶，$op$ 继续与新的栈顶比较；`op.ICP == top.ISP` → 退栈但**不输出**（消除括号）。
4. **函数调用 / 递归 / 显式递归（回溯法）**：系统调用栈保存现场；递归最重要的是**递归式**与**递归边界**（王道 PPT：「递归边界 + 递归式」）。
5. 典型实例：阶乘 `fact(n)=n*fact(n-1)`、Fibonacci（`Fib(0)=0, Fib(1)=1`）、八皇后、迷宫。

**3.1.3 Catalan 数（栈与树的桥梁）**

$n$ 个编号元素按某种顺序进栈、任意时刻可出栈（进出栈可交替进行），得到的不同出栈序列个数等于 $n$ 个结点能构成的不同二叉树个数，即 Catalan 函数：

$$C_n=\frac{1}{n+1}\binom{2n}{n}=\frac{(2n)!}{(n+1)!\,n!},\qquad f(n)=\sum_{i=0}^{n-1} f(i)\,f(n-1-i)$$

（补充笔记与知识点卡片一致：该数也等于不同二叉搜索树的个数。）

**3.1.4 队列（Queue）**

队列是**只允许在表尾（rear）插入、表头（front）删除**的受限线性表，遵循**先进先出 FIFO**。可用顺序队列或链队列实现。链队列入队 `rear->next = s; rear = s;`，出队 `p = front->next; front->next = p->next;`。普通顺序队列存在**「假溢出」**，须用循环队列解决。

**3.1.5 循环队列**（约定：牺牲一个单元，`rear` 指向队尾元素的下一个空位）

- 出队：`front = (front + 1) % size`；入队：`rear = (rear + 1) % size`；
- **判空**：`front == rear`；
- **判满**：`(rear + 1) % size == front`；
- **元素个数**：$(rear - front + size)\ \%\ size$。

补充：若队列非空时 `front` 指向队头元素、`rear` 指向队尾元素，且要求第 1 个元素存在 `A[0]`，则初始 `front=0, rear=n-1`（2011 年第 3 题答案）。队列应用：杨辉三角（各行间插入 0）、电路布线/迷宫（BFS 跟踪已标记但相邻点未标记的点）、操作系统任务调度。

**3.1.6 双端队列与优先级队列**

- **双端队列**：两端都可入队/出队；受限变体（如「两端可入、一端可出」）常考输出序列合法性（2010 年第 2 题）。
- **优先级队列**：非 FIFO，每次出队的是优先级最高元素；可用一般队列（每次插入/删除后把最高优先级移到队首）或**堆**实现。

**3.1.7 数组、特殊矩阵与稀疏矩阵**

- 数组是 $n\ (n\ge1)$ 个相同类型元素的有限序列，占连续空间；多维数组有**行优先**与**列优先**两种映射。行优先下 $m\times n$ 数组（下标 0 起）元素 $a[i][j]$ 的存储偏移：

$$\text{offset}=i\times n + j$$

- **特殊矩阵压缩存储**：对称矩阵、上/下三角阵、对角矩阵，只存非重复/非零元素。
- **稀疏矩阵**：非零元素极少。压缩方法：
  - **三元组表** $(行,\ 列,\ 值)$（顺序存储，转置时需保持行/列有序）；
  - **正交链 / 十字链表**（链式存储）。
- **广义表**：线性表的推广，元素可为原子或子表，递归定义、有序、有**长度**（最外层元素个数）与**深度**（括号最大嵌套层数），可共享、可递归。

### 3.2 核心考点详解

**① 栈容量 / 出栈序列合法性。** 已知入栈序列 $a,b,c,\dots$，判断某出栈序列是否合法，或求栈的最小容量：模拟入栈/出栈过程，记录栈内最大深度（2009 年第 2 题：出队序列 `b,d,c,f,e,a,g` 对应出栈序列，栈内最大深度 3，故容量至少 3）。合法出栈序列总数即 Catalan 数 $C_n$；带附加约束（如「不允许连续三次退栈」，2010 年第 1 题）时需逐项模拟排除。

**② 中缀转后缀的 ISP/ICP 与栈深度。** 同一运算符在栈内、栈外优先级不同，左右括号的优先级变化是核心：左括号入栈前 ICP 高、入栈后 ISP 最低；右括号使站内操作符依次弹出直到左括号（左括号出栈不输出）。2012 年第 2 题要求转换 `a+b-a*((c+d)/e-f)+g` 过程中栈中操作符的**最大个数 = 5**，需逐步模拟运算符栈。

**③ 循环队列的判空 / 判满 / 计数。** 牺牲一个单元时，`front==rear` 只表示空；若不加处理直接让 `rear` 追上 `front` 将无法区分空与满。求元素个数必须 `+size` 再取模防止负值。当 `front` 与 `rear` 的定义变化（如 `rear` 指向真实队尾）时，初始值与公式都要相应调整（2011 年第 3 题）。

**④ 递归与栈。** 递归调用本质是栈，递归深度决定空间复杂度；把递归改写为非递归（显式栈）是综合题常见要求（如二叉树非递归遍历，见第 5 章）。

**⑤ 稀疏矩阵压缩。** 三元组表适合「非零元位置固定、以访问为主」；十字链表适合「非零元个数和位置变化大（如矩阵加法）」。行优先与列优先下地址计算不同，注意下标起始（0 起还是 1 起）。

## 第4章 串与模式匹配（朴素、KMP 与 next 数组）

### 4.1 知识体系

**4.1.1 串的基本概念**

串（字符串）是由零个或多个字符组成的有限序列。主串 $S$、子串（模式串）$T$、串长、空串、子串在主串中的**位置**（子串首字符在主串中的序号）、串相等（长度相等且对应字符相同）。补充笔记将串与数组、广义表并列于「数组、串和广义表」；C 语言中字符串基于字符数组并附加终止符 `'\0'`（见素材 week6 笔记：`C 字符串 = 字符数组 + ASCII 0 终止符`），常用 `strcpy / strcmp / strcat / strlen`。

存储方式：定长顺序存储、堆分配存储、块链存储。

**4.1.2 朴素（简单）模式匹配**

从主串每个位置起，逐字符与模式串比较，一旦失配则**主串指针回溯**到本次起点的下一位、模式串回到首位重新比较。设主串长 $n$、模式串长 $m$，最坏时间复杂度：

$$O(n\times m)$$

补充笔记指出其「有回溯、$O(n*m)$、适合较短的字符串」。

**4.1.3 KMP 算法**

KMP 消除主串指针的回溯：主串指针 $i$ **永不回退**，失配时仅把模式串指针 $j$ 回退到 $\text{next}[j]$ 再继续比较。总时间复杂度：

$$O(n+m)$$

核心是**next 数组**，它「反映子串（模式串）自身的模式」，由模式串的最长相等前后缀决定，与主串无关。

- **$\text{next}[j]$ 的定义（王道/严蔚敏 1 起编号，$T[0]$ 存串长）**：$\text{next}[j]$ 表示在模式串第 $j$ 个字符与主串失配时，下一趟模式串应回退到的位置，等于 $T[1..j-1]$ 中**最长相等真前缀与真后缀的长度 $+1$**；规定 $\text{next}[1]=0$。
- 等价的 0 起编号定义：$\text{next}[0]=-1$，$\text{next}[j]$ = $T[0..j-1]$ 中最长相等前后缀长度，失配时 $j=\text{next}[j]$。两套编号体系极易混淆，做题先确认起始编号。
- **nextval（修正 next）**：当 $T[j]=T[\text{next}[j]]$ 时，把 $\text{next}[j]$ 修正为 $\text{nextval}[\text{next}[j]]$，避免无意义的重复比较（真题多次出现「nextval 优化后的 KMP」）。

**4.1.4 Boyer–Moore（BM）算法**

补充笔记提及：BM 从**子串（模式串）尾部**开始比较，失配时借助坏字符/好后缀规则大跨度移动（素材仅给出「从子串尾部开始比较」这一结论）。

### 4.2 核心考点详解

**① next 数组的手算。** 步骤：写出模式串各位置 $T[1..j-1]$ 的最长相等前后缀长度 $k$，令 $\text{next}[j]=k+1$；$\text{next}[1]=0$，$\text{next}[2]=1$。例如（王道经典）模式串 `abaabc` 的 $\text{next}$（1 起）为 $\text{next}[1]=0,\ \text{next}[2]=1,\ \text{next}[3]=1,\ \text{next}[4]=2,\ \text{next}[5]=2,\ \text{next}[6]=3$。408 常给出主串与模式串，要求「第一趟匹配后模式串右滑几位 / 下一趟比较的模式串第几个字符」，答案直接由 $\text{next}[j]$ 或 $\text{nextval}$ 给出。

**② KMP 匹配过程的指针变化。** 某趟在 $S[i]$ 与 $T[j]$ 失配：保持 $i$ 不动，令 $j=\text{next}[j]$（$j=0$ 时 $i$、$j$ 同时加一）；若 $j>m$ 则匹配成功，返回 $i-m$。真题（2027 王道八套卷）还考过「若 $k=\text{next}[j]$，$k'=\text{next}[i]$，下一趟比较模式串的第几个字符」这类概念辨析。

**③ 复杂度对比。** 朴素 $O(nm)$（有回溯）、KMP $O(n+m)$（无回溯）。KMP 的代价是预处理 $\text{next}$ 数组 $O(m)$ 与额外 $O(m)$ 空间。

**④ next 与 nextval 的区别。** nextval 在 $\text{next}$ 基础上对「回退后字符仍相同」的情形二次回退，减少不必要的比较；选择题常给出两种数组让考生判断「采用 nextval 优化后 KMP 的匹配过程 / 右滑距离」。

### 4.3 典型算法/代码

```c
/* 求 next 数组（重要算法整理 P269，1 起编号，T[0] 存串长） */
void get_next(char T[], int next[]){
    int i = 1, j = 0;
    next[1] = 0;
    while (i <= T[0]){
        if (j == 0 || T[i] == T[j]){
            ++i; ++j; next[i] = j;
        } else
            j = next[j];                 /* 失配时 j 回退（递归地求最长前后缀） */
    }
}

/* KMP 主算法（重要算法整理 P271，返回 T 在 S 中 pos 之后的位置） */
int KMP(char S[], char T[], int next[], int pos){
    int i = pos, j = 1;
    while (i <= S[0] && j <= T[0]){
        if (j == 0 || S[i] == T[j]){ ++i; ++j; }   /* 主串指针 i 不回溯 */
        else j = next[j];
    }
    if (j > T[0]) return i - T[0];
    else return 0;
}

/* nextval 修正思路：在 get_next 中把 next[i]=j 改为
   if (T[i] != T[j]) nextval[i] = j;
   else nextval[i] = nextval[j];                    避免回退后仍比较相同字符 */

/* 朴素模式匹配：失配时 i 回溯到 i-j+2，j 回到 1，最坏 O(n*m) */
int Index(char S[], char T[]){
    int i = 1, j = 1;
    while (i <= S[0] && j <= T[0]){
        if (S[i] == T[j]){ ++i; ++j; }
        else { i = i - j + 2; j = 1; }              /* 主串回溯 */
    }
    if (j > T[0]) return i - T[0];  else return 0;
}
```

### 4.4 易错点与 408 真题考点

- **KMP 是近年高频**：2015 年（$S=$`abaabaabacacaabaabcc`，$t=$`abaabc`，采用 KMP 匹配/第一趟相关判断）、2019 年（主串 $T=$`abaabaabcabaabc`，模式串 $S=$`abaabc`，KMP 匹配过程）、2024 年（**修正后的 KMP / nextval**，模式串 `aabab` 类，问失配时模式串右滑距离）、2027 王道八套卷（$k=\text{next}[j]$ 的下一趟比较位置；`aabaabcabc` 与 `aaaabc` 的 nextval 优化）。
- **两套 next 编号**：$\text{next}[0]=-1$（0 起）与 $\text{next}[1]=0$（1 起）不能混用；素材两套都出现（知识点卡片明确列为易错点）。
- **主串指针 $i$ 不回溯**，只有模式串指针 $j$ 回退到 $\text{next}[j]$ —— 这是 KMP 与朴素算法的本质区别，也是判断题常设的错项。
- 朴素 $O(nm)$、KMP $O(n+m)$；KMP 的 $\text{next}$ 只依赖模式串自身，与主串无关。
- BM 从模式串尾部比较（补充笔记），与 KMP 从头部比较相对。

### 4.5 本章速查表

| 算法 | 是否回溯主串 | 预处理 | 时间复杂度 | 空间 |
|---|---|---|---|---|
| 朴素模式匹配 | 是 | 无 | $O(nm)$ | $O(1)$ |
| KMP | 否 | $\text{next}$ 数组 $O(m)$ | $O(n+m)$ | $O(m)$ |
| BM | 从模式串尾部比较 | 坏字符/好后缀 | —（素材未给数值） | — |

- $\text{next}[1]=0$，$\text{next}[j]=$ $T[1..j-1]$ 最长相等前后缀长度 $+1$（1 起）；0 起则 $\text{next}[0]=-1$。
- 失配：$i$ 不动，$j=\text{next}[j]$；$j>m$ 匹配成功；nextval 对 $T[j]=T[\text{next}[j]]$ 情形二次回退。

## 第5章 树与二叉树（性质、存储、遍历、线索二叉树、树森林转换、并查集）

### 5.1 知识体系

**5.1.1 树的基本术语**

树是 $n\ (n\ge0)$ 个结点的有限集合（递归定义的结构，$n=0$ 为空树）。任意非空树中有且仅有一个根结点；从根到每个结点有且只有 1 条路径。术语：**结点的度**（子结点个数）、**树的度**（所有结点度的最大值）、叶子（度为 0）、分支结点（度 $>0$）、孩子/双亲/兄弟/祖先/子孙、**层次**（根为第 1 层）、**深度/高度**（最大层数）、有序树/无序树、森林（$m$ 棵互不相交树的集合）。

树中结点计数通式（补充笔记与 2010 真题解析）：设度为 $i$ 的结点数为 $N_i$，则

$$N=\sum_i N_i,\qquad N-1=\sum_i i\cdot N_i \quad\Longrightarrow\quad N_0=1+\sum_{i\ge 2}(i-1)N_i$$

**5.1.2 二叉树的定义与特殊形态**

二叉树是每个结点**至多两棵子树**且**左右有序**（区分左右）的树。五种基本形态：空树、仅根、根+左、根+右、根+左右。特殊形态：

- **满二叉树**：深度 $k$ 且有 $2^k-1$ 个结点，每层都填满；
- **完全二叉树**：除最后一层外均填满，最后一层结点**连续集中在左侧**；叶结点只可能在最下两层；
- **二叉排序树 BST**、**平衡二叉树 AVL**（详见第 7 章）。

**5.1.3 二叉树的重要性质**（补充笔记 + 知识点卡片，公式须精确）

1. 第 $i$ 层最多有 $2^{i-1}$ 个结点（根为第 1 层）。
2. 深度为 $k$ 的二叉树最少有 $k$ 个结点、最多有 $2^k-1$ 个结点。
3. 对任意非空二叉树，叶结点数 $n_0$ 与度为 2 的结点数 $n_2$ 满足：

$$n_0=n_2+1$$

   **推导**：$n=n_0+n_1+n_2$；又「边数 = $n-1$」，而边数也等于 $n_1+2n_2$，故 $n=n_1+2n_2+1$。两式相减即得 $n_0=n_2+1$。
4. 具有 $n$ 个结点的**完全二叉树**深度：

$$\lceil \log_2(n+1)\rceil \quad\text{或}\quad \lfloor\log_2 n\rfloor +1$$

5. **Catalan 数**：$n$ 个结点能构成的不同二叉树个数 $=C_n=\dfrac{1}{n+1}\dbinom{2n}{n}$，也等于 $n$ 个元素的进出栈序列数、不同二叉搜索树个数。

**5.1.4 完全二叉树的编号关系**（两套体系，务必先确认起始编号）

编号 $1\sim n$（数组建议从 1 开始存）：

$$i=1 \text{ 为根};\quad i>1:\ \text{父}=\lfloor i/2\rfloor;\quad 2i\le n:\ \text{左孩子}=2i;\quad 2i+1\le n:\ \text{右孩子}=2i+1$$

若 $i$ 为奇数且 $\ne 1$ 则处于**右兄弟**位置，若 $i$ 为偶数则处于**左兄弟**位置。

编号 $0\sim n-1$：

$$i=0 \text{ 为根};\quad i>0:\ \text{父}=\lfloor (i-1)/2\rfloor;\quad 2i+1\le n-1:\ \text{左}=2i+1;\quad 2i+2\le n-1:\ \text{右}=2i+2$$

补充笔记给出整数技巧：对 `unsigned int u`，$\lfloor u/2\rfloor=u/2$，$\lceil u/2\rceil=(u+1)/2$，且 $\lceil u/2\rceil\ne u/2+1$；$\lceil\log_2(u+1)\rceil$ 等于 $u$ 二进制最高非 0 位的位数（如 $8=(1000)_2$ 得 $\lceil\log_2 9\rceil=4$），可连续左移实现。搞不清关系时「画一棵简单二叉树代入比较」。

**5.1.5 二叉树的存储**

- **顺序存储**：仅适合完全二叉树（按层序存入一维数组，建议从 1 编号以便利用上述关系）；一般二叉树需补空位按完全二叉树存储，浪费空间。
- **二叉链表**：结点 `lchild / data / rchild`，$n$ 个结点有 $2n$ 个指针域，其中 $n-1$ 个指向孩子，故**空指针数 $=2n-(n-1)=n+1$**。
- **三叉链表**：增加 `parent` 父指针，便于找双亲；二叉/三叉链表都可用静态链表实现；亦可用仅有父指针的静态链表存树。

**5.1.6 二叉树的遍历**

- **先序 VLR**（根→左→右）、**中序 LVR**（左→根→右）、**后序 LRV**（左→右→根）：递归实现差别仅在 `visit` 的位置；用途：先序（复制树、判相等、广义表打印）、后序（结点计数、求高度）。
- **非递归**：需**栈**实现显式递归；后序还需辅助标识（或双栈）区分是从左子树还是右子树返回。
- **由遍历序列确定二叉树**：**前序 + 中序**、**后序 + 中序**可唯一确定；**仅前序 + 后序不能**唯一确定（但能确定祖先关系：前序为 $XY$、后序为 $YX$ 时 $X$ 是 $Y$ 的祖先）。
- **层序遍历**：借助**队列**，访问某层时把下一层孩子入队。

**5.1.7 线索二叉树**

利用二叉链表中 $n+1$ 个空指针指向遍历序列中的**前驱/后继**，称线索；每个结点增设 `ltag / rtag` 标志域区分「指针指向孩子」还是「线索」。按遍历方式分**前序 / 中序 / 后序线索二叉树**，同一棵树线索化结果依赖遍历序列。中序线索最常用，可在其上实现前序/后序遍历。线索化的关键是维护 `pre` 指针指向刚访问过的结点。

**5.1.8 树与森林的存储、转换与遍历**

- 树的存储：① 广义表（链表）；② **双亲表示法**（父指针，找双亲 $O(1)$，1:N）；③ **孩子链表**；④ **孩子-兄弟链表（长子-兄弟链表）**：`firstChild` 指第一个孩子，`nextSibling` 把同一双亲的孩子串成链，是一种二叉树表示法。
- **树 → 二叉树**（连线-剪枝）：把各兄弟结点连起来，剪断除长子外其它孩子与双亲的边。所得二叉树**根结点一定没有右子树**；原长子在左子树，其兄弟成为右子树上的结点（左孩子右兄弟）。
- **森林 → 二叉树**：各树先转二叉树，再把后一棵树的根依次连到前一棵树根的**右孩子**上。
- 遍历对应：树的**先根**遍历 $\leftrightarrow$ 二叉树的**先序**；树的**后根**遍历 $\leftrightarrow$ 二叉树的**中序**；森林同理，另有广度优先（层次）遍历。

**5.1.9 并查集（Union-Find / Disjoint Set）**

用**父指针树（静态链表）**表示元素与所属子集，支持 `Union`、`Find`。**等价关系**三性质：自反性、对称性、传递性；由等价关系把集合划分为互不相交的**等价类**：初始每元素自成一类，每处理等价对 $i\equiv j$ 先 `Find` 判断，若属不同集合则 `Union`。

优化一：**小集合并入大集合**（按大小/秩合并），防树退化；优化二：**路径压缩**（`Find` 时把沿途结点直接挂到根）。二者结合后近似 $O(\alpha(n))$，几乎常数。应用：Kruskal 判环（见第 6 章）。

**5.1.10 堆（优先级队列的实现）与 Huffman 树**

- **堆**是完全二叉树、用数组顺序存储；**最小堆**：任一结点 $\le$ 左右孩子（堆顶最小），**最大堆**反之；堆递归定义，每棵子树也是堆；**左右孩子之间无确定大小关系**（与 BST 不同）。
- 核心操作：**下滑 siftDown**（父大于最小孩子则交换，逐层向下）、**上滑 siftUp**（结点小于父则交换，逐层向上）。
- **建堆**：从最后一个非叶结点（0 起编号 $\lfloor (n-2)/2\rfloor$，或 1 起 $\lfloor n/2\rfloor$）向前对所有非叶结点逐个 `siftDown`；补充笔记给「时间复杂度均为 $O(n\log_2 n)$」，王道 PPT 堆排序分析中把建堆记为 $O(n)$（见第 8 章，**两种数量级表述均在素材中出现，须按题目语境选用**）。
- **插入**：放末尾再 `siftUp`，$O(\log_2 n)$；**删除**：总是删堆顶，末尾元素移到堆顶再 `siftDown`，$O(\log_2 n)$。
- **带权路径长度** $\text{WPL}=\sum_k w_k \times l_k$（叶结点权值 $\times$ 根到叶路径长度）。**Huffman 树（最优二叉树）**是 WPL 最小的树：每次取权值最小的两个结点作左右子树，根为二者权值之和，重复至只剩一棵树（可用最小堆辅助）。性质：Huffman 树**不唯一但 WPL 唯一**；**没有度为 1 的结点**，只有度 0 和度 2；$n$ 个叶结点共有 $2n-1$ 个结点；Huffman 编码一定是**前缀编码**；对应**最优判定树**。

### 5.2 核心考点详解

**① $n_0=n_2+1$ 的灵活运用。** 由 $n=n_0+n_1+n_2$ 与 $n=n_1+2n_2+1$ 联立。常与完全二叉树结合：$n$ 个结点的完全二叉树，$n_1$ 只能为 0 或 1，故 $n_0=\lceil n/2\rceil$（2011 年第 4 题：768 个结点 → 叶结点 $=768-384=384$；知识点卡片亦给出「最后一个分支结点序号 $\lfloor n/2\rfloor$」）。

**② 完全二叉树结点数的极值。** 2009 年第 5 题：完全二叉树第 6 层有 8 个叶结点，求结点个数最多值。第 6 层有叶则树高可 6 或 7，树高 7 结点更多；前 6 层为满二叉树 $2^6-1=63$，第 7 层因第 6 层 8 个叶而缺失 $8\times2=16$ 个叶，故最多 $2^7-1-16=111$。

**③ 由遍历序列定树 / 定祖先关系。** 前序 + 后序不能唯一确定树，但可判断祖先关系（2012 年第 3 题：前序 `a,e,b,d,c`、后序 `b,c,d,e,a` → 根的孩子只有 `e`）。2011 年第 5 题：前序 `1,2,3,4`、后序 `4,3,2,1`（互为逆序）⇒ 每个结点至多一个孩子 ⇒ 中序序列中根只能在首或尾，据此排除不可能的中序。

**④ 树 ↔ 二叉树转换的「左孩子右兄弟」。** 2009 年第 6 题：森林转二叉树后 $u$ 是 $v$ 的父结点的父结点，问原森林中 $u,v$ 可能的关系（答案：父子或兄弟）。2011 年第 6 题：2011 个结点、116 个叶的树转二叉树后**无右孩子的结点数** = 分支结点数 $+1=2011-116+1=1896$（每个分支结点最右孩子无右孩子，根转换后也无右孩子）。

**⑤ 线索二叉树的空指针数 $=n+1$**，标志域 `ltag/rtag`；2010 年第 3 题考后序线索树判断（据后序序列前驱/后继填线索）。

**⑥ 堆的插入/删除调整与比较次数。** 2009 年第 9 题：小根堆插入 3 后的序列（上滑）；2011 年第 11 题：大根堆 `{25,13,10,12,9}` 尾部插入 18，调整过程**比较 2 次**（18 与 10 交换，再与 25 不换）。注意「先放末尾、再上滑」与「删堆顶、末位顶替再下滑」的方向区别。

**⑦ Huffman 树性质。** 2010 年第 6 题：$n$ 个互异权值构造 Huffman 树，错误的是「该树一定是完全二叉树」（Huffman 树形态不唯一、不一定完全，但无度为 1 结点、两最小权值结点必为兄弟）。

**⑧ 并查集优化。** 按秩合并 + 路径压缩后 `Find/Union` 近似 $O(\alpha(n))$；2027 王道八套卷考过「按秩合并与路径压缩后并查集形态/最大深度」。等价关系三性质是等价类划分的判定依据。

### 5.3 典型算法/代码

```c
/* 二叉链表结构（重要算法整理） */
typedef struct BiTNode { ElemType data; struct BiTNode *lchild, *rchild; } BiTNode, *BiTree;

/* 递归三遍历（差别仅在 visit 的位置） */
void PreOrder(BiTree T){ if(T){ visit(T);  PreOrder(T->lchild);  PreOrder(T->rchild);} }
void InOrder (BiTree T){ if(T){ InOrder(T->lchild);  visit(T);  InOrder(T->rchild);} }
void PostOrder(BiTree T){ if(T){ PostOrder(T->lchild); PostOrder(T->rchild); visit(T);} }

/* 先序非递归：借助栈，走到最左并沿途访问，空则出栈转向右子树 */
void PreOrder2(BiTree T){
    InitStack(S); BiTree p = T;
    while (p || !IsEmpty(S)){
        if (p){ visit(p); Push(S,p); p = p->lchild; }
        else  { Pop(S,p); p = p->rchild; }
    }
}
/* 中序非递归：先入栈走到最左，出栈时访问再转向右子树 */
void InOrder2(BiTree T){
    InitStack(S); BiTree p = T;
    while (p || !IsEmpty(S)){
        if (p){ Push(S,p); p = p->lchild; }
        else  { Pop(S,p); visit(p); p = p->rchild; }
    }
}
/* 后序非递归：用 r 记录最近访问结点，判断右子树是否已访问 */
void PostOrder2(BiTree T){
    InitStack(S); BiTree p = T, r = NULL;
    while (p || !IsEmpty(S)){
        if (p){ Push(S,p); p = p->lchild; }
        else {
            GetTop(S,p);
            if (p->rchild && p->rchild != r){ p = p->rchild; Push(S,p); p = p->lchild; }
            else { Pop(S,p); visit(p); r = p; p = NULL; }
        }
    }
}
/* 层序遍历：借助队列 */
void LevelOrder(BiTree T){
    InitQueue(Q); EnQueue(Q,T);
    while (!IsEmpty(Q)){
        DeQueue(Q,p); visit(p);
        if (p->lchild) EnQueue(Q,p->lchild);
        if (p->rchild) EnQueue(Q,p->rchild);
    }
}

/* 中序线索化（重要算法整理 P118） */
typedef struct ThreadNode { ElemType data; struct ThreadNode *lchild,*rchild; int ltag,rtag; } ThreadNode,*ThreadTree;
void InThread(ThreadTree &p, ThreadTree &pre){
    if (p){
        InThread(p->lchild, pre);
        if (!p->lchild){ p->lchild = pre; p->ltag = 1; }        /* 建前驱线索 */
        if (pre && !pre->rchild){ pre->rchild = p; pre->rtag = 1; } /* 建后继线索 */
        pre = p;
        InThread(p->rchild, pre);
    }
}

/* 并查集：路径压缩 Find + 按大小合并 Union */
int Find(int S[], int x){
    int root = x;
    while (S[root] >= 0) root = S[root];
    while (x != root){ int t = S[x]; S[x] = root; x = t; }   /* 路径压缩 */
    return root;
}
void Union(int S[], int r1, int r2){                          /* 小树并入大树 */
    if (S[r1] > S[r2]) { S[r1] += S[r2]; S[r2] = r1; }         /* S[root] 存 -结点数 */
    else               { S[r2] += S[r1]; S[r1] = r2; }
}

/* 建堆：从最后非叶结点向前 siftDown；插入末尾 siftUp；删堆顶末位顶替 siftDown */
void BuildMaxHeap(ElemType A[], int len){
    for (int i = len/2; i > 0; i--) AdjustDown(A, i, len);
}
```

## 第6章 图（存储、遍历、最小生成树、最短路径、拓扑排序、关键路径）

### 6.1 知识体系

**6.1.1 图的基本概念**

图 $G=(V,E)$ 由顶点集 $V$ 与边集 $E$ 构成。素材约定**：不考虑顶点自环，也不考虑任意两顶点间的多重边**。

- **有向图 / 无向图**；**完全图**边数：

$$\text{无向完全图}: \frac{n(n-1)}{2} \qquad\qquad \text{有向完全图}: n(n-1)$$

- **度 / 入度 / 出度**：无向图所有顶点度之和 $=2e$（必为偶数）；有向图总入度 = 总出度 $=e$。
- **路径、回路/环、简单路径**（顶点不重复）、简单回路、路径长度、点到点的距离；**连通图 / 连通分量**（无向，极大连通子图）；**强连通图 / 强连通分量**（有向，任意两点互有正反路径）；**生成树**：无向连通图的极小连通子图，含 $n$ 个顶点、恰 $n-1$ 条边、无回路。

**6.1.2 图的存储结构**（不同结构适合不同算法）

| 存储 | 结构 | 空间 | 特点 |
|---|---|---|---|
| **邻接矩阵** | $n\times n$ 二维数组 `A[i][j]` | $O(n^2)$ | 无向图为**对称阵**；适合稠密图；建图 $O(n^2)$ |
| **邻接表** | 顶点表 + 每个顶点的边链表 | 无向 $O(n+2e)$、有向 $O(n+e)$ | 无向图每条边存 2 次、有向 1 次；适合稀疏图；有向图可设出边表/入边表（逆邻接表） |
| **邻接多重表** | 每边一个结点，5 域 `Mark, Vertex1, Vertex2, Path1, Path2` | $O(n+e)$ | 每条边只处理一次，适合**以边为处理对象**的无向图算法 |
| **十字链表** | 有向图，结合邻接表与逆邻接表 | $O(n+e)$ | 便于同时找入边/出边 |

邻接矩阵第 $i$ 行（列）非零元个数 = 顶点 $i$ 的度/出度/入度；带权图用权值代替 1、$\infty$ 表示无边。

**6.1.3 图的遍历**

- **深度优先搜索 DFS**：递归算法——访问本结点，再对未访问的各邻接点 DFS；需 `visited[]` 标记处理回路；借助**递归工作栈**，空间 $O(|V|)$。
- **广度优先搜索 BFS**：非递归、按层访问——出队并访问、把其未访问邻接点入队，直到队空；借助**队列**。
- 复杂度（王道 PPT / 2012 真题解析）：

$$\text{邻接表}: O(|V|+|E|)\qquad\qquad \text{邻接矩阵}: O(|V|^2)$$

- 非连通图需对每个 `visited[i]==false` 的顶点发起一次遍历（对每个连通分量各调一次）；BFS 还可求**非带权图的单源最短路径**（按距离由近到远遍历）。生成树/生成森林由遍历经过的边构成。

**6.1.4 最小生成树 MST**

连通带权图的生成树中边权之和最小的生成树，必含 $n-1$ 条边且不构成回路；**MST 可能不唯一（存在相同权值时），但代价（权值之和）唯一**。两种算法都属于**贪心**：

- **Kruskal**：初始只有顶点无边，按权值递增取边，若该边两端点不在同一连通分量（用**并查集 Find** 判断）则加入并 **Union**；直到加入 $n-1$ 条边。用**最小堆**找最小权边。复杂度 $O(e\log_2 e)$，**适合稀疏图**（复杂度取决于边数）。
- **Prim**：把顶点分成已在 MST 的 $V_{\text{mst}}$ 与剩余的 $V-V_{\text{mst}}$（一个**割**），每次选连接两集合的最小权**桥**，把该桥在 $V-V_{\text{mst}}$ 的端点移入，重复至顶点数为 $n$。可用最小堆辅助（每加一顶点把相关边插入堆）。复杂度 $O(n^2)$，**适合稠密图**（复杂度只与顶点数有关）。

**6.1.5 最短路径**

- **Dijkstra**（非负权单源最短路径）：设集合 $S$ 记录已求得最短路径的顶点，辅助数组 `dist[]`（源点到各点当前最短长度，初值 `arcs[v0][i]`）、`path[]`（最短路径上的前驱）。每轮：从 $V-S$ 选 `dist` 最小的顶点 $u$ 加入 $S$，再对 $V-S$ 中每个顶点 $k$ **松弛**：

$$\text{dist}[k]=\min\big(\text{dist}[k],\ \text{dist}[u]+\text{weight}(u,k)\big)$$

  从终点依 `path[]` 回溯逆序输出完整路径。王道 PPT 给出双重循环实现，**时间复杂度 $O(n^2)$**；**不能处理负权边**（可用 Bellman-Ford）。
- **Floyd**（任意两点间最短路径，各边权可正）：动态规划，图用邻接矩阵，$A^{(k)}[i][j]$ 表示「可借助编号 $0..k$ 的顶点作中间点」时 $i\to j$ 的最短长度：

$$A^{(k)}[i][j]=\min\Big(A^{(k-1)}[i][j],\ \min_{0\le r\le n-1}\big(A^{(k-1)}[i][r]+A^{(k-1)}[r][j]\big)\Big)$$

  注意 **$k$（中间点）在最外层循环**；另用 `Path[][]` 记录使上式取最小的中间点 $r$ 用于回溯。$A^{(-1)}[i][j]=\text{weight}(i,j)$。**三重循环，时间复杂度 $O(n^3)$**。

**6.1.6 拓扑排序（AOV 网）**

AOV 网用顶点表示活动、有向边表示前驱/后继关系，是**有向无环图 DAG**。拓扑排序把顶点排成线性序列使所有前驱/后继关系得到满足。算法（王道 PPT / 补充笔记）：

1. 计算各顶点**入度**；
2. 选入度为 0 的顶点输出；
3. 删除该顶点及它发出的所有边（后继入度减 1），把新产生的入度为 0 顶点压入**栈**（或队列）保存；
4. 弹栈重复，直到没有入度为 0 的点。若输出顶点数 $<n$，则图中**存在有向环**。

拓扑序列**不唯一**；用邻接表存储便于删边，**时间复杂度 $O(|V|+|E|)$**。**拓扑逆序**：每次删除**出度为 0** 的顶点及指向它的边。若邻接矩阵主对角线以下（或以上）元素全为 0，则图无环、必存在拓扑序列（可能不唯一）。

**6.1.7 关键路径（AOE 网）**

AOE 网用**边表示活动**、边权为活动持续时间，顶点表示事件；只有一个入度为 0 的**源点** $V_0$、一个出度为 0 的**汇点** $V_{n-1}$。从源点到汇点的**最大长度路径 = 关键路径**，其长度是完成整个项目的**最短时间**。

- 事件 $V_i$ 的**最早发生时间** $V_{\text{Early}}[i]$（拓扑序正向递推）：

$$V_{\text{Early}}[0]=0,\qquad V_{\text{Early}}[i]=\max_{V_k\in \text{pred}(i)}\big(V_{\text{Early}}[k]+\text{duration}(k,i)\big)$$

  $V_{\text{Early}}[n-1]$ 即总工期。
- 事件 $V_i$ 的**最迟发生时间** $V_{\text{Last}}[i]$（拓扑逆序反向递推）：

$$V_{\text{Last}}[n-1]=V_{\text{Early}}[n-1],\qquad V_{\text{Last}}[i]=\min_{V_j\in \text{succ}(i)}\big(V_{\text{Last}}[j]-\text{duration}(i,j)\big)$$

- 活动 $A_i$（边 $V_i\to V_j$）的最早/最迟开始时间：

$$E[i]=V_{\text{Early}}[i],\qquad L[i]=V_{\text{Last}}[j]-\text{duration}(i,j)$$

- **松弛时间（时间余量）** $=L[i]-E[i]$；松弛为 0 的活动即**关键活动**，全部关键活动构成关键路径（可能多条）。缩短关键活动工期才能缩短总工期。

### 6.2 核心考点详解

**① 存储结构决定遍历与算法复杂度。** 邻接表 DFS/BFS 为 $O(|V|+|E|)$（2012 年第 5 题），邻接矩阵为 $O(|V|^2)$；拓扑排序用邻接表 $O(|V|+|E|)$（2016 年真题）。稀疏图用邻接矩阵浪费空间（2011 年第 8 题）。邻接多重表每边只存一次，适合「以边为处理对象」的算法。

**② Dijkstra 的贪心本质与陷阱。** 2009 年第 41 题给出「每次选离当前顶点最近的未加入顶点」的局部贪心法，问能否求最短路径——**不能**，须举反例说明「局部最优不等于全局最优」。Dijkstra 每轮加入的是「当前 `dist` 最小」的点并松弛其邻接点，且**边权非负**才保证正确。2012 年第 7 题考 Dijkstra 各轮得到最短路径的目标顶点顺序。

**③ MST 的性质辨析。** 2012 年第 8 题：MST 代价唯一（Ⅰ 对）；权值最小的边不一定出现在所有 MST 中（若多条最小权边成环，Ⅱ 错）；Prim 从不同顶点出发所得 MST 不一定相同（Ⅲ 错）；Prim 与 Kruskal 所得 MST 也不总不同（权值互异时 MST 唯一，二者相同，Ⅳ 错）。

**④ 拓扑序列计数与判环。** 2010 年第 8 题：给定 DAG 的**不同拓扑序列个数 = 3**（`abced、abecd、aebcd`）。2012 年第 6 题：邻接矩阵主对角线以下元素全为 0 ⇒ 图无环、拓扑序列**存在且可能不唯一**。2011 年第 8 题：「存在拓扑序列则图不存在回路」（Ⅲ 正确）。

**⑤ 关键路径的计算方向。** $V_{\text{Early}}$ 正向拓扑序取 $\max$，$V_{\text{Last}}$ 反向拓扑逆序取 $\min$，方向/取 max-min 一一对应（补充笔记与知识点卡片反复强调）。2011 年第 41 题：由上三角压缩存储的邻接矩阵还原图并求关键路径 $0\to1\to2\to3\to5$、长度 $4+5+4+3=16$；2025 年真题再考关键路径完整过程。

**⑥ 并查集在 Kruskal 中的角色。** 用 `Find` 判断边两端点是否同属一个连通分量（同则成环、丢弃），用 `Union` 合并两个分量；结合最小堆按权取边。

- **2016 年**：拓扑排序邻接表时间复杂度 $O(|V|+|E|)$；**B+ 树以外**（见第 7 章）此处不展开。**2025 年**：关键路径全过程。
- Dijkstra **不能处理负权边**；Floyd 三重循环 $k$ 在最外层，且 Floyd 可处理带负权边（但不能有负权回路，素材未展开）。
- MST 不唯一但代价唯一；Prim 看顶点数 $O(n^2)$、Kruskal 看边数 $O(e\log e)$，适用稠密/稀疏恰相反。
- 拓扑序列不唯一；输出顶点数 $<n$ 即有环；拓扑逆序删的是出度 0 的顶点。
- 关键路径是**最长**路径（不是最短），却是完成项目的**最短时间**；$V_{\text{Early}}$ 取 $\max$、$V_{\text{Last}}$ 取 $\min$，方向不可颠倒。

## 第7章 查找（顺序 / 折半 / 分块、BST、AVL、红黑树、B 树 / B+ 树、散列表）

### 7.1 知识体系

**7.1.1 查找的基本概念与 ASL**

查找表由**记录（数据元素）**组成，记录含**关键字 key**（查找时比较的对象）及其它信息。查找分**静态查找结构**（查找中不插入/删除）与**动态查找结构**（插入/删除后需调整结构、结构可能变化，如 BST、AVL、B 树）。衡量效率用**平均查找长度 ASL**（或外部搜索的磁盘 I/O 次数）：

$$\text{ASL}=\sum_{i=1}^{n} p_i\,c_i$$

其中 $p_i$ 为查找第 $i$ 个元素的概率（等概率时 $p_i=1/n$）、$c_i$ 为找到该元素所需的关键字比较次数。ASL 分**查找成功**与**查找失败**两种，分母与比较次数不同（王道 PPT：查找有成功/失败两种情况，故 ASL 也分两种）。素材折半判定树示例（8 个关键字、9 个失败区间）：$\text{ASL}_{\text{成功}}=(1+2+2+3+3+3+3+4)/8=21/8$，$\text{ASL}_{\text{失败}}=(3+3+3+3+3+3+3+4+4)/9=29/9$。

**7.1.2 顺序查找（线性查找）**

从表的一端顺序扫描，逐个比较关键字；可设「哨兵」`a[0]=key` 从后往前找以省去越界判断。$O(n)$。等概率下：$\text{ASL}_{\text{成功}}=\dfrac{n+1}{2}$，$\text{ASL}_{\text{失败}}=n+1$。适用于顺序表或链表、对有序性无要求。

**7.1.3 折半查找（二分查找）**

**仅适用于有序的顺序表**（链表无法折半）。取中点比较：

$$\text{mid}=\text{low}+\frac{\text{high}-\text{low}}{2}\quad\left(=\lfloor(\text{low}+\text{high})/2\rfloor\right)$$

（写成 `low+(high-low)/2` 是为了**防止 `low+high` 直接相加溢出**；素材明确「相加可能溢出」）。相等则成功，$\text{key}<A[\text{mid}]$ 则 `high=mid-1`，否则 `low=mid+1`，直到 `low>high` 失败。

- **判定树**：把折半过程画成二叉树，树中**结点表示查找成功**，**外部结点（空区间）表示查找不成功**；某元素比较次数 = 根到该结点的路径结点数。
- 具有 $N$ 个结点的判定树高度 $=\lceil\log_2(N+1)\rceil=\lfloor\log_2 N\rfloor+1$，故**时间复杂度 $O(\log_2 n)$**；等概率下 $\text{ASL}_{\text{成功}}\approx \log_2(n+1)-1$。
- 折半查找 `mid` 向下取整，判定树**一定是平衡二叉树且是二叉排序树**；「不能构成折半查找比较序列/判定树」是选择题高频（2015、2017 真题）。

**7.1.4 分块查找（索引顺序查找）**

把长为 $n$ 的表均分为 $b$ 块、每块 $s$ 个记录（$n=b\times s$），「**块内可无序、块间有序**」：$\max\{\text{第 }i\text{ 块}\}<\min\{\text{第 }i+1\text{ 块}\}$。另建**索引表**（每项存该块最大关键字、块首下标、块长），索引表按关键字有序。

查找两步：① 确定待查值在哪一块（块间可折半/顺序）；② 在块内顺序查找。因为进行两次查找，**总 ASL 为两次 ASL 之和**：

$$\text{ASL}_{\text{分块}}=\text{ASL}_{\text{块间}}+\text{ASL}_{\text{块内}}$$

设等概率、块间折半块内顺序：$\text{ASL}_{\text{分块}}\approx \lceil\log_2(b+1)\rceil-1+\dfrac{s+1}{2}$；块间与块内都顺序时 $\text{ASL}_{\text{分块}}=\dfrac{b+1}{2}+\dfrac{s+1}{2}$（当 $b=s=\sqrt n$ 时约 $\sqrt n+1$）。

**7.1.5 二叉排序树 BST**

递归定义：左子树（非空）所有结点 $\;<$ 根 $\;<$ 右子树（非空）所有结点，且左右子树也是 BST（「左小右大」）。**中序遍历结果从小到大有序**；$\text{ASL}\le$ 树的高度。

- 查找：沿搜索路径比较，平均 $O(\log_2 n)$，最坏（退化成单链表）$O(n)$。
- 插入：先查找，已存在则不插入，否则插到搜索停止处的左/右孩子。
- 删除三种情况：① 叶结点直接删；② 仅有左/右子树，用该子树顶替；③ 兼有左右子树，用**右子树中 key 最小的结点（中序后继）**或左子树最大结点填补，是递归过程。
- 不同 key 有不同查找概率时，ASL 最小的 BST 称**最优二叉排序树**。

**7.1.6 平衡二叉树 AVL**

高度平衡的二叉搜索树：任一结点**左右子树高度之差（平衡因子 = 左高 − 右高）绝对值 $\le 1$**，即取 $-1,0,1$。插入/删除失衡后通过**旋转**恢复，四种失衡形态对应四种旋转：

$$LL\to\text{右单旋}\qquad RR\to\text{左单旋}\qquad LR\to\text{先左后右双旋}\qquad RL\to\text{先右后左双旋}$$

高度 $O(\log_2 n)$。判断旋转类型看「失衡结点到新插入结点路径的前两步方向」。素材给出「所有非叶结点平衡因子均为 1」的最少结点递推：$C_N=C_{N-1}+C_{N-2}+1,\ C_2=2,\ C_3=4\Rightarrow C_6=20$（2012 年第 4 题）。

**7.1.7 红黑树与伸展树**

**红黑树**性质（补充笔记）：① 根结点和所有**外部结点（虚构的空叶结点 NIL）**为黑色；② 从根到外部结点的途中**没有连续两个红色结点**；③ 所有从根到外部结点的路径上**黑色结点数目相同（黑高相同）**。由此「最长路径 $\le$ 最短路径的 2 倍」，维持近似平衡；树高 $\le 2\log_2(n+1)$，查找/插入/删除 $O(\log_2 n)$。**伸展树**：查找/插入后把目标结点旋转（伸展）到根，摊还 $O(\log_2 n)$。

**7.1.8 B 树与 B+ 树**（补充笔记极详尽，为 408 重点）

**m 阶 B 树**（$m>2$，最少 3 叉）是一棵平衡的 $m$ 路搜索树，可为空；非空 B 树性质：

1. 根结点至少 2 棵子树；**其它内部结点子树数 $\in[\lceil m/2\rceil,\ m]$**；
2. 结点内 **key 数 = 子树数 − 1**，`key[1..n]` 正序排列；$i$ 号子树的 key 落在 `key[i]` 与 `key[i+1]` 之间；
3. **所有叶结点（失败结点，即 NULL 子树）都在同一层**，不含信息。

插入总是发生在**最底层的叶结点**：若插入后 key 数超过 $m-1$ 则**分裂**——取中间 key `key[⌈m/2⌉]` 上移到父结点，当前结点分成左、右两部分；父结点也可能因 key 超量连锁分裂，最坏整棵树**增加一层**。删除后若结点 key 数 $< \lceil m/2\rceil-1$ 则处理：兄弟够借则从兄弟借（经父结点中转，父 key 下移、兄弟 key 上移）；兄弟都不够借则与兄弟合并并从父结点取一个 key 参与合并，父结点减少 key 可能连锁向上，最坏整棵树**减少一层**；若被删 key 在非叶结点，先用其相邻 key（右子树最小或左子树最大）逐层交换到叶结点再删。

**B+ 树**是 B 树的变形：

1. **所有 key 都在叶结点层**，从小到大排列，且各叶结点组成**有序链表**；
2. 内部结点只存对应子树中最大（或最小）的 key 作索引，不存记录地址，**结点比 B 树小很多**；内部结点 **key 数 = 子树数**（与 B 树的「key 数 = 子树数 − 1」不同）；
3. 子树数限制同 B 树（根 $\ge2$，其它 $\lceil m/2\rceil\sim m$）；
4. 除根指针外还有指向最小 key 叶结点的链表头指针；**不论是否在内部结点命中，查找都要走到叶结点**，也可从叶结点链表顺序遍历，适合**范围查询与文件索引**。

**7.1.9 散列表（Hash）**

把 key 通过**散列函数**直接映射到存储地址。散列函数要求：定义域包含全部可能 key、地址均匀分布、算法简单高效。常用构造：**除留余数法** $H(\text{key})=\text{key}\bmod p$（$p$ 为不大于表长 $m$ 的**质数**，最常用）；另有数字分析法、平方取中法、折叠法（移位/分界）。

**处理冲突**：

- **闭散列（开放定址）**：冲突后占用其它码位：
  - **线性探查**：$(H+i)\bmod \text{size}$，即 $H+1,H+2,\dots$；
  - **二次探查**：$(H+i^2)\bmod\text{size}$ 与 $(H-i^2)\bmod\text{size}$，即 $H+1,H-1,H+4,H-4,\dots$；
  - **双散列**：采用两种不同的散列函数。
  - 闭散列**不能直接删除元素**，只能打「已删除」标记（惰性删除）或移动后续受影响元素，不适合频繁变动。
- **开散列（链地址 / 拉链法）**：用链表（桶）保存同义词，桶内顺序查找。

**装填因子**：

$$\alpha=\frac{\text{表中记录数 }n}{\text{散列表长度 }m}$$

$\alpha$ 表明发生冲突的可能性，不应过大。散列表查找效率取决于**散列函数、冲突处理方法、装填因子**三者。素材给出 ASL 计算范例（2010 年第 41 题）：$H(\text{key})=(\text{key}\times3)\bmod 7$，$\alpha=0.7\Rightarrow m=10$，线性探测，$\text{ASL}_{\text{成功}}=(1+2+1+1+1+3+3)/7=12/7$，$\text{ASL}_{\text{不成功}}=(3+2+1+2+1+5+4)/7=18/7$（分母为**散列函数能映射到的地址个数 7**，而非表长 10）。

**7.1.10 其它**

字典是 $\langle\text{key},\text{value}\rangle$ 集合，基本操作 Find/Insert/Remove；**跳表**在有序链表上增加多级指针，期望 $O(\log_2 n)$；集合可用**位向量**（并 `a|b`、交 `a&b`、差 `a&~b`）或有序链表实现；**可扩充散列**（目录表 + 二叉 Trie 树）、**Trie 树**适合可变长 key 的多级索引。

### 7.2 核心考点详解

**① ASL 的两个分母别弄混。** 查找成功 ASL 分母是「元素个数」，比较次数按各元素查找长度；查找失败 ASL 分母是「散列地址个数 / 失败区间个数」，比较次数按探查到空位/失败结点的长度。2010 年第 41 题特别提示「要防止惯性思维」，失败时只可能在 $0\sim6$ 位置（散列函数 MOD 7）。2010 年第 9 题：长度 16 有序表折半查找不存在元素，最多比较 $\lfloor\log_2 16\rfloor+1=5$ 次。

**② 折半查找的前置条件与判定树。** 仅「有序 + 顺序存储」可用；`mid` 向下取整决定判定树形态；判定树高即最大比较次数 $\lceil\log_2(n+1)\rceil$。2015 年考「不能构成折半查找中关键字比较序列」、2017 年考「可能成为折半查找判定树（不含外部结点）的二叉树」、2023 年考 600 个元素最多比较次数。

**③ BST 查找路径的合法性。** 沿路径比较时，一旦进入某结点的左子树，后续所有 key 必须小于该结点值（反之右子树必须大于）。2011 年第 7 题：`95,22,91,24,94,71` 中查到 91 后转向 24（进入左子树），后面却出现 94（$>91$），故不能构成查找路径。

**④ AVL 的旋转类型判断。** 看失衡结点到新插入结点路径的前两步方向（LL/RR/LR/RL），LR 必须「先左旋子树再右旋根」，顺序不可颠倒；2010 年第 4 题插入 48 后平衡因子变 $-2$，需**先右旋后左旋**（RL 型）。

**⑤ B 树 vs B+ 树是必考对比。** 2009 年第 8 题：「叶结点之间通过指针链接」是 **B+ 树**特点而非 B 树，故不符合 m 阶 B 树定义。B 树 key 数 = 子树数 − 1，B+ 树 key 数 = 子树数；B 树所有 key 分布在各层结点、查找可在内部结点命中即返回，B+ 树必须查到叶结点。2016 年考「B+ 树不同于 B 树的特点」、2017 年考「适合使用 B+ 树的场景」（文件/数据库索引、范围查询）。

**⑥ B 树删除的三种情形。** 2012 年第 9 题：3 阶 B 树删除 78，被删结点 key 数 $=1=\lceil3/2\rceil-1$，左兄弟 key 数 $=2\ge\lceil3/2\rceil$ 属「兄弟够借」——左兄弟最大 key 上移父结点、父结点 key 下移到被删结点，答案最右叶结点 key 为 65。

**⑦ 散列效率三要素。** 2011 年第 9 题：「增大装填因子」错（$\alpha$ 越大冲突概率越大）；「设计冲突少的散列函数」「避免聚集（堆积）」对。装填因子 $\alpha\ge1$ 只可能发生在**链地址法**（开散列）中（2027 王道八套卷）。

**⑧ 红黑树。** 2027 王道八套卷考「红黑树说法正确的」（红黑树也是适度平衡的二叉排序树、黑高概念等），2024/2025 年真题涉及红黑树插入与 AVL 对比；核心记「根/外部结点黑、无连续红、黑高相同」。

### 7.3 典型算法/代码

```c
/* 折半查找（重要算法整理 P237） */
int Binary_Search(SeqList L, ElemType key){
    int low=0, high=L.length-1, mid;
    while(low<=high){
        mid = (low+high)/2;                        /* 或 low+(high-low)/2 防溢出 */
        if(L.elem[mid]==key) return mid;
        else if(L.elem[mid]>key) high=mid-1;
        else low=mid+1;
    }
    return -1;
}
/* 顺序查找（哨兵，王道 PPT）：a[0]=key，从后往前，返回 0 表示失败 */
int Search_Seq(int a[], int n, int key){
    a[0]=key; int i=n;
    while(a[i]!=key) i--;
    return i;
}

/* BST 非递归查找：p 指向被查结点的双亲（供插入/删除用） */
BiTNode *BST_Search(BiTree T, ElemType key, BiTNode *&p){
    p=NULL;
    while(T!=NULL && key!=T->data){ p=T;
        if(key<T->data) T=T->lchild; else T=T->rchild; }
    return T;
}
/* BST 插入（递归）：空则新建根；相等返回 0；小插左、大插右 */
int BST_Insert(BiTree &T, ElemType k){
    if(!T){ T=(BiTree)malloc(sizeof(BiTNode)); T->key=k; T->lchild=T->rchild=NULL; return 1; }
    else if(k==T->key) return 0;
    else if(k<T->key)  return BST_Insert(T->lchild,k);
    else               return BST_Insert(T->rchild,k);
}

/* 散列表构造与 ASL（2010 年第 41 题思路）：
   H(key)=(key*3)%7，alpha=0.7 -> 表长 10（下标 0..9），线性探测 (H+i)%10；
   成功 ASL = 各元素探查次数之和 / 7；失败 ASL = 对地址 0..6 探查到空位次数之和 / 7 */
```

- 折半查找只适用于**有序顺序表**；`mid` 向下取整；判定树是平衡 BST。
- B 树 key 数 = 子树数 − 1，B+ 树 key 数 = 子树数；B+ 树查找必须到叶结点。
- 闭散列删除只能打标记（惰性删除），不能物理删除；$\alpha$ 不应过大；除留余数 $p$ 取质数。

## 第8章 排序（各类排序算法、复杂度与稳定性、外部排序、败者树、置换选择、最佳归并树）

### 8.1 知识体系

**8.1.1 排序的基本概念**

排序是把记录按关键字有序（递增/递减）排列。评价维度：

- **稳定性**：关键字相等的记录排序后**相对次序不变**则称稳定，否则不稳定。稳定性只与算法本身有关。
- **内部排序**（数据全部驻留内存）与**外部排序**（数据量大，需借助外存，多次内存/外存交换）。
- **性能评估**：数据**比较次数**与**移动次数**；时间复杂度、空间复杂度。
- 素材重要结论（补充笔记注 1、注 2 与知识点卡片）：
  - **交换类排序和选择类排序**每轮排序后，已处理元素所在位置**就是最终位置**；**插入排序和归并排序没有这个特点**。
  - **快速排序在序列已有序（正序或逆序）时为最坏情况**，而其它方法一般**正序为最好、逆序为最坏**（反直觉，高频陷阱）。
  - 绝大多数内部排序基于**顺序存储**（数组）；用链表则无需移动元素，也可用静态链表、排完再顺序输出。

**8.1.2 插入排序**

- **直接插入排序**：插入第 $i$ 个元素时，前 $0\sim i-1$ 已有序，从后向前依次比较并后移，找到位置插入。可用 `A[0]` 作**哨兵**暂存并省去越界判断。对**基本有序**的序列高效。时间 $O(n^2)$，最好（已有序）$O(n)$，**稳定**，空间 $O(1)$。
- **折半插入排序**：在寻找插入位置时改用**折半查找**，减少**比较次数**（$O(n\log_2 n)$，与序列初态无关），但**移动次数不变**，故总时间仍 $O(n^2)$，**稳定**，$O(1)$ 空间。
- **希尔排序（缩小增量排序）**：取增量 $\text{gap}$，把相距 $\text{gap}$ 的元素分到同一子序列做直接插入排序，逐步缩小 $\text{gap}$ 直至 1；各增量应**互质**，可取 $\text{gap}=\lfloor\text{gap}/3\rfloor+1$（补充笔记）或 $\text{gap}=n/2,\ n/4,\dots,1$（重要算法整理）。前期 gap 大、子序列短，后期序列已基本有序，都使速度快，**突破 $O(n^2)$**；**不稳定**，空间 $O(1)$。

**8.1.3 交换排序**

- **冒泡排序**：从一端起相邻两元素比较，逆序则交换，每趟把一个最大（或最小）元素「冒」到一端；改进：设 `flag` 标志，某趟无交换则提前结束。$O(n^2)$，带标志最好 $O(n)$，**稳定**，每趟确定一个最终位置。
- **快速排序**（详见 8.2）：分治算法，平均 $O(n\log_2 n)$，最坏 $O(n^2)$，**不稳定**，递归需工作栈 $O(\log_2 n)$。

**8.1.4 选择排序**

- **简单（直接）选择排序**：每趟从无序区选最小元素与无序区第一个交换，$O(n^2)$，**不稳定**（交换可能颠倒相等元素相对次序），每趟确定一个最终位置。
- **锦标赛排序**：利用**胜者树/败者树**，**稳定**，$O(n\log_2 n)$，需 $n-1$ 个辅助空间。
- **堆排序**：把一维数组视为顺序存储的完全二叉树，`siftDown` 建成**大顶堆**，堆顶（0 号/1 号，最大值）与末尾元素交换，再把剩余 $n-1$ 个元素重新调整为堆，重复至堆内只剩 1 个元素。王道 PPT 分析：总时间 = 建堆 $O(n)$ + $(n-1)$ 次向下调整 $O(n\log_2 n)$ = $O(n\log_2 n)$；**不稳定**（如两个 2 的相对位置可能变化），空间 $O(1)$。

**8.1.5 归并排序**

把 $n$ 个元素分成前后两个等长子序列，分别排序后**归并**，递归实现即**二路归并排序**。$O(n\log_2 n)$、**稳定**、需 $O(n)$ 辅助空间。**归并两个长度分别为 $m,n$ 的有序序列，最坏需比较 $m+n-1$ 次**（一序列先耗尽时）。

**8.1.6 分配排序（非比较类）**

- **桶式排序**：按取值区间分桶。分配时元素从桶上面依次进入，收集时从桶下面依次移出。
- **基数排序**：多关键字排序，分**最高位优先 MSD** 与**最低位优先 LSD**（从最低位到最高位，每位作为 key 做一轮分配+收集）；**每轮排序必须使用稳定的算法**，否则破坏前轮结果。设 $d$ 为数字位数、$r$ 为每位数字范围（基数），复杂度 $O\big(d(n+r)\big)$，**稳定**。虽为线性复杂度，但「截取各位 key」的辅助操作耗时较大，多数情况不一定比快排快。

**8.1.7 各类排序复杂度与稳定性汇总**（素材注 1、注 2 + 知识点卡片）

**8.1.8 外部排序**

外排序需多次在内存与外存间交换数据，**决定效率的关键是减少外存 I/O 次数**；多用归并排序，增大**归并路数 $k$** 可减少归并遍数（$\approx\lceil\log_k(\text{初始段数})\rceil$），但路数过多会增大每次内部比较开销、且缓冲区变小又增加 I/O，需综合考虑。

两个**阶段**：① 把文件分段输入内存，用某种内部排序方法排序，得到**初始归并段**写回外存；② 对多个初始归并段多遍归并，最终形成单一归并段。

**置换-选择排序**（生成初始归并段）：工作区满后（初始从输入缓冲区复制数据），把工作区调整为**败者树**，选最小元素输出到当前归并段（输出缓冲区），再从输入缓冲区取新元素；若新元素**比当前归并段最后一个（最大者，动态「门槛」）小**，则不能进入当前段，放到工作区固定位置留待下一归并段、工作区名义容量减 1，否则插入败者树继续选大于门槛的最小者。重复至新输入元素都不能加入（名义容量为 0），完成当前段并恢复容量、开始下一段。相比常规方法「每段大小 = 工作区容量」，置换-选择生成的段**都 ≥ 工作区容量**：最好（输入有序）**只生成 1 个段**，最坏（输入逆序）段长 = 工作区容量，平均段长不等。

**最佳归并树**（针对置换-选择产生的**不等长**段）：让元素少的段先归并、多的段后归并，即构造**带权路径长度 WPL 最小的正则 $k$ 叉树**（只有度为 0 和 $k$ 的结点）。$k$ 路最佳归并树是二叉树 Huffman 算法的推广：叶结点为各段长度，每次合并 $k$ 个最小结点、其和作新结点继续参与。每个叶到根的路径长度 = 该段参与归并的次数；每次归并有 2 次 I/O（读 + 写），若每段 $n$ 个元素分别读写，则：

$$\text{完成全部归并的 I/O 次数}=2\times \text{WPL}$$

**补虚段**：为使初始段数恰好能构成正则 $k$ 叉树，若 $(\text{段数}-1)\bmod(k-1)\ne0$，需补充若干个**权为 0 的虚段**（2019 年真题：120 个初始归并段、12 路归并，求需补虚段个数）。

**败者树**：是完全二叉树、用一维数组存储、**必须从 1 号下标开始**（0 号单元存整棵树的**胜者**）。$k$ 路归并的败者树：$k$ 个叶结点编号 $k\sim 2k-1$（对应 $0\sim k-1$ 号归并段），$k-1$ 个内部结点编号 $1\sim k-1$（加上 0 号，数组大小恰为 $k$）；**父结点保存两子结点中的败者（归并段编号），胜者继续向上比较**，最终 0 号存最小元素的归并段编号。由「$n_2=n_0-1$」得内部结点数 $=k-1$。建立时从最后一个叶结点向前逐组比较，比较次数 $=k-1$；归并时把胜者（0 号）的队首输出，原归并段下一元素替补，沿路径与父结点保存的败者比较并更新直到根，**每次选最小最多比较 $\lceil\log_2 k\rceil$ 次**（王道 PPT），优于直接 $k$ 路内部排序。归并段耗尽时把对应叶置为 $\text{MaxValue}$。简化建树技巧：把各内部结点和 0 号都初始化为 $k$（虚拟「只有一个 MinValue 的编号为 $k$ 的归并段」），再从 $2k-1$ 号叶向前逐个参加比赛调整，可省去辅助单元。

### 8.2 核心考点详解（以快速排序为例展开）

**分区（Partition）过程**：任取一个元素作**基准/枢轴 pivot**（常取子表第一个元素 `A[low]`），用 `low`、`high` 两指针从两端交替向中间扫描：

1. `pivot = A[low]`（把首元素暂存，留出空位）；
2. 先从右向左：当 `A[high] >= pivot` 则 `high--`；遇到 `<pivot` 的，把 `A[high]` 移到 `A[low]`（左端空位）；
3. 再从左向右：当 `A[low] <= pivot` 则 `low++`；遇到 `>pivot` 的，把 `A[low]` 移到 `A[high]`（右端空位）；
4. 重复 2–3 直到 `low==high`，把 `pivot` 放入 `A[low]`——**基准落在最终排序位置**；
5. 递归对 `[low, pivot-1]` 与 `[pivot+1, high]` 做同样处理，直到子表长度 $\le1$。

结果：左侧子序列所有元素 $\le pivot$、右侧 $\ge pivot$。分区使「每趟至少确定一个元素的最终位置」（2012 年第 10 题把快排与选择、堆排归为「每趟定最终位置」一类）。

**基准选择**：基准取法直接影响效率。固定取首元素时，若输入**本来就有序（正序或逆序）**，每次划分都得到 $0$ 与 $n-1$ 的极不平衡分区，递归深度 $n$，退化为 $O(n^2)$——这是快排的**最坏情况**，与其它排序「正序最好」相反。改进：① **随机选择**基准；② **三数取中**（取首、尾、中三者的中间值）。

**改进策略**（补充笔记 + 知识点卡片）：① 序列长度较小时改用**直接插入排序**（元素少时快排反而比简单排序慢）；或先做几轮快排得到基本有序序列再整体插入排序；② 三数取中/随机化基准；③ **三路划分**处理**有大量相等元素**的情况（分成 $<pivot$、$=pivot$、$>pivot$ 三段，等于段不再递归）。

**递归次数**：与初始排列有关（划分越平衡递归次数越少），但**与每次划分后两个分区的处理顺序无关**（2010 年第 10 题）；递归工作栈空间 $O(\log_2 n)$（最坏 $O(n)$）。

**空间与存储**：快排要求**顺序存储**（2011 年第 10 题），因为分区需前后双向交替扫描。

**排序结果识别（408 经典题型）**：给出「第 1/2/3 趟排序结果」判断所用算法——
- 冒泡/选择：每趟把一个最值放到一端（最终位置）；
- 插入：前若干个元素有序、其余保持原相对次序（2009 年第 10 题：`11,12,13,7,8,9,23,4,5` 是第二趟结果，只能是插入排序）；
- 归并：第一趟即出现若干长度为 2 的有序子序列；
- 希尔：按增量分组后组内有序；
- 基数：按某位分配收集。
2010 年第 11 题（三趟结果 `2,12,16,5,10,88`→…→`2,5,10,12,16,88` 判为冒泡）、2012 年第 10 题（每趟定最终位置：简单选择、快排、堆排 = ⅠⅢⅣ）、2012 年第 11 题（折半插入 vs 直接插入的不同在**比较次数**：折半插入比较次数与初态无关为 $O(n\log_2 n)$，直接插入为 $O(n)\sim O(n^2)$；总趟数、移动次数、辅助空间都相同）、2019/2024/2025 年（「不可能是快速排序第二趟结果」）。

**外部排序的 I/O 计算**：2012 年第 41 题（6 个长度 10/35/40/50/60/200 的有序表经 5 次两两合并、比较总次数最少）：借**哈夫曼/最佳归并树**思想，每次合并最短的两表，两有序表合并最坏比较 $m+n-1$ 次，按 `A+B→45, AB+C→85, D+E→110, ABC+DE→195, ABCDE+F→395`，总比较 $44+84+109+194+394=825$。2023 年（置换-选择生成段的最大/最小可能长度），2024 年（败者树「冠军」结点），2019 年（补虚段个数），2027 王道八套卷（最佳归并树求 I/O 次数：`I/O=2\times WPL`，示例 $2\times(2\times3+3\times3+6\times3+9\times2+12\times2+30\times1+17\times2+18\times2+24\times2)=446$；6 路归并败者树深度、外部排序 I/O 措施判断）。

### 8.3 典型算法/代码

```c
/* 直接插入排序：A[0] 作哨兵（重要算法整理 P285） */
void InsertSort(ElemType A[], int n){
    for(int i=2; i<=n; i++)
        if(A[i].key < A[i-1].key){
            A[0]=A[i];
            for(int j=i-1; A[0].key<A[j].key; --j) A[j+1]=A[j];
            A[j+1]=A[0];
        }
}
/* 折半插入排序：找插入位置用折半，移动次数不变（P286） */
void BinInsertSort(ElemType A[], int n){
    for(int i=2;i<=n;i++){ A[0]=A[i]; int low=1,high=i-1,mid;
        while(low<=high){ mid=(low+high)/2;
            if(A[mid].key>A[0].key) high=mid-1; else low=mid+1; }
        for(int j=i-1;j>=high+1;--j) A[j+1]=A[j];
        A[high+1]=A[0];
    }
}
/* 希尔排序：前后记录增量 dk 而非 1，A[0] 只暂存非哨兵（P286） */
void ShellSort(ElemType A[], int n){
    for(int dk=n/2; dk>=1; dk/=2)
        for(int i=dk+1; i<=n; ++i)
            if(A[i].key < A[i-dk].key){
                A[0]=A[i];
                for(int j=i-dk; j>0 && A[0].key<A[j].key; j-=dk) A[j+dk]=A[j];
                A[j+dk]=A[0];
            }
}
/* 冒泡排序：flag 记录本趟是否交换，无交换提前结束（数据结构算法背诵） */
void BubbleSort(int A[], int n){
    int i,j,temp,flag=1;
    for(i=n-1; i>=1 && flag==1; i--){
        flag=0;
        for(j=0;j<i;j++) if(A[j]>A[j+1]){ temp=A[j]; A[j]=A[j+1]; A[j+1]=temp; flag=1; }
    }
}
/* 快速排序：Partition + 递归（重要算法整理 P291） */
int Partition(ElemType A[], int low, int high){
    ElemType pivot=A[low];
    while(low<high){
        while(low<high && A[high]>=pivot) --high;
        A[low]=A[high];                              /* 小者移到左端 */
        while(low<high && A[low]<=pivot) ++low;
        A[high]=A[low];                              /* 大者移到右端 */
    }
    A[low]=pivot; return low;                       /* 基准落最终位置 */
}
void QuickSort(ElemType A[], int low, int high){
    if(low<high){ int p=Partition(A,low,high);
        QuickSort(A,low,p-1); QuickSort(A,p+1,high); }
}
/* 简单选择排序（P301） */
void SelectSort(ElemType A[], int n){
    for(int i=0;i<n-1;i++){ int min=i;
        for(int j=i+1;j<n;j++) if(A[j]<A[min]) min=j;
        if(min!=i) swap(A[i],A[min]); }
}
/* 堆排序：建大顶堆 + n-1 趟「换堆顶 + AdjustDown」（P302） */
void BuildMaxHeap(ElemType A[], int len){ for(int i=len/2;i>0;i--) AdjustDown(A,i,len); }
void AdjustDown(ElemType A[], int k, int len){
    A[0]=A[k];
    for(int i=2*k; i<=len; i*=2){
        if(i<len && A[i]<A[i+1]) i++;               /* 取较大孩子 */
        if(A[0]>=A[i]) break;
        A[k]=A[i]; k=i;
    }
    A[k]=A[0];
}
void HeapSort(ElemType A[], int len){
    BuildMaxHeap(A,len);
    for(int i=len;i>1;i--){ Swap(A[i],A[1]); AdjustDown(A,1,i-1); }
}
/* 二路归并：Merge 用辅助数组 B（P309） */
void Merge(ElemType A[], int low, int mid, int high){
    for(int k=low;k<=high;k++) B[k]=A[k];
    int i=low, j=mid+1, k=i;
    while(i<=mid && j<=high) A[k++] = (B[i]<=B[j]) ? B[i++] : B[j++];
    while(i<=mid) A[k++]=B[i++];
    while(j<=high) A[k++]=B[j++];
}
void MergeSort(ElemType A[], int low, int high){
    if(low<high){ int mid=(low+high)/2;
        MergeSort(A,low,mid); MergeSort(A,mid+1,high); Merge(A,low,mid,high); }
}
```

### 8.4 易错点与 408 真题考点

- **排序结果识别**：2009 年第 10 题（第二趟结果 `11,12,13,7,8,9,23,4,5` → 只能是插入排序）；2010 年第 11 题（三趟结果 → 冒泡）；2019、2024、2025 年（「不可能是快排第 2 趟结果」）；2027 王道八套卷（快排一次划分后的序列判断）。
- **每趟定最终位置**：2012 年第 10 题 —— 简单选择、快速、堆排序（ⅠⅢⅣ），希尔与二路归并**不能**保证每趟定一个最终位置。
- **折半插入 vs 直接插入**：2012 年第 11 题 —— 不同之处只在**比较次数**（折半插入 $O(n\log_2 n)$ 与初态无关；直接插入 $O(n)\sim O(n^2)$ 与初态有关）；总趟数（均 $n-1$）、移动次数、辅助空间（均 $O(1)$）都相同。
- **堆调整比较次数**：2009 年第 9 题（小根堆插入）、2011 年第 11 题（大根堆插入 18 调整比较 2 次）、2027 王道八套卷（建大根堆结果、输出两个最小关键字后剩余堆）。
- **快排反直觉结论**：正序/逆序为**最坏** $O(n^2)$；递归次数与分区处理顺序无关（2010 年第 10 题）；宜顺序存储（2011 年第 10 题）；2010 年第 10 题还考「先处理较短/较长分区能否减少递归次数」——答案是与处理顺序无关。
- **外部排序**：2012 年第 41 题（哈夫曼式合并，总比较 825 次，指出「外部排序属于大纲新增考点」）；2019 年（120 段 12 路归并补虚段、快排第二趟）；2023 年（置换-选择生成初始归并段的最大/最小可能长度）；2024 年（败者树冠军结点、快排第一趟）；2027 王道八套卷（置换-选择/败者树/最佳归并树的 I/O 措施判断、6 路败者树深度）。
- **稳定性**：记牢「快排、堆排、选择、希尔不稳定」；「希尔增量序列互质」「基数每轮必须稳定」「基数 $d$ 位数、$r$ 基数 $O(d(n+r))$」。
- **外部排序 I/O**：$\text{I/O 次数}=2\times\text{WPL}$；补 0 虚段保证正则 $k$ 叉树；败者树 0 号存胜者、内部结点存败者、$k$ 叶编号 $k\sim2k-1$。
- 交换/选择类每轮定最终位置，插入/归并不定；归并两有序表最坏比较 $m+n-1$ 次。
