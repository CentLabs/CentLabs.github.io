## 第1章 计算机系统概述（冯诺依曼结构、层次结构、性能指标 CPI/MIPS、主频与时钟周期计算）

### 1.1 知识体系

**一、计算机硬件的发展（按所采用的电子器件划分四代）**

| 代次 | 电子器件 |
| --- | --- |
| 第一代 | 电子管 |
| 第二代 | 晶体管 |
| 第三代 | 中小规模集成电路（IC） |
| 第四代 | 超大规模集成电路（VLSI） |

划分依据是**电子器件**，不是软件，也不是体系结构。注意第四代是「超大规模」而非「大规模」。

**二、冯·诺依曼体系结构（本章第一核心）**

- 五大部件：**控制器、运算器、存储器、输入设备、输出设备**。
- 指令和数据均用**二进制**表示，两者**均存放在存储器中，按地址访问**。
- 指令由**操作码 + 地址码**组成。
- 采用「**存储程序**」方式工作：程序事先存入存储器，CPU 按地址自动依次取出执行。
- 组织结构：传统的计算机以**运算器为中心**，现代发展为以**存储器为中心**。

**三、软硬件分界面与层次结构**

- 软件和硬件的分界面是 **指令集体系结构 ISA（Instruction Set Architecture）**；ISA 向下屏蔽硬件实现细节，向上提供指令集。
- 层次结构（自顶向下）：**应用程序 → 高级语言 → 汇编语言 → 操作系统 → 机器语言 →（微指令语言）**。

**四、性能指标与基本时间概念**

衡量整机性能的基本量：**程序的响应时间**（一个任务从提交到完成所需时间）与**系统的吞吐率**（单位时间完成的工作量）。CPU 的基本性能参数：

- **时钟周期（节拍）**：CPU 中最小的时间单位，主频的倒数。
- **主频 $f$**：时钟周期的倒数，$f = 1/T$。
- **CPI（Cycles Per Instruction）**：执行一条指令所需的时钟周期数，与**特定指令相关**；对 CPU 或程序取**加权平均值**。
- **MIPS**：每秒百万条**定点**指令数；**MFLOPS**：每秒百万次**浮点**运算次数；此外还有**基准程序**（Benchmark）评测。

时间概念层次表（易混淆，务必逐条对照）：

| 概念 | 说明 |
| --- | --- |
| 时钟周期 / 节拍 | CPU 中最小的时间单位，主频的倒数 |
| 机器周期 / CPU 周期 | 执行指令的基本操作（取指、译码等）所需时间，含多个时钟周期，现代已不多用此概念 |
| 微指令周期 | 读出并执行一条微指令的时间，一般即机器周期 |
| 指令周期 | 取出并执行一条指令所需时间，含多个时钟周期 |
| 存取时间 | 又称存储器访问时间，完成一次读/写的时间 |
| 存取周期 / 存储周期 | 进行连续两次独立的存储器操作所需的最小间隔，**一定大于**存取时间 |
| 总线周期 | CPU 通过总线对主存或 I/O 端口进行一次访问的时间 |

**核心公式（全部须记牢并会代入）**

$$f = \frac{1}{T}\qquad \text{（主频与时钟周期互为倒数）}$$

$$\text{CPU 执行时间} = \text{时钟周期} \times \text{CPI} \times \text{指令条数} = IC \times CPI \times T = \frac{IC \times CPI}{f}$$

即「时钟周期、CPI、指令条数三者的**乘积**」，其中 $IC$（Instruction Count）为指令条数。

$$\text{MIPS} = \frac{f}{CPI \times 10^{6}} = \frac{IC}{T_{\text{CPU}} \times 10^{6}}$$

加权平均 CPI（CPI 是"与特定指令相关的加权平均值"的数学表达）：

$$\overline{CPI} = \sum_{i} CPI_i \times \frac{IC_i}{IC} = \sum_i CPI_i \cdot p_i \qquad \left(p_i = \frac{IC_i}{IC}\ \text{为第}\ i\ \text{类指令所占比例}\right)$$

$$\text{MFLOPS} = \frac{\text{浮点运算次数}}{\text{执行时间} \times 10^{6}}$$

### 1.2 核心考点详解

**考点一：CPU 凭什么区分指令和数据？** 冯·诺依曼结构中指令和数据都以二进制形式存放在同一个存储器中，从**二进制代码本身**无法区分。区分依据是**指令周期的不同阶段**：取指阶段访存取出的二进制代码是**指令**（送入 IR 译码），执行阶段访存取出的二进制代码是**操作数/数据**（送入 MDR 再进运算器）。这一点是 2009 年统考第 11 题的直接考点，答案选「指令周期的不同阶段」，而不是「指令操作码的译码结果」「寻址方式」「所在存储单元」。

**考点二：CPI 是加权平均，不是常数。** 单条指令的 $CPI_i$ 由其功能决定（例如定点加法指令与乘法指令、访存指令的周期数不同）；谈一台机器或一个程序的 CPI，必须是按各类指令出现频率加权后的平均值。因此「主频越高 ⇒ 性能必然越高」是错误的推断——主频只决定时钟周期 $T$，吞吐能力还取决于 CPI 与指令条数。缩短程序执行时间的三条途径（2010 年第 12 题）：提高 CPU 时钟频率（减小 $T$）、优化数据通路结构（降低 CPI）、编译优化（减少 $IC$），三者都有效。

**考点三：响应时间与 CPU 时间的分离。** 程序运行时间 = CPU 时间 + I/O 时间；只提升 CPU 速度时，I/O 时间不变，不能简单地把总时间按比例缩减，见 1.3 的 2012 年第 12 题演算。

**考点四：各时间单位的从属关系。** 指令周期 ⊇ 机器周期 ⊇ 时钟周期；存取周期 > 存取时间（因为读后还需恢复/再生）；微指令周期一般等于机器周期。现代计算机已无「机器周期」概念，一个节拍即一个脉冲。

### 1.3 典型计算题演算

**例 1-1（主频 / CPI / MIPS / CPU 时间，自编可复核）**
某机主频 $f = 500\,\text{MHz}$，某程序共 $IC = 2\times 10^{8}$ 条指令，加权平均 $\overline{CPI} = 4$。求时钟周期、CPU 执行时间、MIPS。

- 时钟周期 $T = 1/f = 1/(500\times10^{6}) = 2\times10^{-9}\,\text{s} = 2\,\text{ns}$。
- CPU 执行时间 $= IC \times CPI \times T = 2\times10^{8} \times 4 \times 2\,\text{ns} = 1.6\times10^{9}\,\text{ns} = 1.6\,\text{s}$。
  等价算法 $= IC\times CPI / f = 2\times10^{8}\times4/(500\times10^{6}) = 8\times10^{8}/5\times10^{8} = 1.6\,\text{s}$。✔ 两式互验。
- $\text{MIPS} = f/(CPI\times10^6) = 500\times10^{6}/(4\times10^{6}) = 125$，即每秒 1.25 亿条指令。
  用定义验算：$IC/T_{\text{CPU}}/10^6 = 2\times10^{8}/1.6/10^6 = 125$。✔

**例 1-2（加权平均 CPI，自编可复核）**
某程序指令构成：ALU 类占 50%，$CPI=1$；Load/Store 类占 30%，$CPI=2$；分支类占 20%，$CPI=3$。主频 $f=2\,\text{GHz}$，共 $10^{9}$ 条指令。

- $\overline{CPI} = 0.5\times1 + 0.3\times2 + 0.2\times3 = 0.5+0.6+0.6 = 1.7$。
- $T_{\text{CPU}} = 10^{9}\times1.7/(2\times10^{9}) = 0.85\,\text{s}$。
- $\text{MIPS} = 2\times10^{9}/(1.7\times10^{6}) \approx 1176$。
  复核：$10^{9}/0.85/10^{6} \approx 1176$。✔

**例 1-3（2012 年统考第 12 题：CPU 提速不等于总时间同比缩短）**
基准程序 A 运行 100 秒，其中 CPU 时间 90 秒，其余 10 秒为 I/O 时间。CPU 速度提高 50%，I/O 速度不变，求总时间。

- 易错解：$100/1.5 \approx 66.7$ 秒（错，把 I/O 时间也提速了）；或误以为「速度提高 50% ⇒ 时间减半」。
- 正解：CPU 时间变为 $90/1.5 = 60$ 秒，I/O 时间仍为 10 秒，故 $T = 60 + 10 = 70$ 秒。答案 D。✔
- 素材中的【误区】明确指出：「CPU 速度提高 50%，则 CPU 运行时间减少一半。错误！」

**例 1-4（2009 年统考第 43(1) 题：中断方式下 CPU 用于 I/O 的时间占比，逐步手算）**
CPU 主频 500 MHz、$CPI=5$；外设数据传输率 $0.5\,\text{MB/s}$，以 32 位（4 B）为传输单位；中断服务程序 18 条指令，其他开销相当于 2 条指令。

- 每次中断 CPU 开销的时钟周期数 $= 5\times18 + 5\times2 = 100$ 个周期。
- 每秒中断次数 $= 0.5\,\text{MB} / 4\,\text{B} = 125\,000$ 次。
- 每秒用于中断的周期 $= 100\times125\,000 = 12.5\times10^{6} = 12.5\,\text{M}$。
- 占整个 CPU 时间比 $= 12.5\text{M}/500\text{M} = 2.5\%$。✔

**例 1-5（2009 年第 43(2) 题：DMA 方式对照）**
数据率提高到 $5\,\text{MB/s}$，改用 DMA，每次传送块 5000 B，DMA 预处理+后处理共 500 个时钟周期。

- 每秒 DMA 次数 $= 5\,\text{MB}/5000\,\text{B} = 1000$ 次。
- 每秒 CPU 开销 $= 1000\times500 = 0.5\,\text{M}$ 周期。
- 占比 $= 0.5\text{M}/500\text{M} = 0.1\%$。✔ 相比中断方式 2.5% 下降 25 倍，正是 DMA 的意义。

### 1.4 易错点与 408 真题考点

| 易错点 | 正确结论 |
| --- | --- |
| 冯氏机中指令与数据靠「代码本身/所在单元」区分 | 靠**指令周期的不同阶段**（取指→指令；执行→数据） |
| 第四代是「大规模 IC」 | 是**超大规模 IC**；划分依据是电子器件 |
| 传统计算机以存储器为中心 | 传统以**运算器**为中心，现代才以存储器为中心 |
| 主频越高机器一定越快 | 还取决于 CPI、指令条数、I/O；不能跨机用 MIPS 简单比较 |
| CPI 是固定常数 | CPI 与指令相关，整机/程序取**加权平均** |
| 存取周期 = 存取时间 | 存取周期**一定大于**存取时间 |
| CPU 提速 50% ⇒ 总时间减半 | 只对 CPU 部分提速，I/O 时间不变（2012/12） |

**真题佐证：**
- **2009/11**（冯·诺依曼机区分指令与数据的依据）→ 答案 C 指令周期的不同阶段。
- **2009/18**（四段流水线时间 90/80/70/60 ns）→ CPU 时钟周期至少取最长段 **90 ns**，答案 A；此结论来自「流水段以最慢段为准」，属第 5 章但根子在时钟周期概念。
- **2009/20**（总线带宽 4B/2 周期/10MHz）→ 20 MB/s，答案 B（详见第 6 章）。
- **2009/21**（访存 1000 次、缺失 50 次求命中率）→ $(1000-50)/1000=95\%$，答案 D；**陷阱是题干给的是「缺失 50 次」而非「命中 50 次」**。
- **2009/43**（中断/DMA 时间占比）→ 2.5% 与 0.1%（见 1.3 例 1-4、1-5）。
- **2010/12**（缩短程序执行时间的措施：提高时钟频率、优化数据通路、编译优化）→ 三者皆可，答案 D。
- **2011/12**（描述浮点数操作速度的指标）→ **MFLOPS**，答案 D；MIPS 是定点指令速度、CPI 是周期数、IPC 是每周期指令数。
- **2011/19**（每个指令周期至少访存一次、空操作指令不改变任何寄存器）→ 错误项是 C：空操作指令仍会使 **PC 自动 +1**，故「任何寄存器内容都不变」错误。
- **2012/12**（CPU 提速 50%）→ 70 秒，答案 D。
- **2012/43**（主频 80 MHz、CPI=4、平均每条指令访存 1.5 次）→ $\text{MIPS}=80/4=20$；每秒 Cache 缺失 $=20\text{M}\times1.5\times1\%=300\text{k}$；主存带宽至少 $16\text{B}\times300\text{k}=4.8\,\text{MB/s}$（详见第 3、7 章）。

## 第2章 数据的表示和运算（数制转换、原码/反码/补码/移码、定点数运算与溢出、IEEE754、浮点数加减、奇偶/海明/CRC校验、ALU、加法器与先行进位、Booth算法）

### 2.1 知识体系

**一、数制与转换**

从 ISA 层次看，机器级只有几类简单基本数据类型，复杂类型由它们组合而成。

- 二进制 → 十进制：设 $n$ 位整数、$m$ 位小数，按权展开
  $$V = \sum_{i=1}^{n} b_i\cdot 2^{\,i-1} \;+\; \sum_{j=1}^{m} b_j\cdot 2^{-j}$$
- 十进制整数 → 二进制：**除 2 取余，倒序排列**。
- 十进制小数 → 二进制：**乘 2 取整（舍掉整数部分），顺序排列**，前面补 $0.\square\square$，可能需要近似（无限循环）。
- 既有整数又有小数：整数部分、小数部分分别转换后合并。
- 其他编码：BCD 码（8421 码，每位十进制数字用 4 位二进制独立编码）、逻辑值、西文/中文字符与字符串；**大端 Big Endian**（高字节存低地址）/ **小端 Little Endian**（低字节存低地址）。

**二、定点数的四种机器码**

以 $n$ 位（1 位符号位 + $n-1$ 位数值位）为例，真值指绝对值。

| 编码 | 规则 | 零 | 范围（整数） | 用途/性质 |
| --- | --- | --- | --- | --- |
| 原码 | 绝对值真值最高位加 1 位符号位 | 有 $+0$ 与 $-0$ | $-(2^{n-1}-1)\sim +(2^{n-1}-1)$ | 定点原码小数用于表示浮点数的**尾数** |
| 反码 | 正数同原码；负数=真值按位取反 | 有 $+0$ 与 $-0$ | 同原码 | 很少使用 |
| 补码 | 正数同原码；负数=反码 $+1$（按位取反末位 $+1$，带进位） | **0 唯一**，负数比正数多 1 个 | $\mathbf{-2^{n-1}\sim +(2^{n-1}-1)}$ | 加减不必区分符号位，符号位与数值位一同运算；实质是**模 $2^n$** 运算 |
| 移码 | 只用于整数；$n$ 位真值加偏置常数 $2^{n-1}$，使所有值非负 | — | 同补码 | 主要用于表示浮点数的**阶码**；**移码 = 补码最高位取反，其余位不变** |

补码要点公式：

$$[X]_{\text{补}} = 2^{n} + X \pmod{2^{n}} \qquad (X<0\ \text{时})$$

$$-1\ \text{的}\ n\ \text{位整数补码} = 2^{n}-1 \pmod{2^{n}} = \underbrace{11\cdots1}_{n\ \text{个}\ 1}$$

定点小数补码表示范围 $-1 \le X < 1$；$-1$ 的小数 $n$ 位补码为 $2-1 = 1.\underbrace{00\cdots0}_{n-1\ \text{个}\ 0}$。**整数和小数不能合并求补码，需单独处理。**

**三、IEEE 754 浮点数**

同样的位数，浮点数的**个数并不比定点数多**，只是**范围变大**，在数轴上**不等距分布**。单精度（32 bit）格式：**符号 1 bit | 阶码 8 bit | 尾数 23 bit**，阶码偏置为 **127（不是 128，扩大了表示范围）**。双精度（64 bit）：1 + 11 + 52，偏置 1023。

$$\text{规格化数真值} = (-1)^{S}\times 1.f \times 2^{\,e-127}$$

其中尾数采用**隐藏位**策略（最高位恒为 1，不存储），$f$ 为 23 位小数。单精度各类编码（务必背全）：

| 类型 | 符号 | 阶码 $e$ | 尾数 $f$ | 真值 |
| --- | --- | --- | --- | --- |
| 正零/负零 | 0 / 1 | $00000000$（0） | 全 0 | $+0 / -0$ |
| 正无穷/负无穷 | 0 / 1 | $11111111$（255） | 全 0 | $+\infty / -\infty$ |
| 无定义数 NaN | 0 / 1 | 255 | $\ne 0$（共 $2^{23}-1$ 个） | NaN |
| 规格化非零数 | 0 / 1 | $0<e<255$ | $00\cdots0\sim11\cdots1$ | $1.f\times 2^{e-127}$ |
| 非规格化数 | 0 / 1 | 0 | $\ne 0$ | $0.f\times 2^{-126}$ |

**四、数据校验码**

1. **奇偶校验**：数据 $B = b_{n-1}b_{n-2}\cdots b_0$，使 $PB$ 中 1 的总个数为奇数（奇校验）或偶数（偶校验）：
   $$P_{\text{偶}} = b_{n-1}\oplus b_{n-2}\oplus\cdots\oplus b_0,\qquad P_{\text{奇}} = P_{\text{偶}}\oplus 1$$
   能检出**奇数个 bit 错误**（奇、偶校验效果一样），**不能发现偶数个 bit 出错**；实现简单，常用于字节长度数据检错；**码距为 2**。
   异或 $\oplus$（XOR）性质：$A\oplus B = A\overline{B}+\overline{A}B$（C 语言 `a^b == (~a)&b|a&(~b)`），满足结合律；$A\oplus A=0$，$A\oplus0=A$；若 $C=A\oplus B$ 则 $A=B\oplus C$；$C=0\Leftrightarrow A=B$；多个 bit 异或，奇数个 1 为 1、偶数个 1 为 0（故用于生成奇偶校验位）；不用临时变量交换两数：`a=a^b; b=a^b; a=a^b;`。

2. **海明校验（多重/分组奇偶校验）**：$k$ 位校验位 → 故障字 $k$ 位 → $2^k$ 个状态；$n$ 位数据 + $k$ 位校验位，1 位错有 $n+k$ 种，加 1 个无错状态，故要求
   $$\boxed{\,2^{k}\ \ge\ n+k+1\,}$$
   校验位放在第 $2^{i-1}$（$i=1\ldots k$，即第 1、2、4、8…）位，数据顺序填充其余位置。故障字含义：**全 0 = 正确**；**只有 1 位为 1 = 该校验位自身出错（无需纠正）**；**多位为 1 = 其无符号十进制值即出错位号，翻转该位即可纠正**。
   **码距**：两码字对应比特取值不同的位数称海明距离；有效编码集中任意两码字海明距离的最小值即该编码集的码距。
   $$\text{检测}\ d\ \text{位错需码距}\ \ge d+1;\qquad \text{纠正}\ d\ \text{位错需码距}\ \ge 2d+1$$
   每个数据位至少参与两个校验码生成，翻转时导致码字中 3 位变化（2 校验位 + 自身），故码距为 3：**可纠 1 位错（SEC）**，能检出 2 位错但不能同时「检 2 位 + 纠 1 位」；**SEC-DED**（同时发现两位错并纠正一位错）需再增加 1 位校验位。

3. **CRC 循环冗余校验**：$M$ 为 $n$ 位数据，CRC 校验码 $k$ 位；将 $M$ 左移 $k$ 位后除以约定的 $k+1$ 位常数 $G$（生成多项式），用**模 2 除**得 $k$ 位余数 $R$，拼接发送：
   $$D = M\times 2^{k} + R$$
   $k+1$ 位除数的余数一定 $k$ 位，左移 $k$ 位只是为 $R$ 留位置。多项式 $M(x)=\sum m_i x^{i-1}$（如 $1001 \leftrightarrow x^3+1$）。模 2 除的加减**均为异或，不进位、不借位**；部分余数首位为 1 则商 1，否则商 0；当部分余数比除数少 1 位时停止。检错时将 $D$ 除以 $G$，**余数为 0 则无错**，否则有错；不同余数对应不同出错位，可据此纠错。原理：
   $$M\times2^{k}=G\times Q+R\ \Rightarrow\ D=G\times Q+R+R=G\times Q\quad(R\oplus R=0)$$
   CRC 面向 **bit 流**，适用于磁盘、网络传输；网络应用只检错不纠错，出错重传；余数补 0 继续除会循环出现（CRC 之由来）。内存一般采用**海明校验**。

**五、运算方法与运算部件**

- **加法器**：① 行波进位加法器（多个 1 位全加器串联，串行进位，速度慢）；② 进位选择加法器（类似分支预测，硬件较多）；③ **先行（超前）进位加法器**：用「进位生成」「进位传递」函数使各进位**独立、并行**产生，速度快，可单级/两级/多级连接。
  $$G_i = A_i B_i,\qquad P_i = A_i\oplus B_i,\qquad C_{i+1} = G_i + P_i C_i$$
- **ALU**：在先行进位加法器基础上增加逻辑功能；2 个操作数输入、低位进位输入、操作控制输入（**操作码位数决定操作类型数量**，$m$ 位可表示 $2^m$ 种）、1 个结果输出、高位进位输出与标志输出。**74181**：典型 4 位 ALU，4 位操作码 + 1 位功能选择，可实现 16 种算术 + 16 种逻辑运算；**74182**：成组先行进位生成 IC，配合 74181 扩展为两级先行进位（组内、组间均先行）加法器。
- **定点整数运算**（核心是带快速加法器的 ALU）：
  - 移位：算术移位、逻辑移位、循环移位；算术/逻辑左移低位补 0，算术右移高位补符号，逻辑右移高位补 0。
  - 扩展：**零扩展**（无符号数，高位补 0）、**符号扩展**（有符号补码，高位补符号）。
  - **补码加减**：符号位与数值位一起参加运算，减法用加法实现；**同号相加时若结果的符号不同于加数的符号，则溢出**（或：最高位进位与次高位进位不同则溢出）。加减法器在基本加法器上增加进位/加减控制、求补电路、溢出判断电路。
  - **补码乘法**：用加法和右移实现，符号位与数值位一起运算，采用 **Booth 算法**或 MBA 算法；快速乘法器可用基于 CSA 的阵列乘法器、MBA+WT。
  - **补码除法**：用加减法和左移实现；有恢复余数法与**不恢复余数法**（常用，加减交替，**最后一次仍需恢复余数**）；阵列除法器用可控加减单元 CAS。
- **浮点加减五步**：① **对阶**（向阶码大的对齐，小阶尾数右移，右移保留附加位）；② **尾数相加减**（隐藏位与附加位都参加，定点小数原码加减实现，同号相加、异号相减「大数减小数，减即加负数补码，结果取大数符号」）；③ **规格化**（左规/右规）；④ **舍入**（就近舍入、正向舍入、负向舍入、截断 4 种）；⑤ **溢出判断**（阶码上溢时结果溢出）。
- **浮点乘除**：尾数用定点小数原码乘除（符号位、数值位分开运算，数值位用无符号数乘除），阶码用定点整数加减。

### 2.2 核心考点详解

**详解 A：补码范围与求补码的完整逻辑。** 为何 $n$ 位补码多出一个负数？因为 0 的编码唯一（原码、反码各有 $\pm0$ 两个编码），省下的一个编码 $10\cdots0$ 被分配给 $-2^{n-1}$。故 $n=8$ 时范围为 $-128\sim+127$（2010 年第 13 题即在此范围上判断乘积溢出）。求负数补码的可靠口诀：「真值按位取反，末位 $+1$（带进位）」；也可用「从右向左找到第一个 1，其左侧全部取反」。$[X]_{\text{补}}$ 的实质是 $X \bmod 2^n$，因此减法 $X-Y$ 可化为 $[X]_{\text{补}}+[-Y]_{\text{补}} \pmod{2^n}$，符号位自然参与运算。移码只用于整数，等于补码符号位取反，故同一真值的移码与补码**仅最高位不同**，移码全 0 对应最小真值 $-2^{n-1}$，便于比较阶码大小。

**详解 B：IEEE 754 表示一个数的完整流程。** 以 $x=-8.25$（2011 年第 13 题）为例：① 写成二进制 $-1000.01_2$；② 规格化为 $-1.00001\times2^{3}$；③ 符号 $S=1$；④ 阶码 $E = 3 + 127 = 130 = 10000010_2$；⑤ 尾数 $f$ = 去掉隐藏位 1 后的 `00001`，右补 0 至 23 位 = `00001000000000000000000`；⑥ 拼接 `1|10000010|00001000000000000000000` = `1100 0001 0000 0100 0000 0000 0000 0000` = **C1040000H**。注意偏置是 127 不是 128；尾数精度由 23 位决定、范围由 8 位阶码决定；float 能表示的最大正整数 $=1.11\cdots1\times2^{254-127}=2^{127}\times(2-2^{-23})=2^{128}-2^{104}$（2012 年第 14 题答案 D）。

**详解 C：海明码的编码与检错/纠错（完整机制）。** 以素材给出的 **6 位数据**为例：由 $2^k\ge 7+k$ 得 $k=4$（$k=3$ 时 $8\ge10$ 不成立，$k=4$ 时 $16\ge11$ 成立），共 10 位码字。把校验位放在第 1、2、4、8 位：

$$M_{10}M_9M_8M_7M_6M_5M_4M_3M_2M_1 \;=\; D_6\,D_5\,P_4\,D_4\,D_3\,D_2\,P_3\,D_1\,P_2\,P_1$$

故障字各位由「位号二进制中含该权值的码位」异或得到（第 $i$ 位故障位收集所有位号在第 $i$ 个二进制权上为 1 的码位）：

$$e_4 = M_{10}\oplus M_9\oplus M_8 = D_6\oplus D_5\oplus P_4$$
$$e_3 = M_7\oplus M_6\oplus M_5\oplus M_4 = D_4\oplus D_3\oplus D_2\oplus P_3$$
$$e_2 = M_{10}\oplus M_7\oplus M_6\oplus M_3\oplus M_2 = D_6\oplus D_4\oplus D_3\oplus D_1\oplus P_2$$
$$e_1 = M_9\oplus M_7\oplus M_5\oplus M_3\oplus M_1 = D_5\oplus D_4\oplus D_2\oplus D_1\oplus P_1$$

正确状态 $e_4e_3e_2e_1=0000$，由 $A\oplus B=0\Rightarrow A=B$ 反解校验位：

$$P_4 = D_6\oplus D_5,\quad P_3 = D_4\oplus D_3\oplus D_2,\quad P_2 = D_6\oplus D_4\oplus D_3\oplus D_1,\quad P_1 = D_5\oplus D_4\oplus D_2\oplus D_1$$

检错时直接用收到的各码元重算故障字（如 $e_4=M'_{10}\oplus M'_9\oplus M'_8$）；或由收到的 $D'_i$ 重算 $P''_j$，取 $e_j=P'_j\oplus P''_j$。故障字的十进制值即出错位号：如 `0100`=4 → 第 4 位（$P_3$，校验位自身）出错可忽略；`0110`=6 → 第 6 位（$D_3$）出错，翻转即可纠正。完整数值演算见 2.3 例 2-5。

**详解 D：CRC 模 2 除的完整机制。** 关键是「加减即异或、不进位」。以 $k=4$、生成多项式 $G=10011$（即 $G(x)=x^4+x+1$，2023 年真题所用）为例，对 $M=1100$：先左移 4 位成 $1100\,0000$，再用 5 位除数逐位异或，每步「部分余数首位为 1 商 1 并异或 $G$、为 0 商 0 并异或全 0」，落下一位继续，直到处理完所有位，最后保留 4 位余数 $R$。把 $R$ 拼接在 $M$ 后发出，接收端对整串再做同一除法，余数 0 判无错。完整竖式见 2.3 例 2-6。

**详解 E：Booth 算法的完整机制。** 补码一位乘中设乘数寄存器 $Q$、附加位 $Q_{-1}$（初值 0）、$n$ 位累加器 $A$（初值 0）、被乘数 $M=[X]_{\text{补}}$。每轮考察 $(Q_0, Q_{-1})$：

| $Q_0Q_{-1}$ | 操作 |
| --- | --- |
| 00 / 11 | 无操作（$+0$） |
| 01 | $A \leftarrow A + M$ |
| 10 | $A \leftarrow A - M = A + [-M]_{\text{补}}$ |

随后把 $A$ 与 $Q$ 联合**算术右移一位**（$A$ 符号位保持，$A$ 最低位移入 $Q$ 最高位，$Q$ 最低位移入 $Q_{-1}$）。共做 $n$ 轮，最终 $A\!:\!Q$ 即 $2n$ 位乘积补码。这样把「连串 1」的多次加压缩为一次加一次减，符号位与数值位统一处理。完整 4 位演算见 2.3 例 2-7。

**详解 F：补码加减溢出的三种判据。** ① 同号相加结果符号异于加数符号（素材正文）；② 最高位进位 $\oplus$ 次高位进位 $=1$（2011 年第 43 题解析给出的加法器判据）；③ 双符号位（变形补码）结果符号位为 `01`（正溢）或 `10`（负溢）——2009 年第 13 题浮点加法即用双符号位判溢出。三者本质一致。

### 2.3 典型计算题演算（均可手算复核）

**例 2-1（数制转换）** $(13.625)_{10}\to$ 二进制。
整数 13：除 2 取余 `13/2=6…1, 6/2=3…0, 3/2=1…1, 1/2=0…1`，倒序得 $1101$；小数 $0.625$：$0.625\times2=1.25\to1$，$0.25\times2=0.5\to0$，$0.5\times2=1.0\to1$，顺序得 $0.101$；合并 $1101.101_2$。
反验：$8+4+1+0.5+0.125=13.625$ ✔。

**例 2-2（补码范围、求补码、移码）** $n=8$：范围 $-2^{7}\sim2^{7}-1=-128\sim+127$；$n=16$：$-32768\sim+32767$。
求 $-9$ 的 8 位补码：$+9=00001001$，按位取反 $11110110$，末位 $+1$ 得 $11110111=\text{F7H}$；验证 $-9\equiv 256-9=247=\text{F7H}$ ✔。$-1=\text{FFH}$（8 个 1），$-128=\text{80H}$ ✔。
移码：真值 $-1$ 的 8 位补码 FFH，符号位取反得移码 **7FH**；阶码真值 $+3$ 的移码 $=3+127=130=10000010_2$（与 IEEE 754 阶码一致）。

**例 2-3（IEEE 754 表示，2011/13 与 2012/14）** 见 2.2 详解 B：$-8.25\to$ **C1040000H**（答案 A）。
float 最大正整数：规格化数最大值 $=(-1)^0\times1.\underbrace{11\cdots1}_{23}\times2^{254-127}= (2-2^{-23})\times2^{127}=2^{128}-2^{104}$（2012/14 答案 D）✔。
规格化单精度**最接近 0 的负数** $=-(1.0)\times2^{1-127}=-2^{-126}$（王道 8 套卷题，注意题干限定「规格化」，若含非规格化则可小到 $-2^{-149}$）。
float 表示 $0.1$：$0.1=0.00011[0011]\cdots_2=1.100110011\cdots\times2^{-4}$，阶码 $-4+127=123=01111011_2$，就近舍入尾数 `10011001100110011001101`，得 `3DCC CCCD` 附近的机器数（素材题目给出 `3DCC CCCCH`，用于说明十进制小数常无法精确表示）。

**例 2-4（补码加减、溢出、扩展，4 道真题合演）**

(a) **2010/13** 8 位补码：$r_1=\text{FEH}=-2,\ r_2=\text{F2H}=-14,\ r_3=\text{90H}=-112,\ r_4=\text{F8H}=-8$，范围 $-128\sim+127$。
$r_1r_2=28$ ✔；$r_2r_3=(-14)(-112)=1568>127$ **溢出** ✔；$r_1r_4=16$ ✔；$r_2r_4=112$ ✔ → 答案 B。

(b) **2009/12 符号扩展**：$x=127=\text{0000007FH}$（int 32 位）；$y=-9=\text{FFF7H}$（short 16 位）；$z=x+y$。
$y$ 强制转 int：符号位为 1，高位补 16 个 1 → $\text{FFFFFFF7H}$；$z=\text{0000007FH}+\text{FFFFFFF7H}=\text{1\_00000076H}$，最高进位自然丢弃 → $\text{00000076H}=118$ ✔ → 答案 D（`0000007FH, FFF7H, 00000076H`）。
对比 **2012/13 零扩展**：`unsigned short x=65530=FFFAH` → `unsigned int y=0000FFFAH`（无符号，附加位全补 0）✔ 答案 B；若误按有符号符号扩展会得 `FFFFFFFAH`（干扰项 D）。

(c) **2011/43** 8 位机：$x=134=10000110\text{B}=\text{86H}$，$y=246=11110110\text{B}=\text{F6H}$。
$R_1=\text{86H}$；$z_1=x-y=86\text{H}+0\text{A}\text{H}=\text{90H}\Rightarrow R_5=\text{90H}$；$z_2=x+y=86\text{H}+\text{F6H}=1\,7\text{C}\text{H}\Rightarrow R_6=\text{7CH}$（进位丢弃）。
$m$（带符号）$=\text{86H}=-122$；$n=\text{F6H}=-10$；$k_1=m-n=\text{90H}=-112$；$k_2=m+n=-132<-128$ **溢出**（本程序段唯一溢出的带符号语句）。
解析结论：**无符号与带符号的加/减可共用同一个 $n$ 位加法器**——$n$ 位加法器实现的是模 $2^n$ 无符号加，$a-b=a+[-b]_{\text{补}}\ (\bmod 2^n)$；带补码 $[a\pm b]_{\text{补}}=[a]_{\text{补}}+[\pm b]_{\text{补}}\ (\bmod 2^n)$，形式完全一致，只是**溢出/进位解释不同**。
溢出判据：两输入符号相同而和的符号不同；或最高位进位 $\oplus$ 次高位进位 $=1$。

(d) **2011/17 无符号大于转移条件**：`bgt` 做 $A-B$，无借位且结果非 0 时 $A>B$，即 $CF=0$ 且 $ZF=0$，条件 $\overline{CF}\cdot\overline{ZF}$ → 答案 C。（有符号比较还需 $OF$、$SF$。）

(e) **2012/44(1) 算术移位**：16 位补码 $x=-513$ 的机器数 $[x]_{\text{补}}=\text{FDFFH}=1111\,1101\,1111\,1111\text{B}$（由 $513=0000\,0010\,0000\,0001_2$ 取反加 1 得到）。素材解析给出的执行后结果 $\text{FEFFH}=1111\,1110\,1111\,1111\text{B}$ 是**算术右移 1 位**（高位补符号位 1，即 `SHR` $(Rd)/2$）；若按 `SHL` 算术左移 1 位（低位补 0，$2\times(Rd)$）则应为 $\text{FBFEH}=1111\,1011\,1111\,1110\text{B}$。二者差别即本章易错点：**左移低位补 0，右移高位补符号**，不可混淆。

**例 2-5（海明码编码 / 检错 / 纠错，完整数值演算）** 数据 $D_6D_5D_4D_3D_2D_1=101101$（6 位），$2^k\ge7+k\Rightarrow k=4$。
码位安排：$M_{10..1}=D_6\,D_5\,P_4\,D_4\,D_3\,D_2\,P_3\,D_1\,P_2\,P_1=1\,0\,P_4\,1\,1\,0\,P_3\,1\,P_2\,P_1$。
求校验位：
$P_4=D_6\oplus D_5=1\oplus0=1$；$P_3=D_4\oplus D_3\oplus D_2=1\oplus1\oplus0=0$；
$P_2=D_6\oplus D_4\oplus D_3\oplus D_1=1\oplus1\oplus1\oplus1=0$；$P_1=D_5\oplus D_4\oplus D_2\oplus D_1=0\oplus1\oplus0\oplus1=0$。
**发出码字** $M_{10}\cdots M_1=\mathbf{1011100100}$。
发送前自检：$e_4=1\oplus0\oplus1=0$，$e_3=1\oplus1\oplus0\oplus0=0$，$e_2=1\oplus1\oplus1\oplus1\oplus0=0$，$e_1=0\oplus1\oplus0\oplus1\oplus0=0$，故障字 $0000$ ✔。
设传输中第 6 位（$D_3$）由 1 翻转为 0，收到 $1011000100$。重算：
$e_4=M_{10}\oplus M_9\oplus M_8=1\oplus0\oplus1=0$；
$e_3=M_7\oplus M_6\oplus M_5\oplus M_4=1\oplus0\oplus0\oplus0=1$；
$e_2=M_{10}\oplus M_7\oplus M_6\oplus M_3\oplus M_2=1\oplus1\oplus0\oplus1\oplus0=1$；
$e_1=M_9\oplus M_7\oplus M_5\oplus M_3\oplus M_1=0\oplus1\oplus0\oplus1\oplus0=0$。
故障字 $e_4e_3e_2e_1=\mathbf{0110}_2=6$ → **第 6 位出错**，翻转即恢复 $1011100100$ ✔（与素材「故障字 0110 表示第 6 位」完全一致）。
若故障字为 $0100=4$（只有 1 位为 1），则是第 4 位校验位 $P_3$ 自身出错，可忽略。
配套：**王道 8 套卷题**「7 位信息位、偶校验、校验位在 1/2/4/8… 位」：$2^k\ge 7+k+1=8+k$，$k=4$ 时 $16\ge12$ 成立 → **最少 4 个校验位，总码长 11 位**。

**例 2-6（CRC 模 2 除完整竖式，2023/37 同型）** $M=1100$，$k=4$，$G=10011$（$G(x)=x^4+x+1$），被除数 $M\cdot2^4=1100\,0000$。
用 4 位余数寄存器逐位处理（每次左移并移入被除数下一位，得 5 位部分余数；首位为 1 则 $\oplus10011$，为 0 则 $\oplus00000$）：

| 步骤 | 移入位 | 5 位部分余数 | 首位 | 异或 $G$ 后 | 新 4 位余数 | 商 |
| --- | --- | --- | --- | --- | --- | --- |
| 初值 | — | — | — | 取前 4 位 | 1100 | — |
| 1 | 0 | 11000 | 1 | $11000\oplus10011=01011$ | 1011 | 1 |
| 2 | 0 | 10110 | 1 | $10110\oplus10011=00101$ | 0101 | 1 |
| 3 | 0 | 01010 | 0 | $01010\oplus00000=01010$ | 1010 | 0 |
| 4 | 0 | 10100 | 1 | $10100\oplus10011=00111$ | **0111** | 1 |

得 $R=0111$，发出 **$D=1100\,0111$**。
接收端校验（被除数 $1100\,0111$，剩余移入位 $0111$）：

| 步骤 | 移入位 | 5 位部分余数 | 首位 | 新余数 |
| --- | --- | --- | --- | --- |
| 初 | — | — | — | 1100 |
| 1 | 0 | 11000 | 1 | 1011 |
| 2 | 1 | 10111 | 1 | 0100 |
| 3 | 1 | 01001 | 0 | 1001 |
| 4 | 1 | 10011 | 1 | **0000** |

余数 $0000$ → 判定传输无错 ✔（$D=G\times Q+R\oplus R=G\times Q$，$R\oplus R=0$）。

**例 2-7（Booth 算法，4 位补码一位乘，完整演算）** 求 $X\times Y$，$X=3\Rightarrow M=[X]_{\text{补}}=0011$，$[-M]_{\text{补}}=1101$；$Y=-3\Rightarrow Q=[Y]_{\text{补}}=1101$。理论结果 $-9$。
初值 $A=0000,\ Q=1101,\ Q_{-1}=0$；每轮先按 $(Q_0,Q_{-1})$ 操作，再 $A\!:\!Q$ 联合算术右移一位。

| 轮 | $Q_0Q_{-1}$ | 操作 | 操作后 $A$ | 右移后 $A$ | 右移后 $Q$ | 新 $Q_{-1}$ |
| --- | --- | --- | --- | --- | --- | --- |
| 初 | — | — | — | 0000 | 1101 | 0 |
| 1 | 10 | $A\leftarrow A+1101=1101$ | 1101 | 1110 | 1110 | 1 |
| 2 | 01 | $A\leftarrow 1110+0011=0001$ | 0001 | 0000 | 1111 | 0 |
| 3 | 10 | $A\leftarrow 0000+1101=1101$ | 1101 | 1110 | 1111 | 1 |
| 4 | 11 | 无操作 | 1110 | 1111 | 0111 | 1 |

最终 $A\!:\!Q=1111\,0111$，而 $-9$ 的 8 位补码 $=256-9=247=11110111\text{B}$ ✔。

**例 2-8（浮点加减五步，2009/13 原题演算）** 阶码 5 位、尾数 7 位，**均含 2 位符号位**（变形补码）；$X=2^{7}\times29/32,\ Y=2^{5}\times5/8$。
- 写出：$X:\ 00,111;\ 00.11101$（$29/32=0.11101$）；$Y:\ 00,101;\ 00.10100$（$5/8=0.101$）。
- ① 对阶：$\Delta E=00,111-00,101=00,010=2$，小阶向大阶看齐 → $Y$ 阶 $+2$ 成 $00,111$，尾数右移 2 位成 $00.00101$。
- ② 尾数加：$00.11101+00.00101=01.00010$，双符号位 `01` 表示尾数溢出，需右规。
- ③ 规格化（右规）：尾数右移 1 位 $\to 00.10001$（取 7 位小数为 $00.1000$），阶码 $+1$：$00,111+1=01,000$。
- ⑤ 判溢出：阶码双符号位 `01` → **阶码上溢，结果溢出** → 答案 **D 发生溢出** ✔。
（若右规后阶码未越界，才进入 ④ 舍入：就近舍入 / 正向舍入 / 负向舍入 / 截断。）

### 2.4 易错点与 408 真题考点

| 易错点 | 正确结论 |

## 第3章 存储系统（存储器层次、SRAM/DRAM与刷新、芯片扩展、多模块交叉存储器、Cache 三种映射与地址划分、替换算法、写策略、Cache命中率与平均访问时间计算、虚拟存储器与TLB）

### 3.1 知识体系

**一、存储器分类与层次化**

按存取方式分：**随机存取**（任一单元访问时间与物理位置无关）、**顺序存取**、**直接存取**、**相联存储**（按内容访问，如快表 TLB）。主要指标：**容量、速度、价格**。层次化结构（寄存器 → Cache → 主存 → 外存）的目标是用速度换容量、用价格优化整体性能，其有效性建立在**程序访问的局部性原理**之上。

**二、SRAM 与 DRAM**

| | SRAM | DRAM |
| --- | --- | --- |
| 存储元 | 6 管双稳触发器 | MOS 管栅极电容 |
| 集成度 / 功耗 | 集成度低、功耗大（MOS 管多） | 集成度高、功耗小 |
| 刷新 | **无需刷新** | **需定时刷新**，读后再生 |
| 速度 | 读写速度快 | 速度较慢 |
| 用途 | 常作 **Cache** | 常作**主存** |

大容量存储芯片为减少地址引脚多采用**地址复用技术**：行地址、列地址通过相同管脚先后输入。DRAM 刷新是「读出后原样写入」，**按行**进行；三种刷新方式：**集中刷新**、**分散刷新**（分散到每个存储周期）、**异步刷新**（最常用）。传统内存与 CPU 之间采用异步方式交换数据；SDRAM、DDR 采用同步方式，支持突发传输。内存一般采用**海明校验**；内存包括 RAM 和 ROM；主存芯片内采用**行缓存**，当前行数据直接从缓存中取。

**核心公式：**

$$\text{异步刷新间隔} = \frac{\text{刷新周期}}{\text{行数}}$$

**三、存储芯片扩展与 CPU 连接**

- **位扩展**：扩展数据位宽（各芯片共享地址线，数据线分别接不同位）；**字扩展**：扩展地址空间/容量（靠高位地址译码产生片选 $\overline{CS}$）；两者可**同时**使用。
- 与 CPU 连接三类线：**控制线**（$\overline{CS}$ 片选、$W/\overline{R}$ 读写、行/列选通）、**数据线**、**地址线**。
- 所需芯片数：
$$N = \frac{\text{目标总容量}}{\text{单片容量}} \times \frac{\text{目标位宽}}{\text{单片位宽}} = \frac{M_{\text{目标}}}{M_{\text{片}}}\times\frac{W_{\text{目标}}}{W_{\text{片}}}$$

**四、多模块存储器**

- **连续编址（高位交叉）**：CPU 地址线**高位**作片选、**低位**作模块内地址，地址在模块内连续；CPU 串行访问各模块，但 DMA 可同时访问其他模块。
- **交叉编址（低位交叉）**：**低位**作片选、**高位**作模块内地址，多采用**轮流启动**方式，存取速度提高 $n$ 倍，提高带宽。
$$\text{带宽} \approx n \times \frac{\text{单模块数据宽度}}{\text{存储周期}}$$
- **双口 RAM**：发生冲突时按优先级选择某端口，或增加一个 `busy` 引脚避免冲突。

**五、局部性原理与 Cache 基础**

- **时间局部性**：某单元在很短时间内被重复访问（如循环体）；**空间局部性**：相邻单元被相继访问（如顺序遍历数组）。这是 Cache 与虚存有效的基础。
- Cache 每行有**有效位**；**Cache 行 ↔ 主存块**，一行含 1 到多个字节，为 2 的整数幂。分块太小不能充分利用空间局部性、块数增加使冲突概率增大；分块太大则行数减小、缺失率增加，都会降低性能。
- **命中率与平均访问时间**：
$$p = \frac{\text{命中次数}}{\text{总访问次数}},\qquad \boxed{T_a = p\,T_c + (1-p)\,T_m}$$
其中 $T_c$ 为 Cache 访问时间、$T_m$ 为主存访问时间、$p$ 为命中率。**素材明确限定：该式适用于 Cache 和主存「并行访问」的情况**。若采用「先查 Cache、缺失再访主存」的**串行**口径，则
$$T_a = T_c + (1-p)\,T_m = \text{命中时间} + (1-p)\times\text{缺失代价}$$
两种口径的差别是高频陷阱（详见 3.2 详解 A）。

**六、Cache 三种映射与地址划分（本章最核心）**

设主存按字节编址、地址共 $A$ 位；块大小 $2^{b}$ 字节（**块内地址 $b$ 位**）；Cache 共 $2^{c}$ 行；$s$ 路组相联 → 组数 $2^{q}=2^{c}/s$（**组号 $q$ 位**）。

| 映射 | 地址格式（高→低） | 定位关系 | 特点 |
| --- | --- | --- | --- |
| **直接映射** | 标记 $(A-c-b)$ \| **行号** $(c)$ \| 块内 $(b)$ | 行号 $=\text{主存块号}\bmod 2^{c}$（取**主存块号**低 $c$ 位，**不是主存地址低 $c$ 位**） | 实现简单、命中时间短、**无需替换算法**；冲突多、命中率低，适合大容量 Cache |
| **全相联** | 标记 $(A-b)$ \| 块内 $(b)$ | 每块可放**任意**一行；按内容访问，需比较所有行标记 | 冲突概率低；时间与元件开销大、实现困难，不适合大容量 |
| **组相联** | 标记 $(A-q-b)$ \| **组号** $(q)$ \| 块内 $(b)$ | 组号 $=\text{主存块号}\bmod 2^{q}$；**组间模映射、组内全映射**，每组 $s$ 行称 $s$ 路组相联 | 适当选取 $s$，性能可接近全相联 |

$$\text{Cache 行数} = \frac{\text{Cache 数据区容量}}{\text{块大小}},\qquad \text{组数} = \frac{\text{行数}}{s},\qquad \text{标记位数} = A - (\text{组号或行号位数}) - b$$

**命中判断（三者通用）**：按行号/组号定位 → 把主存地址的**标记**与该行（或该组每一行）的标记逐一比较 → **标记相同且有效位为 1 才命中**；否则缺失，从主存调入该块并（若满）按替换算法换出一行。

**七、替换算法与写策略**

替换算法：**FIFO**（先进先出，缺失率较大）、**LRU**（最近最少使用，是**堆栈算法**，每行需计数器，命中率随组增大而提高）、**LFU**（最不经常用）、**随机替换**。

写策略（Cache 一致性，关键是处理好写操作）：

| 策略 | 写命中 | 写不命中 |
| --- | --- | --- |
| **全写法 Write Through** | 同时写 Cache **和**主存 | 写内存后，可装入 Cache 也可不装入 |
| **写回法 Write Back** | **只写 Cache**，每行加 `dirty` 位，**被换出时才写内存** | 先装入 Cache，只写 Cache；需其他机制保证一致性 |
| **写一次法 Write Once** | 与写回基本相同，**仅第一次写命中时同时写 Cache 和主存** | 同写回 |

Cache 性能（命中率）与**容量、行大小**有关；现代一般采用**多级 Cache**，L1 分**指令 Cache 与数据 Cache** 两个，L1 更关注速度、L2 要求尽量高的命中率；采用快速查找算法、**并行判定**也能提高命中率。

**八、虚拟存储器与 TLB**

- 虚存基于局部性原理，采用**部分装入、部分对换、主存辅存独立编址但统一使用**，使进程虚拟地址空间远大于物理内存；所有程序给出逻辑地址，运行时**动态地址转换**。它解决了**内存容量有限**问题，同时解决进程内存空间的**隔离保护和共享**问题。**增加 Cache 是为了匹配 CPU 与内存的速度**（目的不同，勿混）。
- 快表 **TLB**：页表的高速缓存，减少地址映射的访存次数；通常采用**全相联或组相联**、**随机替换**、**写回法**；是「按内容访问」的相联存储器。TLB 命中 ⇒ Page 必然命中；反之不成立；Cache 命中与否与 TLB/Page 命中与否**无必然联系**。
- **CPU 访存最长过程**（素材原文链条）：CPU 给出虚拟地址 VA → TLB 缺失 → 访问主存页表 → 缺页 → 主存无空闲页需换页 → 从硬盘读出一页到主存 → 更新页表和 TLB → 将 VA 转换为物理地址 PA → Cache 缺失 → Cache 无空闲行需替换 → 主存块送入 Cache → 读取数据。

### 3.2 核心考点详解

**详解 A：两种平均访问时间口径必须分清。** 素材公式 $T_a=pT_c+(1-p)T_m$ 的前提是「Cache 与主存**并行**访问」：命中时耗时 $T_c$，缺失时耗时 $T_m$（并行启动下 $T_m$ 已包含开销），按概率加权。而串行口径 $T_a=T_c+(1-p)\times\text{缺失代价}$ 中，命中只花 $T_c$，缺失要在 $T_c$ 之后**再**付出主存访问/缺失损失。卡片库给的「命中时间 $+(1-p)\times$ 缺失代价」即串行式。做题时先看题干给的是「命中时间 + 缺失损失」还是「$T_c$ 与 $T_m$」，再选公式；例如 8 套卷题给出「Cache 命中时间 2 个时钟周期、缺失损失 160 个时钟周期」，就应当用串行式 $T_a=2+(1-p)\times160$。

**详解 B：直接映射的「低 n 位」是主存块号的低 n 位，不是主存地址的低 n 位。** 主存地址 = 块号 + 块内地址；行号由**块号**取模得到。若误把主存地址的低 $c$ 位当行号，会把块内地址位混进去，全盘皆错。求某主存单元所在 Cache 行/组的标准流程：① 求块号 $=\lfloor\text{单元地址}/\text{块大小}\rfloor$；② 行号/组号 $=$ 块号 $\bmod$ 行数/组数；③ 标记 $=\lfloor\text{块号}/\text{行数（或组数）}\rfloor$。2009/14 即是这个流程。

**详解 C：组相联的完整地址划分与命中判断过程（用户重点）。** 见 3.3 例 3-4 的完整 16 位地址演算：把地址拆成「标记 | 组号 | 块内地址」三段 → 用组号索引到 Cache 的某一组 → 组内 $s$ 行的标记与主存标记**并行比较** → 标记相等且有效位为 1 则命中 → 用块内地址在该行内选字节 → 缺失则调块装入该组（组内满时用 LRU 换出一行）。组相联是「组间直接映射 + 组内全相联」，因此它既有直接映射的快速索引，又有全相联的低冲突率。

**详解 D：命中率与「数组按行/按列访问」。** 块大小 $B$ 字节、每个 int 占 4 字节 → 一块可装 $B/4$ 个元素；按行优先存放时，逐行访问每块的第一个元素缺失、其余 $B/4-1$ 个命中，故命中率 $\approx 1-4/B$（当数组大小为块大小整数倍时精确成立）；逐列访问若步长恰使不同行的同列元素映射到同一 Cache 行/组且 Cache 容量不足以容纳，则**每次访问都缺失，命中率 0**。这是 2010/44 的核心结论。

**详解 E：三种映射的标记位数与 Cache 总容量。** Cache 总容量 = 数据区 + 标记项（每行：标记位 + 有效位，写回法再加 dirty 位，替换算法再加 LRU 位）。例如 2010/44：28 位地址、块内 6 位、行号 3 位 → 标记 19 位 + 1 有效位 = 20 位 = 2.5 B，总容量 $=8\times(64+2.5)=532$ B。注意「位数要按字节折算」，这是易错点。

**详解 F：TLB / Cache / Page 命中组合的逻辑约束。** TLB 是页表（Page）的**副本**（高速缓存），故 **TLB 命中 ⇒ Page 必命中**；Page 命中时 TLB 未必命中；**「TLB 命中、Cache 命中、Page 未命中」在逻辑上不可能发生**（2010/17 答案 D）。Cache 与 TLB/Page 彼此独立，四种组合中凡违反上述蕴含关系的即为「不可能」。

**详解 G：真题中「组相联」口径的差异（务必警惕）。** 素材 2009/14 解析专门加了警示：「由于在计算机系统结构中和计算机组成原理的某些教材中介绍的组相联跟此处的组相联并不相同，导致部分考生理解错题目。考生应以真题为准」。因此本章知识体系给出的是教材通用定义（组号 = 主存块号 $\bmod$ 组数），而个别真题（如 2012/17）采用了按「主存块顺序分组后再取模」的特定口径；遇到组相联真题应**先按该题解法定组号**，不可死套公式。详见 3.3 例 3-6。

### 3.3 典型计算题演算（均可手算复核）

**例 3-1（DRAM 异步刷新）** 某 DRAM 刷新周期 $2\,\text{ms}$，共 $128$ 行，采用异步刷新：
$$\text{刷新间隔}= \frac{2\,\text{ms}}{128}=15.625\,\mu\text{s}$$
即每隔 $15.625\,\mu\text{s}$ 插入一次「按行读出后原样写入」的刷新；集中刷新则把全部刷新集中在一小段「死区」，分散刷新把刷新分散到每个存储周期。

**例 3-2（芯片扩展，2009/15 与 2010/15）**

(a) **2009/15**：主存 64 KB，ROM 区 4 KB、其余 60 KB 为 RAM，按字节编址；用 $2\text{K}\times8$ 位 ROM 与 $4\text{K}\times4$ 位 RAM 设计。
ROM：$\dfrac{4\text{K}\times8}{2\text{K}\times8}=2$ 片（**字扩展**）；RAM：$\dfrac{60\text{K}\times8}{4\text{K}\times4}=15\times2=30$ 片（**字、位同时扩展**：先 $60\text{K}/4\text{K}=15$ 组，每组 $8/4=2$ 片并联）→ 答案 **D（2、30）** ✔。

(b) **2010/15**：用若干 $2\text{K}\times4$ 位芯片组成 $8\text{K}\times8$ 位存储器，求地址 `0B1FH` 所在芯片的最小地址。
每行需 $8/4=2$ 片并联（位扩展），共需 $8\text{K}/2\text{K}=4$ 行（字扩展），每行占 $2\text{K}=0800\text{H}$ 个地址：
第 1 行 `0000H~07FFH`、第 2 行 `0800H~0FFFH`、第 3 行 `1000H~17FFH`、第 4 行 `1800H~1FFFH`。
`0B1FH` 落在 `0800H~0FFFH` → 该行最小地址 **0800H**，答案 D ✔。

**例 3-3（直接映射 / 命中率，2009/14、2009/21）**

(a) **2009/14**：Cache 共 16 块，2 路组相联 → 组数 $=16/2=8$；主存块 32 B；求主存 129 号单元所在主存块的 Cache 组号。
① 块号 $=\lfloor129/32\rfloor=4$；② 组号 $=4\bmod 8=4$ → 答案 **C（4）** ✔。
（素材解析：主存第 0、8、16… 块映射到 Cache 第 0 组，第 4 块映射到第 4 组。）

(b) **2009/21**：访存 1000 次，**缺失 50 次** → $p=(1000-50)/1000=95\%$，答案 D ✔（陷阱：题干给的是缺失次数）。

**例 3-4（组相联完整地址划分 + 命中判断，自编可复核，本章重点）**
设主存按字节编址、地址 **16 位**（64 KB），Cache 数据区 **2 KB**，块大小 **16 B**，**2 路组相联**。
- 块内地址 $b=\log_2 16=4$ 位；行数 $=2048/16=128=2^7$；组数 $=128/2=64=2^6$ ⇒ 组号 $q=6$ 位；标记 $=16-6-4=6$ 位。
- **地址格式**：`标记(6) | 组号(6) | 块内地址(4)`，共 16 位。

取主存地址 $A=1234\text{H}=0001\,0010\,0011\,0100_2$：
- 主存块号 $=\lfloor0\times1234/16\rfloor=0\times123=291$；
- 块内地址 $=A\bmod16=4$（`0100`）；
- 组号 $=291\bmod64=35$（`100011`，验证 $291=4\times64+35$ ✔）；
- 标记 $=\lfloor291/64\rfloor=4$（`000100`）；
- 反验：$4\times64\times16+35\times16+4=4096+560+4=4660=1234\text{H}$ ✔。

**命中判断过程**：① 用组号 `100011`=35 定位 Cache 第 **35 组**（该组有 2 行）；② 把主存标记 `000100` 与该组两行的标记**并行比较**；③ 若某一行标记 $=$ `000100` **且有效位 $=1$**，则命中，再用块内地址 `0100`=4 从该行 16 字节中选出第 4 字节；④ 若两行标记都不匹配或有效位为 0，则**缺失**，从主存调入第 291 块装入第 35 组；组内 2 行已满时按 LRU 换出「最久未用」的那一行（换出前若为写回法且 dirty=1，须先回写主存）。

**例 3-5（2010/44 综合：直接映射 Cache 总容量、行号、命中率）**
主存 256 MB 按字节编址（地址 28 位），指令/数据 Cache 分离，各 8 行、行大小 64 B，数据 Cache **直接映射**；`int` 为 32 位补码，数组 `a[256][256]` 行优先、首地址 320。
- (1) 地址 28 位、块内 $\log_264=6$ 位、行号 $\log_28=3$ 位 → 标记 $=28-6-3=19$ 位；加 1 位有效位共 20 位 $=2.5$ B。
  **数据 Cache 总容量** $=8\times(64+20/8)=8\times66.5=\mathbf{532\ \text{B}}$ ✔。
- (2) 每元素 4 B：`a[0][31]` 地址 $=320+31\times4=444$，所在块号 $\lfloor444/64\rfloor=6$，行号 $=6\bmod8=\mathbf{6}$ ✔；
  `a[1][1]` 地址 $=320+256\times4+1\times4=1348$，块号 $\lfloor1348/64\rfloor=21$，行号 $=21\bmod8=\mathbf{5}$ ✔。
- (3) 数组共 $256\times256\times4=2^{18}$ B，占 $2^{18}/64=2^{12}$ 个主存块，共访问 $2^{16}$ 次。
  程序 A 逐行访问：每块 16 个 int，首元素缺失、其余 15 个命中 → 命中率 $=\dfrac{2^{16}-2^{12}}{2^{16}}=\dfrac{15}{16}=\mathbf{93.75\%}$ ✔。
  程序 B 逐列访问：Cache 总容量 $64\times8=512$ B，数组一行为 $256\times4=1$ KB，恰为 Cache 容量 2 倍，不同行的同列元素映射到同一行而不断互相替换 → **每次都不命中，命中率 0**。故 A 执行时间更短 ✔。

**例 3-6（2012/17：2 路组相联 + LRU 命中次数，含真题口径说明）**
按字编址，Cache 4 行、块大小 1 字，2 路组相联 → 2 组，LRU；访问序列 `0,4,8,2,0,6,8,6,4,8`，初始空。
素材（真题）解析采用的分组口径：主存地址 `0~1、4~5、8~9` → 第 0 组，`2~3、6~7` → 第 1 组（见 3.2 详解 G 的口径警示）。按此口径：

| 访问 | 0 | 4 | 8 | 2 | 0 | 6 | 8 | 6 | 4 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 落在组 | 0 | 0 | 0 | 1 | 0 | 1 | 0 | 1 | 0 | 0 |

- 第 0 组（2 行 LRU）：`0`缺→[0]；`4`缺→[0,4]；`8`缺(汰0)→[4,8]；`0`缺(汰4)→[8,0]；`8`**命中**→[0,8]；`4`缺(汰0)→[8,4]；`8`**命中** → 2 次命中。
- 第 1 组（2 行 LRU）：`2`缺→[2]；`6`缺→[2,6]；`6`**命中** → 1 次命中。

合计 **3 次命中**，答案 **C** ✔。

**例 3-7（平均访问时间两种口径，自编可复核）** 设 $p=95\%$，$T_c=10\,\text{ns}$，$T_m=100\,\text{ns}$。
- 并行访问口径（素材公式）：$T_a=pT_c+(1-p)T_m=0.95\times10+0.05\times100=9.5+5=\mathbf{14.5\,\text{ns}}$。
- 串行口径（命中时间 + 缺失代价）：$T_a=T_c+(1-p)T_m=10+0.05\times100=\mathbf{15\,\text{ns}}$。
- 若按 8 套卷题给「命中时间 2 周期、缺失损失 160 周期」、$p=95\%$：$T_a=2+0.05\times160=2+8=\mathbf{10}$ 个时钟周期。
三者数值不同，根源在假设不同，做题必须先看题干口径。

**例 3-8（多模块低位交叉带宽，2012/43(4)）** 主存采用 **4 体低位交叉**，每 $1/4$ 存储周期启动一体，每体存储周期 $50\,\text{ns}$，存储器总线宽 32 位 $=4$ B。
$$\text{最大带宽}=4\times\frac{4\,\text{B}}{50\,\text{ns}}=\frac{16\,\text{B}}{50\times10^{-9}\,\text{s}}=3.2\times10^{8}\,\text{B/s}=\mathbf{320\,\text{MB/s}}$$ ✔
同题前半（2012/43）：主频 80 MHz、$CPI=4$ → $\text{MIPS}=80/4=20$；每秒指令 20 M、平均每条访存 1.5 次 → 每秒访存 30 M 次；命中率 99% → 每秒 Cache 缺失 $=30\text{M}\times1\%=300\text{k}$ 次；每次缺失调 16 B → 主存带宽至少 $16\text{B}\times300\text{k}/\text{s}=4.8\,\text{MB/s}$ ✔；缺页（在缺失访主存时）$300000\times0.0005\%=1.5$ 次/秒；页 4 KB、磁盘接口缓冲 32 位 → 每秒 DMA 请求 $\ge 1.5\times4096/4=1536$ 次 ✔。

**例 3-9（2011/44：虚存 + TLB + Cache 完整地址变换）** 按字节编址，虚地址空间 16 MB、主存 1 MB、页 4 KB；Cache 直接映射 8 行、块 32 B。
- 虚地址 $=\log_2 16\text{M}=24$ 位，高 $24-12=\mathbf{12}$ 位为虚页号（页内偏移 $\log_2 4096=12$ 位）；物理地址 $=\log_2 1\text{M}=20$ 位，高 $20-12=\mathbf{8}$ 位为页框号。
- 物理地址划分（Cache 直接映射）：块内 $\log_232=5$ 位（最低 5 位）、行号 $\log_28=3$ 位（中间 3 位）、标记 $20-5-3=\mathbf{12}$ 位（最高 12 位）。
- 虚地址 `001C60H`：虚页号 $=001\text{H}$，查页表有效位 $=1$、页框号 $=04\text{H}$ → 拼接页内偏移得物理地址 $\mathbf{04C60H}$。
  访问 Cache：物理地址 `04C60H` 的行号 $=011\text{B}=3$、标记 $=04\text{C}\text{H}$；第 3 行有效位 $=1$ 但标记 $=105\text{H}\ne04\text{C}\text{H}$ → **Cache 不命中** ✔。
- TLB：4 路组相联共 8 项 → 组数 $=8/4=2$（组号 1 位）；虚页号高 11 位为 TLB 标记、最低 1 位为组号。虚地址 `024BACH` → 虚页号 $=024\text{H}=0000\,0010\,0100_2$，标记 $=012\text{H}$、组号 $=0$；第 0 组中存在有效位 1、标记 $=012\text{H}$ 的项 → **TLB 命中，页面在主存中** ✔。

### 3.4 易错点与 408 真题考点

| 易错点 | 正确结论 |
| --- | --- |
| DRAM 不需刷新 / SRAM 需刷新 | 反过来：SRAM 触发器**无需刷新**，DRAM 电容漏电**必须刷新** |
| 刷新按字节/按单元 | 按**行**进行，读出后原样写入 |
| 平均访问时间只有一个公式 | 并行用 $pT_c+(1-p)T_m$；串行用 $T_c+(1-p)\times$ 缺失代价 |
| 直接映射取「主存地址低 $c$ 位」作行号 | 取**主存块号**低 $c$ 位，必须先除块大小求块号 |
| 命中只需标记相等 | 还须**有效位 $=1$** |
| 全相联无需标记 | 全相联标记最长（$=A-b$ 位） |
| Cache 总容量只算数据区 | 还要加每行的标记位、有效位（写回加 dirty、LRU 加计数位），且位数要折算成字节 |
| 写回法每次写都更新主存 | 只写 Cache 并置 dirty=1，**换出时**才回写 |
| Cache 与虚存目的一样 | Cache 匹配**速度**，虚存解决**容量**（兼隔离保护、共享） |
| TLB 命中而 Page 未命中 | 不可能：TLB 是 Page 的副本，TLB 命中 ⇒ Page 必命中 |
| 交叉编址用高位作片选 | 连续编址高位片选；**低位交叉**用低位作片选、轮流启动，带宽提高 $n$ 倍 |
| 组相联公式死套 | 个别真题采用不同「分组」口径（2009/14 解析已警示），以该题解法为准 |

**真题佐证（年份明确者）：**
- **2009/14**（16 块 2 路组相联、块 32 B、129 号单元）→ 组号 4，答案 C。
- **2009/15**（ROM 4 KB + RAM 60 KB 芯片数）→ **2、30**，答案 D。
- **2009/21**（缺失 50 次 / 1000 次）→ 命中率 **95%**，答案 D。
- **2010/15**（`2K×4` 组 `8K×8`，`0B1FH`）→ 最小地址 **0800H**，答案 D。
- **2010/16**（RAM/ROM 四叙述）→ Ⅲ「都可作 Cache」错、Ⅳ「都需刷新」错（ROM 不需刷新）→ **仅 Ⅰ、Ⅱ**，答案 A。
- **2010/17**（TLB/Cache/Page 命中组合）→ 「TLB 命中、Cache 命中、Page 未命中」不可能，答案 D。
- **2010/44**（数据 Cache 总容量 / 两个行号 / A、B 命中率）→ **532 B**、**6 与 5**、**93.75% 与 0**，A 更快。
- **2011/14**（不采用随机存取方式）→ **CD-ROM**（光盘为串行/直接存取），答案 B；EPROM、DRAM、SRAM 均随机存取。
- **2011/15**（64 MB 地址空间，MAR 位数）→ **26 位**，答案 D（按主存地址空间算，不是按实际装机 32 MB 算）。
- **2011/44**（虚存/Cache/TLB 综合）→ 物理地址 `04C60H`、Cache 不命中、TLB 命中（见例 3-9）。
- **2012/16**（闪存 Flash 叙述）→ 错在「读写速度一样快」（写比读慢），答案 A；闪存非易失、随机访问、属 ROM 家族。
- **2012/17**（2 路组相联 LRU 命中次数）→ **3 次**，答案 C（见例 3-6）。
- **2012/43**（MIPS、缺失次数、主存带宽、缺页、DMA 请求、4 体交叉带宽）→ 20 / 300k / 4.8 MB/s / 1.5 次 / 1536 次 / 320 MB/s。
- **王道 8 套卷（模拟）**：8 路组相联 L1 Cache 的标记/组号/块内划分；全相联 + 回写 Cache 总容量（标记位 + 有效位 + dirty 位逐行折算）；8 路组相联比较器个数与「一个主存地址比较总次数」；4 路组相联 LRU + 回写 + 命中时间 2 周期/缺失损失 160 周期的平均访存时间；「提高 Cache 关联度一定能降低缺失率」为**错误**说法（存在抖动式缺失）。

## 第4章 指令系统（指令格式、扩展操作码、寻址方式、CISC与RISC、标志位）

### 4.1 知识体系

**一、指令系统设计原则**：**完备性**（功能齐全）、**兼容性**（系列机向下兼容）、**均匀性**（能处理多种数据类型）、**可扩充性**（留有余地）。

**二、指令格式**

$$\text{指令} = \text{操作码}\ [\,+\ \text{地址码}\,]\qquad(\text{地址码不一定是地址})$$

指令一般为整数个字节；可能全部指令长度固定、操作码长度固定、或指令与操作码都固定、或**都不固定**。
- **定长**：方便地址计算、取指和译码；**变长（扩展）**：紧凑、节约存储空间。
- **零地址指令**：或是无操作数（不需地址），或是操作数隐含在**堆栈**中，地址由栈指针给出。
- **寄存器数量多**：可减少访存、提高性能，但会增加指令长度、增加芯片成本。

**扩展操作码（变长操作码）**：素材指出「变长（扩展）—紧凑，节约存储空间」，其具体实现就是在**指令字长固定**时让操作码长度可变：地址数多的指令用较短操作码，把若干短码点保留为「扩展窗口」，用它们把腾出的地址字段改作更长指令的操作码，从而在有限字长内编码更多指令。设计约束是**任一短操作码不能是长操作码的前缀**（前缀码，保证唯一可译）。编码空间计数见 4.3 例 4-1。

**三、操作数类型**：地址/指针（用无符号整数表示）、有符号整数、浮点数、十进制数、字符串、逻辑值。

**四、寻址方式（重点，须逐一写出有效地址 EA）**

| # | 寻址方式 | 示例 | 有效地址 / 说明 |
| --- | --- | --- | --- |
| 1 | 立即（数）寻址 | `ADD #FFH` | 操作数就在指令中，无需访存 |
| 2 | 直接寻址 | `MOV AL, FFH` | $EA=A$ |
| 3 | 间接寻址（指针） | `MOV AL, [FFH]` | $EA=(A)$，需**多次访存** |
| 4 | 寄存器寻址 | `ADD AL` | 操作数在寄存器中，$EA=R$ |
| 5 | 寄存器间接 | `MOV EAX, [ECX]` | $EA=(R)$，可**扩大寻址范围** |
| 6 | 变址寻址 | `MOV AL, [SI*Size+1000H]` | $EA=(I)+A$；$1000\text{H}$ 为数组首址、$SI$ 为循环变量、$Size$ 为元素大小，**常用于循环中访问数组** |
| 7 | 相对寻址 | `JMP FFH` | $EA=(PC)+A$，$A$ 为**有符号**偏移量，**基址隐含由 PC 给出**；用于指令跳转、浮动子程序 |
| 8 | 基址寻址 | — | $EA=(\text{Base})+A$，**基址固定、$A$ 可变**；用于进程重定位/分段 |
| 9 | 其他 | — | 隐含累加器寻址、堆栈（栈顶）、位寻址、块寻址、串寻址（首地址 + 长度/末地址/尾标志） |

变址与间址结合：**前变址** $EA=((I)+A)$（先变址后间址，是一个指针数组）；**后变址** $EA=(I)+(A)$（先间址后变址，$A$ 为指针的指针）。
**变址、基址、相对三者统称「偏移寻址」**——$EA=$ 某寄存器内容 $+$ 形式地址 $A$，区别只在寄存器来源（变址寄存器 / 基址寄存器 / PC）。

**五、操作类型**：数据传送（寄存器/主存/栈顶间）、运算（算术与逻辑）、移位（算术/逻辑左移低位补 0、算术右移高位补符号、逻辑右移高位补 0、半字交换）、串处理（查找/传送/比较）、I/O 操作（CPU 与接口交换数据、状态、命令）、程序流程控制（条件/无条件转移、调用、返回）、系统控制（停机、中断、模式切换、开关中断、空操作，**一般为特权指令**）。

**六、标志位 / 条件码（Flags）**

| 标志 | 含义 |
| --- | --- |
| NF/SF | 符号位，结果为负置 1 |
| VF/OF | 溢出位，结果溢出置 1 |
| CF | 进位/借位标志，产生进位/借位置 1 |
| ZF | 零位，结果为 0 置 1 |

条件转移指令据此判断大小关系（先做减法 $a-b$）。**无符号数**比较（素材给出的逻辑式）：

$$a=b \Leftrightarrow ZF;\qquad a>b \Leftrightarrow \overline{CF}\cdot\overline{ZF};\qquad a\le b \Leftrightarrow CF+ZF;\qquad a<b \Leftrightarrow CF\cdot\overline{ZF};\qquad a\ge b \Leftrightarrow \overline{CF}+ZF$$

其中 $A+B$ 为逻辑或、$A\cdot B$ 为逻辑与、上划线为取反；$CF=1$ 表示 $a-b$ 有借位（即 $a<b$）。**有符号数**比较还必须考虑溢出位 $OF$ 与符号位 $SF$。

**七、按地址码指定风格分类**：累加器型（早期）、堆栈型（JVM、CLI）、通用寄存器型（x86）、**Load/Store 型**（也算通用寄存器型，但限制访存方式，RISC）。

**八、CISC 与 RISC**

| | CISC | RISC |
| --- | --- | --- |
| 指令 | 系统复杂、指令多、寻址方式多、格式多 | 数量少，只含常用简单指令；格式规整 |
| 指令周期 | 长，且各指令周期**差距大** | 多数单周期，规整 |
| 风格 | — | **Load/Store 型**，大量通用寄存器 |
| 执行 | — | **流水线**方式执行 |
| 控制器 | **微程序控制** | **组合逻辑（硬连线）控制** |
| 编译优化 | 较难 | 有利于编译优化 |

二者相互融合：RISC 随功能扩展日趋复杂；CISC 采用微指令、吸收 RISC 优点实现流水线，又保持指令集兼容。

### 4.2 核心考点详解

**详解 A：相对寻址必须先算「取指后的 PC」。** 相对寻址 $EA=(PC)+A$，而 $PC$ 在取指过程中**已经自增**（指向下一条指令），不是转移指令本身的首地址。2009/16：转移指令 2 字节、每取 1 字节 PC+1、指令位于 2000H → 取指后 $PC=2002\text{H}$，故 $EA=2002\text{H}+06\text{H}=2008\text{H}$。若误用 2000H 会得 2006H（干扰项 A）。

**详解 B：偏移寻址三者辨析。** 共同形式 $EA=(\text{Reg})+A$，但：变址寻址中 **$I$ 可变、$A$ 固定**（数组首址），面向**程序员**写循环；基址寻址中 **Base 固定、$A$ 可变**，面向**操作系统**做重定位/分段；相对寻址的寄存器**隐含是 PC**，$A$ 是有符号位移量。三者统称偏移寻址，而**间接寻址不需要寄存器**（$EA=(A)$），故「不属于偏移寻址」的答案是间接寻址（2011/16 答案 A）。

**详解 C：标志位与条件转移。** 无符号 `bgt` 的转移条件是 $\overline{CF}\cdot\overline{ZF}$（既无借位、又非相等，2011/17 答案 C）；有符号比较必须把 $OF$ 纳入判断（例如 $SF\oplus OF=1$ 表示「小于」）。$CF$ 只表示**无符号**的进位/借位，$OF$ 才表示**有符号**溢出，二者不可混用。

**详解 D：CISC/RISC 的控制器归属。** 「RISC 普遍采用微程序控制器」是**错误**说法（2009/17 答案 A）：RISC 用硬连线（组合逻辑）控制器以求单周期与流水线；微程序控制恰是 CISC 的特征。反之「硬布线控制器速度快但修改扩展困难」（2009/19 答案 D）也与之一致。

**详解 E：有利于流水线的指令系统特征。** 2011/18 三项全对（答案 D）：Ⅰ 指令格式规整且长度一致（取指/译码时间固定）、Ⅱ 指令和数据按边界对齐存放、Ⅲ 只有 Load/Store 才能访存（访存集中在一个流水段）——都是 RISC 特征，简化流水线。

### 4.3 典型计算题演算（均可手算复核）

**例 4-1（扩展操作码编码空间，按素材「变长（扩展）」思想的通用设计）**
指令字长 16 位，每个地址码 4 位；依次设计三地址、二地址、一地址、零地址指令，每种都留 1 个码点作扩展窗口。
- 三地址：`OP(4) | A1(4) | A2(4) | A3(4)`，OP 有 $2^4=16$ 个码点，留 1 个扩展 → **15 条**三地址指令。
- 二地址：扩展窗口把 $A1$ 的 4 位升为操作码 → 又 $2^4=16$ 个码点，留 1 个扩展 → **15 条**二地址指令。
- 一地址：再把 $A2$ 升为操作码 → 16 个码点，留 1 个扩展 → **15 条**一地址指令。
- 零地址：最后 4 位全部作操作码 → **16 条**零地址指令。
合计 $15+15+15+16=\mathbf{61}$ 条。
校验：总码字数 $=2^{16}=65536$；一条三地址指令占 $2^{12}=4096$ 个码字（15 条共 61440）、二地址占 $2^8=256$（15 条共 3840）、一地址占 $2^4=16$（15 条共 240）、零地址占 1（16 条共 16）；$61440+3840+240+16=65536$ ✔ 恰好用满且无前缀冲突。

**例 4-2（相对寻址，2009/16）** 见 4.2 详解 A：$PC_{\text{取指后}}=2000\text{H}+2=2002\text{H}$，$EA=2002\text{H}+06\text{H}=\mathbf{2008H}$，答案 C ✔。

**例 4-3（2010/43 指令格式与机器码完整演算）** 字长 16 位，16 位定长指令，主存 128 KB **按字编址**，格式 `OP(4) | Ms(3) | Rs(3) | Md(3) | Rd(3)`，转移采用相对寻址。
- (1) 操作码 4 位 → 最多 $2^4=\mathbf{16}$ 条指令；操作数字段 6 位 = 寻址方式 3 位 + 寄存器号 3 位 → 最多 $2^3=\mathbf{8}$ 个通用寄存器；主存 $128\text{KB}/2\text{B}=2^{16}$ 个存储单元 → **MAR 与 MDR 各至少 16 位**。
- (2) PC 与 Rn 均可表示 $0\sim2^{16}-1$，主存地址空间 $2^{16}$ → 转移目标地址范围 **0000H~FFFFH**。
- (3) `add (R4), (R5)+`：OP(加法)$=0010$；源 `(R4)` 为寄存器间接 $Ms=001$、$Rs=100$；目的 `(R5)+` 为寄存器间接自增 $Md=010$、$Rd=101$ → 机器码
  $0010\,001\,100\,010\,101_2 = 0010\,0011\,0001\,0101_2=\mathbf{2315H}$ ✔。
  执行：$((R4))=$ 地址 1234H 的内容 $=5678\text{H}$；$((R5))=$ 地址 5678H 的内容 $=1234\text{H}$；和 $=5678\text{H}+1234\text{H}=\mathbf{68ACH}$ 写回地址 5678H；`(R5)+` 使 $R5: 5678\text{H}\to\mathbf{5679H}$ ✔。故改变的只有 **R5 与存储单元 5678H**。

**例 4-4（无符号数比较标志位，自编可复核）** 8 位无符号数做 $a-b$：
- $a=200,\ b=100$：$200-100=100$，无借位 $CF=0$、$ZF=0$ → $a>b$（$\overline{CF}\cdot\overline{ZF}=1$）✔。
- $a=100,\ b=200$：$100-200$ 产生借位 $CF=1$、$ZF=0$ → $a<b$（$CF\cdot\overline{ZF}=1$）✔。
- $a=b=100$：$ZF=1$、$CF=0$ → $a=b$ ✔。

### 4.4 易错点与 408 真题考点

| 易错点 | 正确结论 |
| --- | --- |
| 相对寻址用指令首地址作 PC 基值 | 用**取指后已自增的 PC**（2009/16：2002H 而非 2000H） |
| 间接寻址属于偏移寻址 | 偏移寻址 = 变址/基址/相对（都带寄存器）；**间接寻址不是**（2011/16） |
| 基址与变址谁可变 | 变址：$I$ 变 $A$ 固定；基址：Base 固定 $A$ 变 |
| RISC 用微程序控制器 | RISC 用**硬连线（组合逻辑）**；微程序是 CISC（2009/17） |
| CISC 更易编译优化 | 恰恰相反，RISC 利于编译优化 |
| 系统控制指令是普通指令 | 一般为**特权指令** |
| $CF$ 判断有符号溢出 | $CF$ 是无符号进位/借位；有符号溢出看 $OF$ |
| 零地址指令一定无操作数 | 也可能操作数**隐含在堆栈**中（栈指针给地址） |
| 寄存器越多越好 | 减少访存但**增加指令长度与芯片成本** |

**真题佐证（年份明确者）：**
- **2009/16**（2 字节相对转移、2000H、位移 06H）→ **2008H**，答案 C。
- **2009/17**（RISC 错误叙述）→ 「普遍采用微程序控制器」错，答案 A。
- **2009/19**（硬布线控制器特点）→ 速度快、修改扩展难，答案 D。
- **2010/20**（全为总线标准的选项）→ ISA、EISA、PCI、PCI-Express，答案 D（CRT/CPI/RAM/MIPS 不是总线标准）。
- **2010/43**（16 位定长指令格式）→ 16 条指令 / 8 个寄存器 / MAR、MDR 各 16 位 / 目标 0000H~FFFFH / 机器码 **2315H** / R5→5679H、5678H 单元→68ACH。
- **2011/16**（不属于偏移寻址）→ **间接寻址**，答案 A。
- **2011/17**（无符号 `bgt` 条件）→ $\overline{CF}\cdot\overline{ZF}$，答案 C。
- **2011/18**（有利于指令流水线的特点）→ Ⅰ、Ⅱ、Ⅲ 全对，答案 D。
- **2011/19**（指令周期叙述）→ 错误项 C「空操作指令任何寄存器都不变」（PC 仍 +1）。
- **2011/20**（系统总线数据线上不可能传输）→ **握手（应答）信号**，答案 C；指令、操作数、中断类型号都可走数据线。
- **2011/21**（5 级中断屏蔽字）→ 答案 D `01010`（详见第 7 章）。
- **王道 8 套卷（模拟）**：16 位操作数采用基址寻址 + 小端的有效地址计算；「指令字长/操作码长度/地址码长度」的组合辨析；扩展操作码编码空间计数（见例 4-1）。

## 第5章 中央处理器（CPU结构、数据通路、控制器硬连线/微程序、指令周期、微指令编码）

> 说明：按 408 大纲，**指令流水线**及其加速比、吞吐率、冒险归入本章；素材将其单列为「第7章 指令流水线」，此处合并精读。

### 5.1 知识体系

**一、CPU 的功能与取指执行过程**

- 基本功能：① 控制指令的**执行顺序**；② 控制指令执行**操作**（what）；③ 控制操作**时序**（when）；④ 对数据进行运算；⑤ 对存储器或 I/O 访问进行控制；⑥ 异常和中断处理。
- 执行一条指令的 7 步：① 指令地址计算；② 取指令（**定长指令通常一次访存；变长指令可能需多次访存**）；③ 操作码译码、生成控制信号；④ 源操作数地址计算、取操作数；⑤ 数据运算；⑥ 目的操作数地址计算、存数；⑦ 检查是否发生中断，如有则转入中断处理程序。

**二、CPU 基本结构 = 数据通路 + 控制单元**

- **数据通路**包含**组合逻辑单元**（加法器、ALU、扩展器〔0 扩展/符号扩展〕、多路选择器、状态单元读逻辑）与**状态单元**（触发器、寄存器，保存中间/最终结果；某一时刻输出可与输入不同，**再经一个时钟边沿后**输入才传到输出）。
- 数据通路结构演进：累加器+内存（如 IAS）→ 总线结构（单总线/多总线，总线与部件之间一般通过寄存器和三态门隔离）→ **现代专用数据通路结构**。
- **控制单元**：对取出的指令译码，与条件码/机器状态/时序信号组合，生成对数据通路的控制信号；含 PC、IR、指令译码器、时序信号产生部件、操作控制信号形成部件、总线控制逻辑、中断机构。

**三、寄存器分类（高频辨析）**

| 类别 | 寄存器 |
| --- | --- |
| **用户可见** | 通用寄存器（数据/地址）、地址寄存器（段/变址/基址/堆栈指针）、**PC/EIP（存放下一条指令地址）** |
| **部分可见** | 程序状态字 PSWR / 标志寄存器（由 CPU 依结果自动设置，用户只能隐含读部分、不能直接改） |
| **不可见** | **IR**（正在执行的指令）、**MAR**（将要访问的存储单元地址）、**MDR**（读出/写入的数据）、中断请求寄存器、进程控制块指针、页表基址指针 |

每条指令功能不同，数据经过的部件与路径可能不同，但**取指阶段对所有指令都一样**。

**四、时序与控制器实现**

早期采用**机器周期、节拍、脉冲**三级时序；现代计算机**没有机器周期概念，一个节拍即一个脉冲**，数据通路用时钟信号定时，在**时钟边沿**状态单元写入信息。

| | 硬连线（组合逻辑）控制器 | 微程序控制器 |
| --- | --- | --- |
| 思想 | 每个时钟周期的控制信号取值组合看作一个**状态**，全部指令执行过程用**有限状态转换图**描述 | 每个时钟周期的控制信号取值组合看作一个 0/1 序列（每位对应一个**微命令**），若干微命令组成**微指令**，一条机器指令由若干微指令（**微程序**）完成 |
| 实现 | PLA 组合逻辑生成控制信号 + 状态寄存器实现状态转换 | 微程序存于**控制存储器 CM（只读）**；PLA/ROM 生成每条指令微程序首地址；**微程序定序器**控制执行；每来一个时钟执行一条微指令 |
| 特点 | **速度快**，适合简单/规整指令系统（RISC）；**修改扩展困难** | 结构标准化程度高、**便于扩充**；**速度较慢**（每条指令都要访控存） |

**微程序定序器**（确定下条微指令地址）：**计数器法（μPC）**、**断定法（下址字段法，显式给出下条微指令地址）**。

**微指令编码方式**：
- **直接控制法**：控制字段每一位代表一个微命令，置 1/0 即开/关控制门；全 0 对应 `nop`；微操作码长度 = 微命令个数，**无需译码、速度快、便于并行**，但**浪费码位**。
- **字段直接编译法**：同一微周期内不会同时打开的**互斥**微命令编成一组（一个字段）用二进制编码表示；**相容**微命令放在**不同字段**；每个字段一般**留出一个状态表示本字段不发任何微命令**。
- **字段间接编译法**：在字段直接编译基础上，规定某字段的某些微命令兼由另一字段某些微命令解释，进一步缩短字长，**极少采用**。

字段位数通式（$k$ 个互斥微命令，需留 1 个空状态）：
$$\text{该字段位数}=\lceil \log_2 (k+1)\rceil$$

**五、异常与中断（内中断）**

异常分三类：**故障**（由正在执行的指令产生，如溢出、除数为 0、非法操作、缺页；处理后有的可继续、有的只能终止进程）、**陷阱**（预先安排，如断点、单步跟踪、系统调用）、**终止**（严重硬件故障，只能终止系统或重启）。**外部中断**：外设或其他 CPU 通过中断请求线发出的请求，**与当前指令无关**，是一种 I/O 控制方式。异常处理过程：① 保护断点和程序状态（PC 和 PSW）；② 识别异常事件并转入处理；③ 关中断。

**六、指令流水线**

把指令解释细分为 5 个子过程：**取指 IF、译码 ID、取数 OF、执行 EX、写回寄存器 WB**（真题另有 IF/ID/EX/M/WB 划分）。上一指令进入第 2 段时，第 1 段即开始处理下一条；理想时 5 个部件同时处理 5 条不同指令。
- 每段执行时间以**最慢流水段**为准定为一个时钟周期；理想情况下每个时钟进 1 条、出 1 条，$\mathbf{CPI=1}$。
- 流水段之间是**组合逻辑部件**，段间必须加**流水段寄存器**，记录控制信号、指令、新 PC、操作数、结果、异常信息、读/写口地址、存储地址等；译码所得控制信号随数据同步向后传送。

**流水线性能指标（核心公式）**

设 $m$ 段、$n$ 条指令、时钟周期 $\tau$（由最慢段决定）：

$$T_{\text{流水线}} = (m+n-1)\,\tau,\qquad T_{\text{非流水线}} = n\cdot m\cdot\tau$$

$$\boxed{TP = \frac{n}{(m+n-1)\tau}}\qquad \boxed{S = \frac{T_{\text{非流水线}}}{T_{\text{流水线}}}=\frac{n\,m}{m+n-1}}$$

理想情况（$n\gg m$）：$S\to m$，$TP\to 1/\tau$，即**吞吐率/加速比理想为流水段数 $m$ 倍**。注意素材特别指出：由于按最慢段定时钟、加上流水段寄存器额外开销，**流水线方式下单条指令的执行时间反而更长了**，提高的是**吞吐率**而非单条指令速度。

**流水线局限性**：并非每条指令都能划分成相同段数（按最复杂指令划分后某些段是 `nop`）；各段时间不均（按最长定时钟导致时间浪费）；**流水段寄存器额外开销随深度增大**；资源冲突/数据相关/控制相关导致**阻塞**。

**三类冒险与解决策略**：
- **结构冒险（资源冲突）**：多条指令同时要求同一功能部件 → 规定每个功能部件一条指令只用一次、只在特定阶段使用；**指令 Cache 与数据 Cache 分开**。
- **数据冒险（数据相关）**：前指令目的操作数是后指令源操作数 → 编译器插入 `nop`；硬件检测后插入「气泡」阻塞；**转发（旁路）**把前面指令中途得到的结果直接送到需要处（解决 RAW、WAW）；**load-use** 需「**阻塞 + 转发**」。
- **控制冒险（控制相关）**：转移指令（分支/调用/返回/跳转，需算目标地址，引起**分支冒险**）与异常/中断 → 插入 `nop`（条数 = 延迟损失时间片）、插入气泡阻塞、**分支预测**（静态固定预测 / 动态按历史调整预测位，动态成功率高得多）、**延迟分支**（把与转移无关的指令放入**延迟槽**，不够用 `nop` 填满，调整在编译阶段完成）。
- 异常/中断在流水线中的处理：一般只把异常原因与断点记入特定寄存器，指令继续流到**最后阶段**再检测，若有则刷新流水线转入中断处理。

**高级流水线**：**超流水线**（划分更细、级数更多，**时间**上并行）；**多发射流水线 / 超标量**（同时发射多条、多功能部件并行，**空间**上并行，$\mathbf{CPI<1}$；两大任务「指令打包」与「冒险处理」）；**静态多发射**（编译器静态完成，即 **VLIW 超长指令字**，Intel IA-64 / EPIC，过度依赖编译器）；**动态多发射**（硬件执行时动态确定发射）；**动态流水线调度**（相关性检测 + 动态分支预测，投机地**乱序执行**，阻塞时到后面找无依赖指令提前执行）。

### 5.2 核心考点详解

**详解 A：硬连线 vs 微程序的判断链。** 题干出现「速度快、规整、RISC、不易扩充」→ 硬连线；出现「控存 CM、微指令序列、易扩充、CISC、速度慢」→ 微程序。2009/19 答案 D 即「硬布线速度快、修改扩展难」；素材解析点明原因：硬布线速度取决于电路延迟，微程序采用存储程序原理、每条指令都要访控存。

**详解 B：字段直接编译法的位数计算。** 关键是「互斥微命令同字段、相容微命令不同字段」+「每段留 1 个空状态」。故 $k$ 个微命令的一类需 $\lceil\log_2(k+1)\rceil$ 位，而不是 $\lceil\log_2 k\rceil$ 位——漏掉「+1」是 2012/18 的主要失分点。

**详解 C：流水线时钟周期由最慢段决定。** 四段 90/80/70/60 ns 必须取 90 ns（2009/18 答案 A）；否则 90 ns 段的功能无法在一个周期内完成。这也是「单条指令执行时间变长」的根源。

**详解 D：数据相关的阻塞来源。** 2012/44(3)：`I3 ADD R1,R2` 与 `I1 LOAD R1,[a]`、`I2 LOAD R2,[b]` 都存在数据相关，必须等两条 LOAD 把结果**写回寄存器**后 I3 才能读寄存器 → **I3 的 ID 段被阻塞**；而 `I4` 的前一条 I3 在 ID 被阻塞，故 **I4 的 IF 段随之被阻塞**（按序发射、按序完成的连锁效应）。

**详解 E：加速比为何达不到理想值 $m$。** 公式 $S=\dfrac{nm}{m+n-1}$ 中，$n$ 有限时 $S<m$；实际还有气泡、阻塞、流水段寄存器开销，故实测加速比更低。但理想极限（$n\to\infty$）确为 $m$，与素材「理想情况为 m 倍」一致。

### 5.3 典型计算题演算（均可手算复核）

**例 5-1（2009/18 流水线时钟周期）** 四段耗时 $90,80,70,60\,\text{ns}$（忽略段间缓存时间）→ 取最长段 $\mathbf{90\,\text{ns}}$，答案 A ✔。

**例 5-2（2012/18 微指令字段直接编码位数）** 33 个微命令构成 5 个互斥类，分别含 $7,3,12,5,6$ 个微命令；每类留 1 个「不发命令」状态，需 $\lceil\log_2(k+1)\rceil$ 位：
$$7\to\lceil\log_2 8\rceil=3;\quad 3\to\lceil\log_2 4\rceil=2;\quad 12\to\lceil\log_2 13\rceil=4;\quad 5\to\lceil\log_2 6\rceil=3;\quad 6\to\lceil\log_2 7\rceil=3$$
合计 $3+2+4+3+3=\mathbf{15}$ 位，答案 C ✔（素材解析同样给出 3、2、4、3、3 共 15 位）。

**例 5-3（加速比与吞吐率，自编可复核）** $m=5$ 段、$n=100$ 条指令、$\tau=2\,\text{ns}$（每段 2 ns）。
- 非流水线：$T_{\text{非}}=100\times5\times2=1000\,\text{ns}$。
- 流水线：$T_{\text{流}}=(5+100-1)\times2=104\times2=\mathbf{208\,\text{ns}}$。
- 加速比 $S=\dfrac{1000}{208}\approx\mathbf{4.81}$；用通式复核 $\dfrac{nm}{m+n-1}=\dfrac{100\times5}{104}=\dfrac{500}{104}\approx4.81$ ✔（理想极限为 5）。
- 吞吐率 $TP=\dfrac{100}{208\,\text{ns}}\approx4.81\times10^{8}$ 条/s；理想极限 $1/\tau=5\times10^{8}$ 条/s ✔。
- 若 $n=4$ 条：$T=(5+4-1)\tau=8\tau$，即 2012/44(2) 答案「**8 个时钟周期**」✔。

**例 5-4（2012/44 流水线阻塞与最少周期）** 5 段 IF/ID/EX/M/WB，按序发射按序完成，**无转发**、同一寄存器读写不能同周期。
- (2) 连续 4 条指令无阻塞：$4+(5-1)=\mathbf{8}$ 个时钟周期 ✔。
- (3) `x=a+b` 序列 `I1 LOAD R1,[a]; I2 LOAD R2,[b]; I3 ADD R1,R2; I4 STORE R2,[x]`：**I3 的 ID 段**因与 I1、I2 数据相关、须等结果写回才能读寄存器而阻塞；**I4 的 IF 段**因 I3 在 ID 被阻塞（前一条未前进）而连带阻塞 ✔。
- (4) `x=x*2+a`（unsigned int）指令序列 `I1 LOAD R1,[x]; I2 LOAD R2,[a]; I3 SHL R1（或 ADD R1,R1）; I4 ADD R1,R2; I5 STORE R2,[x]` → 最少 **17 个时钟周期** ✔（素材给出的流水线时空图结论）。

**例 5-5（2009/44 数据通路执行阶段控制信号，完整演算）** 16 位机，`ADD (R1), R0` 功能 $(R0)+((R1))\to(R1)$；取指/译码已给 C1~C4（`MAR←(PC)`、`MDR←M(MAR), PC←(PC)+1`、`IR←(MDR)`、译码）。执行阶段需先取 $((R1))$ 再相加再写回，注意 **MAR 中始终是 R1 所指地址**：
| 时钟 | 功能 | 有效控制信号 |
| --- | --- | --- |
| C5 | $MAR\leftarrow(R1)$ | `R1out, MARin` |
| C6 | $MDR\leftarrow M(MAR)$ | `MemR, MDRinE` |
| C7 | $A\leftarrow(MDR)$ | `MDRout, Ain` |
| C8 | $AC\leftarrow(A)+(R0)$ | `R0out, Add, ACin` |
| C9 | $MDR\leftarrow(AC)$ | `ACout, MDRin` |
| C10 | $M(MAR)\leftarrow(MDR)$ | `MDRoutE, MemW` |
规律：流入寄存器 $X$ 用 `Xin`、流出用 `Xout`；另有 `PC+1`、`Add`、`MemR/MemW` 等特殊信号。素材指出**答案不唯一**：若在 C6 同时完成 $(R0)\to A$（`MemR, MDRinE, R0out, Ain`）不发生总线冲突，可省 1 个节拍。

**例 5-6（数据相关插入 nop 的通用分析）** 五段流水、不采用转发、**前半周期写寄存器堆 / 后半周期读**：`I1`、`I2` 的结果都被 `I3` 使用。无 nop 时 I1 的 WB 在周期 5、I2 的 WB 在周期 6、I3 的 ID 在周期 4；要让 I3 读到两条结果，ID 最晚须在周期 6（I2 周期 6 前半写、I3 周期 6 后半读）。故 ID 从周期 4 推迟到周期 6，需阻塞 2 拍 → 在 I3 前插入 **2 条 `nop`**。一般结论：插入 `nop` 的条数等于**延迟损失时间片**；采用转发后 RAW 可零阻塞，但 load-use 仍须「阻塞 + 转发」。

### 5.4 易错点与 408 真题考点

| 易错点 | 正确结论 |
| --- | --- |
| 流水线提高单条指令速度 | 提高的是**吞吐率**；单条指令执行时间反而**变长**（最慢段 + 寄存器开销） |
| 时钟周期取各段平均或最短 | 取**最慢（最长）段** |
| 加速比恒为 $m$ | 理想极限为 $m$，实际 $S=\dfrac{nm}{m+n-1}<m$，还受气泡/阻塞影响 |
| 字段直接编码位数 $\lceil\log_2 k\rceil$ | 须 $\lceil\log_2(k+1)\rceil$（留空状态） |
| 互斥微命令放不同字段 | **互斥同字段、相容不同字段** |
| 转发能解决全部数据冒险 | 转发解决 RAW/WAW；**load-use 需阻塞 + 转发** |
| 延迟槽里放相关指令 | 只能放**与转移无关**的指令，不够用 `nop` 填满 |
| PC 存当前指令地址 | PC 存**下一条**指令地址；IR/MAR/MDR 用户不可见 |
| 汇编程序员可见 MAR/MDR/IR | 只有 **PC** 等用户可见寄存器对汇编程序员可见（2010/18） |
| 硬布线控制器易扩充 | 硬布线**难**扩充；微程序才易扩充 |

- **2009/18**（四段 90/80/70/60 ns）→ 时钟周期至少 **90 ns**，答案 A。

## 第6章 总线（分类、性能指标与带宽计算、仲裁、定时方式、总线标准）

### 6.1 知识体系

**一、总线的定义与分类**

总线是**一组设备共享的传输线**：一次只能为一个部件提供服务，其发出的信号可被其他**所有**部件接收。

| 分类维度 | 类别 |
| --- | --- |
| 按连接部件 | **内部总线**（片内）、**系统总线**（功能部件之间）、**通信总线**（主机与 I/O 或其他主机，如 USB、以太网） |
| 系统总线按传输信息 | **数据总线**（**双向**传输）、**地址总线**（**单向**）、**控制总线**（传输时钟和命令信息） |

也存在把**地址线与数据线复用**（经数据线传送地址）的设计。

**二、性能指标与带宽（核心公式）**

对**同步总线**，带宽 $B$ 与数据总线位宽 $W$、总线时钟频率 $F$、传输每个数据所需时钟周期数 $N$ 有关：

$$\boxed{B = \frac{W\cdot F}{N}}$$

$W$ 若以**字节**计则 $B$ 单位为 B/s，以**位**计则为 bit/s。等价写法：$B = W / (N\cdot T) = W\cdot F/N$，其中 $T=1/F$ 为总线时钟周期。

**三、总线事务与突发传送**

总线上一对设备间一次交换信息的过程称为**总线事务**，典型如存储器读写、I/O 读写、中断响应。一次事务包括**地址阶段**和**数据阶段**；细分又有**申请分配阶段、寻址阶段、数据传送阶段、结束阶段**。**突发（burst）传送**由**一个地址阶段 + 多个数据阶段**构成，可传送多个连续单元的数据，也称**组传送**。

一个总线事务总是在**一对主、从设备**之间传送数据；当有多个主控设备时，需要**总线裁决（仲裁）**决定谁使用总线。

**四、总线仲裁（裁决）**

**(1) 集中式**（有总线控制器/裁决器；主控设备发请求，获准后传送，完成后以某种方式通知控制器释放总线）：

| 方式 | 控制线数 | 优先级 | 特点 |
| --- | --- | --- | --- |
| **链式查询 / 菊花链**（击鼓传花） | **3 根**（总线请求、允许、忙；前 2 根用于裁决） | **靠近控制器者优先级高**（由物理位置决定） | 结构简单；不能保证公正、**可靠性低**（一处故障全链失效）、裁决速度慢 |
| **计数器定时查询**（点名报到） | $\lceil\log_2 n\rceil$ 根设备地址线 + 1 请求线 + 1 忙线 | 每次从 0 计数则**设备地址即优先级**（越小越高）；从上次选中设备开始则**优先级平等**；也可程序设初值调整 | 可靠性较高，但控制较复杂 |
| **独立请求方式**（领导说了算） | **$2n$ 根**（每设备 1 请求 + 1 允许），**无忙线** | 裁决器内有排队器，**优先级控制非常灵活** | 裁决响应快；控制逻辑与结构复杂 |

**(2) 分布式**（无中央裁决器，每个设备有自己的裁决器和请求号，竞争使用、自行裁决）：**自举式**（每设备一根请求线兼作忙线，检测较高优先级请求线空闲才可用；优先级固定、请求线多故多复用数据线）、**冲突检测式**（如以太网 CSMA/CD；控制线少、冲突多）、**并行竞争式**（$n$ 个设备用 $\lceil\log_2 n\rceil$ 根仲裁线，各设备出「仲裁号」比大小，设备与仲裁线逻辑相反；优先级灵活、裁决线少）。

$$\text{计数器定时查询设备地址线数}=\lceil\log_2 n\rceil,\qquad \text{独立请求控制线数}=2n$$

**五、总线定时方式（4 种）**

| 方式 | 机制 | 优缺点 |
| --- | --- | --- |
| **同步** | 所有设备从**公共时钟线**获得定时，协议规定每周期应完成的特定操作 | 传输速度快、接口逻辑少；**必须按最慢设备确定时钟**，适合存取时间接近的设备；**时钟偏移**使总线不能过长；无确认信号、**可靠性较低** |
| **异步** | 采用**应答（握手）**方式，需增加请求和应答线 | 有**不互锁、半互锁、全互锁（三次握手）**三种；可靠性高 |
| **半同步** | 异步 + 时钟线，握手信号总在**时钟边沿**发生 | 提高抗干扰能力 |
| **分离事务** | 设备不用总线时**立即释放**，多设备交替使用 | 完成一个事务可能需**多次获得总线**，从设备还须跟踪对方状态 |

**六、总线标准与总线结构**

- 标准：**系统总线** ISA、EISA、PCI、PCI-E（PCI-Express）；**设备总线/接口** IDE、SATA、SCSI、USB；**图形总线/接口** AGP。（2010/20 答案 D：ISA、EISA、PCI、PCI-Express 全为总线标准；CRT、CPI、RAM、MIPS 等不是。）
- 结构：**单总线**；**双总线**（主存总线 + 系统总线，或主存总线 + I/O 处理器 & I/O 总线）；**多总线**（I/O 总线 + 主存总线 + 高速 I/O 与内存间 DMA 总线；或处理器总线 + 桥接器 + 主存总线 + 高速 I/O 总线 + I/O 处理器 & 低速 I/O 总线）。

### 6.2 核心考点详解

**详解 A：带宽公式的三个量都不能漏。** $B=W\cdot F/N$ 中 $N$ 是「传输**每个数据**所需的时钟周期数」，分母常被遗忘。2009/20：$W=4$ B、$F=10$ MHz、$N=2$ → $B=4\times10^7/2=2\times10^7$ B/s $=20$ MB/s；若漏除 2 会误得 40 MB/s（干扰项 C）。

**详解 B：突发传送的时间计算。** 地址/数据线复用时，一次「主存写」事务 = 1 个地址阶段 + $k$ 个数据阶段，每阶段占 1 个时钟周期；数据阶段数 $k=\text{总数据位数}/\text{总线宽度}$。2012/19：128 位 / 32 位 $=4$，加 1 个地址阶段共 5 个周期 ×10 ns = 50 ns。

**详解 C：三种集中仲裁的「线数—优先级—可靠性」对照。** 链式查询线最少（3 根）但优先级被物理位置锁死、可靠性最低；独立请求线最多（$2n$）但优先级最灵活、响应最快；计数器定时查询介于其间，且能「从上次选中处计数」实现平等优先级。分布式并行竞争式只需 $\lceil\log_2 n\rceil$ 根仲裁线。

**详解 D：同步总线的固有矛盾。** 公共时钟必须迁就**最慢设备**，且时钟偏移限制总线长度、无应答使可靠性低——这正是高速场景转向串行差分 + 异步/半同步的原因（素材：并行总线各数据线间干扰与位不同步限制长度和频率；串行无位同步问题、差分抗干扰强、可提高时钟频率）。

### 6.3 典型计算题演算（均可手算复核）

**例 6-1（2009/20 总线带宽）** 一个总线周期并行传输 4 B，一个总线周期占 2 个时钟周期，总线时钟频率 10 MHz。
$$B=\frac{W\cdot F}{N}=\frac{4\,\text{B}\times10\,\text{MHz}}{2}=20\,\text{MB/s}$$
答案 B ✔（素材解析等价写法：2×(1/10 MHz) 秒内传 4 B，故 $4\text{B}\times10\text{MHz}/2=20\text{MB/s}$）。

**例 6-2（2012/19 突发传送时间）** 同步总线 100 MHz（$T=10$ ns），宽 32 位，**地址/数据线复用**，每传一个地址或数据占 1 个时钟周期，突发传输 128 位数据。
- 地址阶段：1 个周期 = 10 ns；
- 数据阶段数 $=128/32=4$，各占 10 ns → 40 ns；
- 总计 $10+40=\mathbf{50\,ns}$，答案 C ✔。

**例 6-3（仲裁控制线数，自编可复核）** $n=8$ 个主控设备：
- 链式查询：3 根；
- 计数器定时查询：$\lceil\log_2 8\rceil+1+1=3+2=\mathbf{5}$ 根（3 根设备地址线 + 请求线 + 忙线）；
- 独立请求：$2\times8=\mathbf{16}$ 根；
- 并行竞争（分布式）：$\lceil\log_2 8\rceil=\mathbf{3}$ 根仲裁线。

**例 6-4（带宽公式变式，自编可复核）** 总线宽 64 位 $=8$ B、时钟 200 MHz、每数据需 4 个时钟周期（含地址阶段）：
$$B=\frac{8\,\text{B}\times200\,\text{MHz}}{4}=400\,\text{MB/s}$$
若按位计：$64\,\text{bit}\times200\,\text{MHz}/4=3.2\,\text{Gbit/s}$，两者一致 ✔（$3.2\text{Gbit/s}=400\text{MB/s}$）。

### 6.4 易错点与 408 真题考点

| 易错点 | 正确结论 |
| --- | --- |
| $B=W\cdot F$ | 还要除以 $N$（每数据所需周期数） |
| 地址总线双向 | 地址总线**单向**，数据总线**双向**，控制总线传命令/时序 |
| 链式查询优先级可软件调整 | 由**物理位置**（离控制器远近）锁死，不能保证公正 |
| 独立请求有总线忙线 | **没有**忙线，靠 $2n$ 根请求/允许线 + 排队器 |
| 计数器定时查询每次都从 0 计数 | 也可从上次选中设备开始（优先级平等）或程序设初值 |
| 同步总线按最快设备定时钟 | 按**最慢设备**；且总线过长会受时钟偏移限制 |
| 异步总线速度一定慢但不可靠 | 异步用握手，**可靠性高** |
| USB 同时传多位 | USB 是**串行（差分）**总线，不能同时传 2 位（2012/20） |
| PCI 是设备总线 | PCI/PCI-E 是**系统总线**；USB/SATA/SCSI 是设备总线 |

**真题佐证（年份明确者）：**
- **2009/20**（4 B / 2 周期 / 10 MHz）→ **20 MB/s**，答案 B。
- **2010/20**（全为总线标准）→ ISA、EISA、PCI、PCI-Express，答案 D。
- **2011/20**（系统总线数据线上**不可能**传输）→ **握手（应答）信号**，答案 C；指令（取指时）、操作数、中断类型号都可经数据线传输。
- **2011/15**（MAR 位数）→ 26 位（地址总线宽度相关，见第 3 章）。
- **2012/19**（100 MHz、32 位、地址/数据复用、突发 128 位）→ **50 ns**，答案 C。
- **2012/20**（USB 错误叙述）→ 「同时可传输 2 位数据」错，答案 D；USB 支持即插即用、热插拔、级联、串行差分。
- **2012/21**（I/O 总线数据线上传输的信息）→ 命令字、状态字、中断类型号**全部**，答案 D。
- **2012/43**（4 体交叉主存最大带宽）→ 320 MB/s（见第 3 章例 3-8）。
- **王道 8 套卷（模拟）**：总线带宽与「一个总线周期内并行传输字节数」的换算；同步/异步定时方式辨析。

## 第7章 输入/输出系统（I/O接口与端口编址、程序查询/中断/DMA/通道、中断响应与优先级、DMA周期窃取）

### 7.1 知识体系

**一、外设与磁表面存储器**

输入设备（键盘、鼠标）、输出设备（显示器、打印机）和外部存储器（硬盘、光盘、U 盘、磁带）统称**外设**；特点是**异步性、实时性、多样性**。磁表面存储器的数据记录方式：

| 编码 | 规则 | 特性 |
| --- | --- | --- |
| 归零制 RZ | 正脉冲 1、负脉冲 0，bit 间电流总归零（实为 ±1、0 三态） | 记录密度低，有自同步能力 |
| 不归零-1 制 NRZ-1 | 电流翻转为 1，bit 间无间隙 | 密度高，**无自同步能力**，直流分量大、功耗大 |
| 调相制 PM | 由负到正 ↑ 为 1、由正到负 ↓ 为 0，每 bit 一次换向 | 可生成同步脉冲、自同步，即**曼彻斯特编码** |
| 调频制 FM | bit 间必有跳变，bit 内有跳变为 1、无跳变为 0（1 的频率为 0 的 2 倍） | 有自同步能力 |
| 改进调频制 MFM | 连续两个及以上 0 才在位边沿跳变，bit 内有跳变为 1、无跳变为 0 | 有自同步，**记录密度提高（倍密度），应用广泛** |

**二、I/O 接口与端口编址**

- I/O 接口功能：**数据缓冲、错误或状态检测、控制和定时、数据格式转换、与主机和设备通信**。
- 接口分类：按数据传送方式串口/并口；按灵活性可编程/不可编程；按通用性通用/专用；按设备连接总线多点/点对点；按控制方式程序控制（轮询）/中断式/DMA。
- **I/O 端口**指接口中用户可访问的寄存器：**数据端口、状态端口、命令端口**；状态与命令传送**方向相反、被访问时间一般错开，故经常复用**。
- **端口编址方式**：**独立编址**（I/O 地址空间与主存分离，需专用 I/O 指令）与**统一编址**（I/O 端口占用主存地址空间，用访存指令访问）。

**三、并行与串行传输**

通常并行传输多用于同步总线（**但不是必须**），串行多用于异步或半异步总线（也可用于同步）。并行一次传多位，但各数据线间**干扰**与长度/传输特性偏差造成**位不同步**，提高时钟频率时更严重，限制了并行总线的长度与频率，最终限制带宽；**串行无位同步问题**，若采用**差分**方式抗干扰强、传输距离长，还可充分提高时钟频率弥补位宽不足，某些场合优于并行。系统总线多根数据线是**并行**的；**USB 是串行（差分）通信总线**，以太网双绞线也是串行。

**四、四种 I/O 控制方式（核心）**

| 方式 | 机制 | CPU 参与度 |
| --- | --- | --- |
| **程序直接控制** | 无条件传送/同步（按程序定时传送，无需检测状态，适合过程控制、巡回检测）；条件传送/**程序查询**/异步（查询外设状态，有定时查询、独占查询） | CPU **全程轮询**，与设备串行工作，浪费 CPU 时间 |
| **程序中断** | 外设发**中断请求**，CPU 在**中断服务程序**中完成数据/错误处理 | 仅少量外设适用；中断次数太多时 CPU 累计开销可观 |
| **DMA** | 高速外设以成批方式与主存**直接（双向）**交换数据，由 DMA 控制器控制总线 | 仅**一块数据传送结束**才发中断请求 CPU，把 CPU 从繁杂 I/O 事务中解放 |
| **通道 / I/O 处理机** | CPU—通道—设备控制器—I/O 设备**四级连接**；通道有**专用通道指令**，可独立执行完成 I/O | 通道是**从属于 CPU 的专用处理器**，CPU 仅用 I/O 指令启动/停止/改变状态 |

**DMA 完整流程**：① 对 DMA 控制器**初始化**（CPU 执行设备驱动程序，设置主存首址、传送字数、方向等）；② 由 DMA 控制器**控制总线**在主存与高速设备之间直接交换数据，**无需 CPU 干预**；③ 传送完毕，DMA 控制器向外设接口发「DMA 传送结束」信号，并**发中断请求给 CPU**，CPU 进行 DMA 结束处理。

**DMA 与 CPU 访存冲突的三种协调方法（重点：周期窃取）**：
1. **CPU 不访存**（停止 CPU 访存）；
2. **周期挪用 / 周期窃取**：CPU 让出总线给 DMA，**DMA 总线优先级比 CPU 高**（防止高速设备丢失数据），**每次访存都要申请总线**；
3. **交替分时访问**（CPU 与 DMA 分时占用）。

$$\boxed{\text{中断响应在「一个指令周期」结束后；DMA 响应在「一个总线周期」后}}$$

DMA 还会引出**虚存跨页**与 **Cache 一致性**问题。

**五、中断响应与优先级**

- 中断系统有两种优先级：**响应优先级**（由查询程序或**硬件判优排队**决定，多个中断同时请求时选哪个响应）与**处理优先级**（由**中断屏蔽字**动态设定，反映多重/嵌套中断之间的关系）。**中断是异步的**。
- **中断隐指令**（硬件自动完成，不属于中断服务程序）：**关中断、保存断点、形成中断服务程序入口地址并送 PC**；而「保存通用寄存器内容」是在**进入中断服务程序后**首先进行的操作。
- **单级中断**（不允许嵌套）服务程序内的顺序：**保护现场 → 中断事件处理 → 恢复现场 → 开中断 → 中断返回**；其中关中断、保存断点、识别中断源由**硬件**完成。
- 素材（操作系统设备管理）补充：程序询问与中断方式仅适用少量外设；DMA 与通道都采用「设备与主存直接交换」，区别是 **DMA 要求 CPU 执行设备驱动程序启动设备并做好传送准备**，而**通道是一个相对独立的 I/O 控制系统**，CPU 发出启动命令后即接收控制权、完成全部 I/O。

**六、通道类型**

| 类型 | 适用 | 数据传输率 |
| --- | --- | --- |
| **字节多通道** | 按字节交替传送，连接多个**低速**设备 | **所有设备传输率之和** |
| **选择通道** | 高速设备，一段时间只为**单个**设备服务、成组传送 | **所接设备最大的传输率** |
| **成组通道（数组通道）** | 多台设备以**定长数据块分时**传送 | **所接设备最大的传输率** |

I/O 处理机与通道相比，**有自己的指令系统和单独的存储器**，有一定数据处理功能。

**七、缓冲与相关辨析（素材操作系统部分）**

缓冲用于匹配设备与 CPU 速度、减少中断次数；有单缓冲、双缓冲、多缓冲（循环缓冲、缓冲池）。**Cache 与 Buffer 的区别**：Cache 内数据是低速设备上数据的**一部分（备份）**，缺失时可直接访问低速存储；Buffer 内数据一般是**独有的**、是数据的**必经之路**。SPOOLING 把物理设备虚拟成多个逻辑设备（**缓存在内存，井在硬盘**）。

### 7.2 核心考点详解

**详解 A：中断响应时机 vs DMA 响应时机（最高频）。** 中断响应发生在**一条指令执行完（指令周期结束）**后，CPU 才去查询中断请求；而 DMA 响应只需**一个总线周期结束**（一次访存结束）即可插入，故 DMA 响应**更早、更频繁**，这正是为保证磁盘等高速设备不丢数据。与之配套：周期挪用中 **DMA 总线优先级高于 CPU**（2012/43(3)：若 DMA 请求得不到及时响应，I/O 数据可能丢失）。

**详解 B：响应优先级 ≠ 处理优先级。** 前者是**硬件/查询程序**在多个同时到达的中断里挑谁先被响应（固定、由排队链或编码决定）；后者是**中断屏蔽字**在中断服务程序中动态设定的「谁可以打断谁」，用于实现多重中断嵌套。2011/21 正是用屏蔽字定处理优先级：按响应优先级 $L4>L0>L2>L1>L3$，$L1$ 处理时只需屏蔽比它响应优先级低的 $L3$ 与自身 $L1$，故屏蔽字 $M_4M_3M_2M_1M_0=\mathbf{01010}$（高优先级置 0 表示开放、低优先级与自身置 1 表示屏蔽）。

**详解 C：中断隐指令的边界。** 硬件完成的是「关中断 + 保存断点 + 引出中断服务程序（入口地址送 PC）」；「保存通用寄存器」由软件（中断服务程序）完成。2012/22 答案 B（Ⅰ、Ⅲ）即据此；2010/21 答案 A 也据此——中断服务程序内的第一步是**保护现场**而非关中断/保存断点。

**详解 D：DMA 周期窃取的三个要点。** ① DMA 与 CPU 共享主存总线，冲突时 DMA 优先；② 每次挪用只传送**一个数据**（一个总线周期），故「每次访存都要申请总线」；③ 只在**成批数据传送结束**后才发一次中断，大幅降低中断次数。对比程序中断方式「每传一个字中断一次」（2009/43：0.5 MB/s、4 B/次 → 每秒 12.5 万次中断）。

**详解 E：通道三种类型的传输率公式。** 字节多通道是**求和**（多个低速设备并行交替），选择通道与成组通道是**取最大**（一段时间内独占或按块分时）。这是选择题常见陷阱。

### 7.3 典型计算题演算（均可手算复核）

**例 7-1（2011/22 程序查询方式 CPU 时间占比）** 主频 50 MHz，查询程序运行一次至少 500 个时钟周期，为保证数据不丢失每秒至少查询 200 次。
$$\text{每秒占用周期}=200\times500=100\,000,\qquad \text{占比}=\frac{100\,000}{50\times10^{6}}=0.2\%$$
答案 C ✔。

**例 7-2（2010/22 显存带宽）** 分辨率 $1600\times1200$、色深 24 bit、帧频 85 Hz，显存总带宽的 50% 用于刷新屏幕。
$$\text{刷新所需带宽}=1600\times1200\times24\times85=3916.8\ \text{Mbit/s}$$
$$\text{显存总带宽}\ge \frac{3916.8}{0.5}=7833.6\approx\mathbf{7834\ \text{Mbit/s}}$$
答案 D ✔。

**例 7-3（2009/43 中断 vs DMA，完整对照，第 1 章已列式，此处补 DMA 机理）**
- 中断方式：主频 500 MHz、$CPI=5$、每次传 4 B、服务程序 18 条指令 + 2 条开销 → 每次 100 周期；每秒中断 $0.5\text{MB}/4\text{B}=125000$ 次 → $12.5\text{M}/500\text{M}=\mathbf{2.5\%}$。
- DMA 方式：数据率升到 5 MB/s、每块 5000 B、预处理+后处理 500 周期 → 每秒 DMA $5\text{MB}/5000\text{B}=1000$ 次 → $0.5\text{M}/500\text{M}=\mathbf{0.1\%}$。
  机理：DMA 只在**整块结束**发一次中断，且传送期间用**周期窃取**直接访主存，CPU 几乎不介入 ✔。

**例 7-4（2011/21 中断屏蔽字）** 5 级中断 $L4\sim L0$，屏蔽字 $M_4M_3M_2M_1M_0$（$M_i=1$ 屏蔽 $L_i$），响应优先级 $L4\to L0\to L2\to L1\to L3$。求 $L1$ 处理程序中的屏蔽字：$L1$ 处理时应开放响应优先级更高的 $L4,L0,L2$（置 0），屏蔽比它低的 $L3$ 与**自身 $L1$**（置 1）→ $M_4M_3M_2M_1M_0=\mathbf{01010}$，答案 D ✔。

**例 7-5（2012/43 DMA 请求次数与优先级）**
- 每秒缺页 1.5 次（见第 3 章例 3-8），页 4 KB，磁盘接口数据缓冲寄存器 32 位 $=4$ B，周期挪用方式下每传 4 B 发一次 DMA 请求：
$$\text{每秒 DMA 请求}\ge 1.5\times\frac{4096}{4}=1.5\times1024=\mathbf{1536}\ \text{次}$$ ✔
- (3) CPU 与 DMA 同时请求存储器总线时 **DMA 优先级更高**，理由：DMA 请求得不到及时响应，高速 I/O 传输的数据可能丢失 ✔。
- (4) 4 体低位交叉最大带宽 320 MB/s（见第 3 章例 3-8）✔。

**例 7-6（2010/21 单级中断服务程序顺序）** 硬件（中断隐指令）完成：关中断 → 保存断点 → 识别中断源；中断服务程序完成：保护现场(Ⅰ) → 中断事件处理(Ⅴ) → 恢复现场(Ⅵ) → 开中断(Ⅱ) → 中断返回(Ⅶ) → 答案 **A**（`Ⅰ→Ⅴ→Ⅵ→Ⅱ→Ⅶ`）✔。单级中断**不允许嵌套**，故处理期间不再开中断。

**例 7-7（2012/22 中断隐指令）** 除保护断点外，中断隐指令还完成 Ⅰ 关中断、Ⅲ 形成中断服务程序入口地址并送 PC；Ⅱ 保存通用寄存器属中断服务程序 → 答案 **B（Ⅰ、Ⅲ）** ✔。

### 7.4 易错点与 408 真题考点

| 易错点 | 正确结论 |
| --- | --- |
| 中断响应与 DMA 响应时机相同 | 中断在**指令周期结束**，DMA 在**总线周期结束**（更早） |
| 周期挪用中 CPU 优先 | **DMA 总线优先级高于 CPU**，防高速设备丢数据 |
| DMA 每传一个字都中断 | 仅**一整块传送结束**才发一次中断 |
| 响应优先级 = 处理优先级 | 前者硬件/查询排队固定；后者**中断屏蔽字动态设定** |
| 中断隐指令负责保存通用寄存器 | 由**中断服务程序**完成；隐指令只做关中断、保存断点、送入口地址 |
| 单级中断可嵌套 | 单级中断**不允许中断嵌套** |
| 状态端口与命令端口不能复用 | 二者方向相反、访问时间错开，**经常复用** |
| USB 并行传多位 | USB 是**串行（差分）**通信总线 |
| 字节多通道传输率取最大 | 字节多通道是**各设备之和**；选择/成组通道才取最大 |
| Cache 与 Buffer 一样 | Cache 是低速数据的**备份**、缺失可直接访低速；Buffer 是**必经之路**、数据独有 |
| 通道 = I/O 处理机 | I/O 处理机另有**自己的指令系统和存储器**、有数据处理功能 |
